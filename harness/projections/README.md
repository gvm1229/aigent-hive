# Host projections

Host projection은 provider-neutral canonical source를 Codex, Claude Code, Gemini Antigravity가 발견할 수 있는 얇은 파일로 변환.

- orchestration engine 제외
- host 또는 OMX/OMC runtime file은 소유 범위 밖
- broad keyword hook 추가 금지
- Hive marker와 namespaced command만 사용
- 지원 여부는 host/version별 conformance evidence로 결정
