# Host projections

Host projection은 provider-neutral canonical source를 Codex, Claude Code, Gemini Antigravity가 발견할 수 있는 얇은 파일로 변환한다.

- orchestration engine을 포함하지 않음
- host 또는 OMX/OMC runtime file을 소유하지 않음
- broad keyword hook을 추가하지 않음
- Hive marker와 namespaced command만 사용
- 지원 여부는 host/version별 conformance evidence로 결정
