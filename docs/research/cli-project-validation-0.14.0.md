## 새 프로젝트 설정

- 진입: `hive setup --target <dir>`, 선택적 `--user-root`, 터미널 또는 명시적 무입력 방식
- 공통 질문 목록·범위별 진행 저장·미리보기·최종 확인과 기존 핵심 적용·검증 재사용
- 빠른 설정: 전역 언어·위키·성격·프로젝트 기본 기능 상속, 역할·지식 포함 경로·외부 공유·선택 후크의 자동 추가 없음
- 맞춤 설정: 현재 질문 목록의 직접 입력, 잘못된 값에 대한 해당 질문만 반복
- 호스트 존재·설치 지원 버전과 실제 실행 기능 증거 구분. 별도 증거 없는 기능은 `unverified`, 외부 실행 도구의 자동 선택 없음
- `--show`, `--describe --section <id> --output json` 조회와 미완료 `--resume` 연결
