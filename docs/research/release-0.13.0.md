# 세션 중단·알림 전용 0.13.0 출시 검증

## 로컬 검증 시점의 범위

- 사용자 최종 선택: 세션 중단·알림 창만0.13.0으로 출시. 기존0.12.1 번호의 새 기능 분류 충돌을 피하는 minor 버전, 버전 정책 예외 없음
- 로컬 소스 검증 완료 당시의 기록, 공개0.13.0-test.1·안정판 게시 전 시점. 당시 공개 안정판0.12.0
- 이후 상태는 [공개 시험 수용](public-test-0.13.0.md)과 [정식 출시 실행](../plans/0.13.0-stable-release.md)에서 추적
- 선택형 독립 감시: 설치·업데이트만으로 새 활성화 없음, 정확 preview 확인과 세션 중단 승인 필요. 기존 활성 선택 유지
- Codex 앱 종료·재개 잠금·다른 예정 기능 제외. 추가 실제 중단 시험 없음

## 로컬 검증

- [정확한 기록](../../tests/results/release-0.13.0-local.json): Windows 11 x64·소스 빌드. 공개 패키지를 검사했다는 주장 제외
- 전체 Rust 1,027개 통과·5개 제외, 엄격 Clippy·rustfmt 통과. 제외는 별도 실제 사용량 감지·동의된 의미 검색 환경·대규모 성능 자료가 필요한 검사
- 최종 Skill 표시·지문 결합 뒤 관련54개 중51개 통과·3개 제외. 제외 이유: POSIX 전용 심볼릭 링크·FIFO와 권한 없는 디렉터리 연결 미지원
- 새 정상 관측 뒤 확인 명령 없이 자동 작업 허가, 다른 세션 결합 거부, 초기화 감지 시 현재 허가 거부 검증. 관측 역행·기록 변조 거부 유지
- 0.9.1~0.12.0의 공개 안정판 원본 표본12개에서 갱신·원복·중단 복구·사용자 수정/외부 파일 보존의 Windows 검증. 공개 후보의 다섯 운영체제/구조 검사와 구분

## 현재 앱 근거의 연결

- [0.12.1-dev 수용](../../tests/results/session-stop-one-shot-qualification-0.12.1.json)의 실제 native 중단 경로와 후속 한 차례 제어·표시 검증 보존
- 감시·조회·중단·알림·공식 로고11개 파일의 정본 Git 바이트가 해당 검증 커밋과 동일. Windows 플랫폼 검사 스크립트의 작업 사본 CRLF와 정본 LF를 구분한 비교
- 버전·이전 버전 호환 자료·공개 Skill 표시 변경만으로 연결. 새0.13.0 통합 실제 중단 시험이나 실제 제공자 초기화 시험으로 확대 주장 제외
- 현재 사용자0.12.1-dev 설치와 로그인 상시 감시는 유지. 공개0.13.0으로의 실제 사용자 설치는 별도 승인 범위
- 다른 운영체제·원격·클라우드의 실행 중단, 서버 처리/과금 동시 종료는 미지원·미증명

## 공개 전 조사 이력

- 첫 원격 검사: 새 검사4개 미등록으로 시작 전 거부, 기존 contract 묶음에 등록하고 목록의 누락·중복 검사 유지
- 두 번째 원격 검사:0.12.1의 새 기능 분류 충돌, 합성 시험 자료 표시, 문서 연결/출처 지문, 옛 확인 잠금 가정2개 발견. 번호0.13.0 선택·표시 정정·소스 위키 정합화·직접 재개 검사로 대응
- 실패·취소한 실행은 공개 시험 게시나 통과 근거로 집계 제외. 공개 후보·게시·수용의 정확한 번호·소스·지문은 다음 단계에서 기록
