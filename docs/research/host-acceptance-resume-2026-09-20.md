# 0.11.0 실제 호스트 수용 재개

대상: 기존 미완료 6개 항목. 환경: Windows Codex. 기존 수용 기준·제품 버전·안정판 승인 경계 유지.

## 실행 순서

1. `RFH-002`: 기존 격리 폴더의 정확한 훅 정의 신뢰 확인과 실제 차단 재시험. 독립적인 지식 저장·새 작업 조회는 먼저 검증
2. `HK-003–004`: 실제 호출·파일 지문·고정 사례로 판단. 보호 편집 성공과 미지원 사례의 실패 기록 보존
3. `RFH-003`: Codex 수용 이후 같은 자료로 다른 호스트 확대. 접근 불가 시 정확한 사용자 실행 절차 준비
4. `RB104-004`: 설치된 호스트의 작업 조회·중단 연결부터 확인. 연결 없는 감시기와 추론 중단의 성공 추정 제외
5. `RFR-001`: 위 증거와 전체 검증 확인 후 번호 시험판 절차 진행. 미완료 항목의 임의 제외 금지

## 증거 기준

- 합성 지식과 격리 사용자 루트만 사용. 실제 사용자 지식·전역 설정 변경 제외
- 새 작업의 요청에는 질문·도구·경로만 전달, 정답과 기존 대화 전달 제외
- 실제 앱의 도구 결과와 정본·색인·결과 파일 지문을 함께 확인
- 제품 지문·호스트·버전·운영체제·실행 여부·증명 한계 기록
- 모사 시험·설정 존재·명령 성공을 실제 앱 차단 성공의 대체 근거로 사용 금지

## 연결 조사

- Codex 동봉 CLI의 기본 제어 소켓 조회 실패: Windows 소켓 오류 `10050`. 현재 앱은 `app-server`로 실행 중이나, 이 결과만으로 별도 클라이언트 연결 가능 판정 불가
- [Codex 비동기 훅](https://learn.chatgpt.com/docs/hooks#run-hooks-in-the-background): 다음 안전한 시점의 안내 전달, 진행 중 작업 차단 권한과 구분
- [Codex 작업 중단](https://learn.chatgpt.com/docs/app-server#interrupt-a-turn): 정확한 작업·턴 식별자와 연결된 전송 경로 필요. 성공 응답 뒤 실제 중단 결과의 별도 확인
- 새 서버 시작·앱 재시작·신뢰 우회·프로세스 강제 종료 제외
- 현재 작업 도구에 직접 작업 중단 명령 없음. 작업 이동 도구의 부수적 중단을 감시 기능으로 전용하는 방식 제외

## 실제 지식 연결 결과

- 실행: Windows 11, Codex `0.155.0-alpha.9.2`. 정답을 전달하지 않은 새 작업에서 검색 1회·추가 질문 0회·후속 파일 작성 성공
- 근거: 호스트의 `commandExecution` 종료 `0`, `fileChange` 완료와 실제 파일 독립 재조회. 같은 작업의 두 번째 요청에서도 검색 1회로 동일 근거 반환, 파일 쓰기 없음
- 제품: `decd54a1`에서 빌드한 `0.11.0`. 실행 파일 SHA-256 `9b5aa8a6bda331e2643ea3345c1178ae80198a4690f61a44b6e2564d7a465ee2`
- [정본·색인·결과 파일 확인](../../tests/results/runs/20260919T173028-d530c967ecef.md): 합성 결정 1개, 파생 색인 검사 통과, 검사에 따른 파일 쓰기 0건
- 결과 파일 SHA-256 `039d8e462a78d2eeabba0ab9c36695ced88ee0a03219241af906f32c0535a0cd`, 색인 SHA-256 `202a5bff3d41f97786d8a8c8cf4c54b4049d68f90aeb9a77243aa67bc5c77a39`
- 준비 오류: 격리 기본 `Wiki`·`Raw` 디렉터리 누락으로 검사 2회 실패. 빈 디렉터리 보완 뒤 통과, 실패 기록 보존. 제품 코드 수정이나 지식 내용 변경과 구분
- 제한: 명시적 CLI 경로를 준 단일 합성 사례. 스킬 자동 선택·실제 취소 후 재개·다른 호스트·훅 차단의 증명 제외
- 저장 작업 완료와 정본 생성 확인. 해당 작업의 최신 도구 목록 조회가 비어 있어 정확한 저장 호출 횟수 주장 제외

## 남은 수용 경계

- `HK-003`: 정의별 신뢰 확인 대기. 이전 보호 파일 편집 성공의 실패 판정 유지
- `HK-004`: 실제 차단 확인 뒤 같은 정책의 지침 단독 대비 평가 필요. CLI 모사 결과로 완료 대체 금지
- `RFH-002`: 지식 연결·완료된 작업 재조회는 실제 확인. 취소와 취소 후 재개·정확한 훅 신뢰 확인은 별도 대기
- `RFH-003`: Codex 수용 이후 Claude·Antigravity 실제 작업 필요. 이번 버전 조회는 각각 `2.1.163`, `1.1.18`; 모델 실행 없음
- `RB104-004`: 초기화 감지의 작업별 제외는 별도 구현. 15초 감시와 진행 중 추론 중단은 연결된 호스트 제어 증거 부재
- `RFR-001`: 위 수용 전 시험판·전체 계획 완료 판정 불가. 미완료 6개를 완료나 출시 제외로 변경하는 조치 없음

## 초기화 감지 제외의 독립 구현

- `7445f519`: `disable-reset-guard`·`enable-reset-guard`와 제외 전용 확인 인자 추가. 기존 명령·전역 설정·잔여량 보호 유지
- 같은 호스트·세션·프로세스의 제어 기록만 사용. 옛 기록의 기본 활성, 다른 연결로 제외 권한 이전 금지
- 이미 발생한 초기화 중단은 제외 명령으로 해제 불가. 기존 지문 확인 절차와 새 `enforce` 필수
- [명령줄 회귀](../../tests/results/runs/20260919T173641-6d88edaa00ec.md): Windows 72개 중 68개 통과, POSIX 링크·권한·Unix 프로세스 조건 4개 제외
- [스킬 투영](../../tests/results/runs/20260919T173850-2ea56c146a97.md): Windows 22개 중 20개 통과, POSIX FIFO·링크 권한 조건 2개 제외
- [전체 Rust](../../tests/results/runs/20260919T174105-3d8aaddbbf81.md): Windows 941개 통과·별도 조건 4개 제외, 형식·Clippy 통과. 외부 호스트 중단·주기 감시의 증명 제외
- Rust 제외 사유: 동의된 선택형 검색 환경 1개, 50,000개 초과 기밀 자료 규모 시험 1개, SSD의 `--release --ignored` 성능 시험 2개. 이번 실행에서 해당 환경·성능의 검증 없음
- 첫 전체 Python 실행: 변경 전 코드 지문을 가리킨 사실 문서 오류. 해당 출처 갱신·문서 형식 보완 후 정본 186개와 파생 색인 검사 통과, 최초 실패 기록 보존
- 설치된 `0.10.3` 변경·실제 사용자 보호 해제 없음. 새 개발 명령의 실제 사용 전 설치본 도움말 확인 필요

- [전체 Python 재실행](../../tests/results/runs/20260919T174439-c94228c3a950.md): Windows 928개 중 885개 통과·43개 제외. 문서·보안·명령 규약·통합·배포 전 구간 통과. POSIX 전용 동작·Windows 링크 권한 등 제외 조건과 실제 호스트 수용은 별도 범위
