- [Codex 비교](../../tests/results/runs/20260920T031956-d390dfb20948.md): 명시 요청 1,266바이트. 실제 전체 실행 80.060초·77.852초
- [Antigravity 자료 동결](../../tests/results/runs/20260920T192301-a437a8912c8c.md), [훅 적용](../../tests/results/runs/20260920T192617-c9ad09966616.md), [지침 단독](../../tests/results/runs/20260920T192800-8090aa333878.md): 명시 요청 바이트·지문 보존, UI의 Worked for 표시는 30초·39초
- 실제 파일 효과는 모두 별도 바이트 검사. 시도 횟수는 호스트 작업 보고, 추가 질문은 실제 대화 관측. 공개되지 않은 내부 호출·재시도 횟수 추정 제외
- 정상·유사 허용 경로·보호 경로·미로드·손상 입력/설정·시간 초과·중단 재개의 자료와 결과를 [연결 기록](host-acceptance-final-queue-2026-09-20.md)에 보존
- [명령 비용 90회](../../tests/results/runs/20260920T084942-3a65aa4e1dd5.md): 직접 검사기 중앙값 8.197–11.664ms, 바깥 명령 포함 376.643–393.449ms. 입력·출력 바이트와 각 5회 표본 보존
- 전체 실행 시간에는 모델·도구 작업 포함. 모델 전체 문맥 토큰·훅 단독 지연·일반 준수율·큰 표본 성능의 증명 제외. 서로 다른 앱의 시간 표시를 정밀 성능 순위로 비교 금지
- 초기 진단의 경로 누락과 바깥 셸 문제, Antigravity 빈 TargetContent 오류는 원래 실패로 보존. 수정한 것은 시험용 진단·입력이며 제품이나 보류 자료의 기대값 변경 없음
- 실행 파일·정의·합성 파일의 정확한 복원 확인. 승인된 후속 범위인 Claude·상시 감시·자동 중단을 통과 사례에 포함하지 않는 판정
