## 제외·미검증

- Windows 명령 검사1개·투영2개: Unix 링크 시험의 운영체제 제한, 수용 실패와 구분
- 현재 계정의 실제0%·유료 크레딧 전환: 비용 발생 시험 미실행, 합성 관측의 차단만 증명
- 현재 실행 중단: 지원 제어 연결 부재, `active_turn_interruption_verified=false`. Hive 밖 호출·이미 실행한 호출의 크레딧 사용 방지 보장 제외
- Linux: WSL 목록의 docker-desktop만 존재, 전용 개발 배포판 부재. 컨테이너·원격 CI의 별도 검사 필요
- macOS: 원래 간헐 오류·실제 호스트 수용은 QLF112-005의 마지막 실행, Windows 결과로 대체 금지
- 공개 시험·안정판·현재 사용자 설치: 미실행. 새 시험은 정확한 소스·제품 지문·검사 뒤 진행, 안정판·설치는 0.12.0별 승인 필요
