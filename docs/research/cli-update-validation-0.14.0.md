# 0.14.0 갱신 연결의 Windows 검증

## 결론과 적용 범위

- 공개0.13.1 원본에서 시작한 같은 갱신 명령 안의 새 질문·답변·설정 적용·최종 검사 통과
- Windows11 x64·Codex 터미널에서 실행. 구버전 실행 파일은 원본, 새 실행 파일은 로컬0.14.0 개발본, 설치 프로그램과 Antigravity는 시험 대역
- 공개0.14.0 배포물의 합격 근거에서 제외. 실제 앱·직접 설치 전체 교체·Linux·macOS·시간 제한 복구는 별도 미검증
- 승인 계획의 U140-001~003 미완료 유지. 다음 공개 시험은0.14.0-test.1, 실제 사용자 설치는0.13.1 유지

## 발견한 입력 오류와 수정

Windows ReadConsole의 반환값은 실제로 읽은 글자 수. 기존 StringBuilder 변환은 그 뒤의 미입력 영역까지 문자열로 취급하여 짧은 답변과 빈 Enter의 반복 오류 발생.

- 수정: 문자 배열과 반환된 글자 수만 사용, 배열 크기를 넘는 반환값 거부
- 실제 콘솔 확인: `yes`·빈 Enter·한국어 `예`의 정확한 전달
- [자동 회귀](../../tests/conformance/contracts/test_windows_update_console.py): 사용자 콘솔과 분리된 숨김 콘솔에 합성 키 입력, 짧은 답변·빈줄·한국어·반복 읽기 검사
- [Windows 회귀4개 통과](../../tests/results/runs/20261023T235903-c519a498cc7a.md): 새 콘솔 검사1개와 기존 연결 계약3개. 다른 운영체제의 콘솔 동작은 증명 범위 밖
- 제품 커밋: `4134da47`. 앞선 앱 범위 보존: `e785a958`

## 새 갱신 명령과 재개

- 같은 버전의 `hive update`에서 미완료 설정을 registry 조회·재설치보다 먼저 재개. [실패 뒤 실제 재개](../../tests/results/runs/20261023T202931-0e6cd4a92910.md)
- 비대화형 이전의 기존 독립0% 보호·조회 실패 차단 보존, 새 경고 비활성, 미응답 질문 유지. 이후 터미널에서 같은 질문의 명시적 변경. [완료기 시험](../../tests/results/runs/20261023T213311-ab0230b76f6f.md)
- `--confirm`은 소프트웨어 갱신 승인만 대신하며 설정 질문 유지. `--non-interactive`·JSON은 입력 대기 없음, `--interactive`는 터미널 필수, 충돌 옵션은 쓰기 전 거부
- [실제 터미널의 JSON 시험](../../tests/results/runs/20261023T234501-b4e7443123a7.md): 기존 효과·선택형 질문 보존, 단일 JSON, 반복 실행의 설정 불변. 합성 npm 배치·앱 대역, 실제 본체 교체 제외
- [직접 설치 인계 시험](../../tests/results/runs/20261023T234549-ac72f7cc96aa.md): 부모의 pending과 별도 결과 파일 구분. 미완료를 성공으로 표시하지 않는 반환만 증명, 본체 교체와 동기 완료는 미검증
- 제품 커밋: 재개 `20c682bd`, 완료기 `bfd44872`, 새 부모 연결 `717367b1`, 입력·결과 `bbbd34a5`

## 적용 기록의 결합

- `538bbb56`: 답안뿐 아니라 감시 이전 정보·원본 형식·질문·대상·설정 방식까지 처리 기록의 지문에 포함
- 실제 진행 상태의 변경만 허용, 이미 확인한 실행 정보 변경 시 재개·투영·완료 거부. 선택 출처를 별도 실행 권한으로 사용하는 동작 없음
- [진행 기록15개](../../tests/results/runs/20261023T233635-d8e3b95ca321.md)·[설정118개](../../tests/results/runs/20261023T233729-45f7935651a1.md) 통과. Windows 합성 파일 검사, 실제 사용자 설정이나 다른 OS의 증명 제외
- 구버전이 고른 앱은 진행의 update_hosts로 보존. 동일0.14.0 재개에서 유지, 다른 앱 범위의 재사용 거부. 구버전 질문판·답변 시각의 임의 생성 없음
