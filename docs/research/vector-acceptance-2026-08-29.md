# 벡터 검색 수용·시각 설명 계획

## 유지보수자 결정

- 2026-08-29: 현재 5만 청크·100모음 스트레스 측정 결과의 제품 수용 승인
- 최초 생성과 대규모 변경 비용의 사전 안내, 기존 FTS·증분 재사용 유지
- 과거 기준 미달 기록·원본 측정값 보존. 승인 뒤 수용 정책 변경과 재판정으로 구분
- 작업 동안 모델을 유지하는 제안은 반복 준비 비용을 줄이기 위한 선택적 성능 개선안. 이번 요청에 따라 생략, 별도 기능·보안 결함 해결의 선행 조건 아님
- 안정판 승인 아님. 이후 번호 시험판 절차만 허용

## 실행 계획

1. 고정 측정값에 새 스트레스 수용 정책 적용, 품질·격리·무결성·복구 기준 유지
2. 기존 판정기의 과거 정책 보존과 새 정책 선택·회귀 시험 추가
3. `VEC10-007` 채택 완료, ADR·계획·현재 상태·사용 안내·bilingual fact 정합화
4. `docs/hive-vector-search.ko.html` 작성: 구현 흐름·Hive 연결·기술 구성·실측·사용 주의사항의 독립형 시각 문서
5. 문서·시각/좁은 화면·접근성·오프라인 동작 확인 후 concern별 commit·push
6. 승인된 벡터를 포함한 번호 시험판 준비·수용으로 진행. 안정판 작업 제외

## 새 운영 기준

현재 측정 수용과 후속 큰 회귀 탐지를 위한 한도. 유지보수자가 직접 지정한 숫자가 아닌, 이번 승인에 맞춰 설정한 운영 기준.

| 측정 | 기존 기준 | 새 기준 | 현재 관측 |
| --- | ---: | ---: | ---: |
| 5만 개 전체 생성 | 600초 | 900초 | 638.597초 |
| 100개 변경 갱신 | 30초 | 90초 | 51.989초 |
| 새 CLI 전체 조회 p95 | 2초 | 4초 | 최대 3.067394초 |
| 100DB SQL 조회 p95 | 50ms | 150ms | 98.8755ms |

- 모델 유지 warm 500ms: 현재 단발 실행 구조의 출시 차단 기준에서 제외, 통과로 재명명하지 않는 미측정 항목
- 의미 질문 90% 이상·FTS 대비 15%p 이상 향상, 정확 질문의 문항별 순위 무회귀 유지
- 512MiB 색인 한도·누출 0건·제공자 API 0건·FTS 복귀·재개/복구·세 운영체제 수용 유지
- 고정 Windows 합성 자료 기준. 모든 PC의 보장 시간이나 1–10개 변경의 미측정 지연으로 환산 금지
- 최초 생성 외에도 모델/처리 계약 변경·벡터 삭제·복구 방식에 따라 전체 재계산 가능. 소규모 변경은 보통 재사용에 유리하지만 고정 비용도 존재
