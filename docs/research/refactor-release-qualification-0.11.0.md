1. 시험 의도·양언어 출시 설명·현재 수용 근거 검증과 커밋
2. PR #60의 정확한 커밋·필수 검사 확인, develop 통합
3. Release candidate를 develop에서 실행, 다섯 대상·npm 후보·서명/출처 결과 확인
4. 성공한 정확한 후보 실행 ID로 test 채널 게시
5. npm 정확한 버전·test 태그·GitHub prerelease 확인, latest=0.10.3 불변 확인
