- 현재 Windows 11 x64·Codex `26.1013.4894.0`의 사용자 신고 직후 읽기 전용 조사
- 앱 종료 명령의 직접 실행 없음. 해당 시각 감시 실행·Windows 사건·앱 기록·충돌 수집 기록 대조

- 충돌을 일으킨 정확한 함수·예외·메모리 상태는 미확정. 남아 있는 자료에 충돌 덤프·예외 코드 부재. 직전 `ResizeObserver` 화면 오류 반복은 시간상 단서이며 원인 증명 제외

## 재발 방지와 계속한 확인

- 기존 Hive 감시 예약1개·이번 시험 예약8개 임시 비활성화. 당시 실행 중인 Hive 감시·검사 프로세스0개 확인
- 기존 감시 활성 선택·지식·사용자 설정·중단 기록·예약 정의 보존. 실행 차단과 사용자 선택 변경의 구분, 재활성화 전 새 버전 수용 필요
- 실제 중단 재시험 보류, 앱 종료·재시작·잠금·프로세스 이름 기준 종료 없음
- 조회 보조 프로세스 정리만 현재 앱에서 별도 실행. 기본 조회 → 소유 조회 프로세스 장애 → 새 프로세스 보조 성공 → 기본 조회 복구 → 조회 제어부 정상 종료 순서 확인
- 위 전 구간에서 핸들로 고정한 Codex 주 프로세스·화면과 무관한 시험 형제 프로세스 보존 확인. 앱 제어 메시지·중단 요청 없음
- 조회 정리 확인의 최초 검사는 조회 경로 표시값을 잘못 예상하여 실패. 실제 반환값에 맞춘 재검사 통과, 첫 실패 기록 보존
- 현재 정리 경로의 소유 범위 증거이며 앱 충돌의 완전한 재현·원인 해결 증명 제외. 공개·설치·전체 기능 완료 판단 보류

- Agent 소유: 자동 회귀, 재활성화 관측 시간·상태 표시 점검, 실패한 실제 수용 결과 보존
