# 0.14.0 설정 기반 검증

## 판정 범위

- 대상: P140-001의 설정 자료 형식·선택 출처·범위별 진행 저장
- 실행: 2026-10-23 Windows 11 x64·Codex, 로컬 개발 소스0.14.0. 각 시험의 소스 SHA·변경 지문·실행 명령은 연결된 기록에 보존
- 완료 판정: v1/v2 읽기·왕복, 값과 출처의 같은 파일 교체, 외부 편집 구분, 상속 선언 지문, 동시 저장 거부, 진행 대상 분리
- 제외: v1 감시 상태에 따른 실제 이전, 새 보호 정책의 실행 효과, 공개0.13.1 첫 갱신, 대화형 최종 적용 전체, 다른 운영체제 수용. 해당 항목은 별도 계획 기준으로 미완료 유지

## 진행 중인 터미널 연결

- 공통 질문43개·선택지·조건·두 언어·기본값의 정본 추가. 묶음별 조회와 기존 전체 조회 병존
- 신규 전역 질문·잘못된 답의 해당 질문 반복·기본 거부인 최종 확인·선택 기록 저장 연결
- [Windows 실제 터미널 첫 실행](../../tests/results/runs/20261023T084737-d87367b026e7.md): 한국어 선택 후 설정 방식 질문에서 중단, 선호 본문·설치 파일 변경 없음
- [같은 버전 재개](../../tests/results/runs/20261023T084804-c2ded4d8cce2.md): 저장된 한국어 재사용, 설정 방식·배경 선택 후 앱 선택에서 중단, 진행 보존
- 두 실제 터미널 기록은 각 기록의 개발 실행 파일만 증명. 마지막 확인 뒤 실제 설치·감시 전환·전체 복구·공개 파일의 수용 근거에서 제외
- 기존 v1 전역 설정은 현재 연결층에서 이전 보류 결과 반환. 검증된 실제 감시 상태와 사용자 선택을 연결하는 P140-002 작업 이후 전체 흐름 수용
- 중간 모듈 가시성·시간 함수·타입·수명·정적 검사 실패 기록 보존. 수정 후 위 회귀 재통과, 실패 기록의 삭제나 통과 근거 전용 없음
