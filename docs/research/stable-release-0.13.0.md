## 사용자 동작과 검증 경계

- 새 감시는 명시적 선택 후 활성화. 설치·업데이트만으로 새 활성화 없음, 기존 활성 선택 유지
- 초기화 관측 또는 정상 조회60초 공백 때 감지 당시 작업에 한 차례 중단 요청. 15초 시작·5초 조회 제한·2초 재시도
- Codex 앱 유지·직접 재개·새 메시지 허용. 알림은 이유·시각·확인 상태와 닫기만 제공, 잠금·해제·자동 작업 재개 없음
- 실제 앱 중단·표시 증거는0.12.1-dev 구성요소 수용과 동일 정본 코드의 연결. 공개 시험판의 현재 Windows 읽기·기본 비활성·기존 설정/앱 유지 확인, 새0.13 통합 실제 중단 요청0건
- Windows 11 x64·Codex26.1013.4894.0의 실행 중단 지원. 세 운영체제의 패키지 검증과 구분. 실제 제공자 초기화·서버 처리/과금 동시 종료·정확한 OS 자식5초 종료는 미증명
- 현재 사용자 설치는 기존0.12.1-dev·상시 감시 유지. 마지막 정상 관측 공백1초·실제 감시 정상 확인, 실제 사용자0.13 설치 변경 없음
