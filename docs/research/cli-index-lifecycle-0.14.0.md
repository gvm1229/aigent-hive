# 0.14.0 전역 색인 범위와 종료 복구

## 범위와 현재 판정

- 전역 설정의 검색 저장소 준비·보존·해제·되돌리기 범위
- Windows 11 x64의 개발 CLI와 가짜 Codex, Linux amd64 격리 컨테이너의 관련 Rust 시험
- 실제 사용자 설치·감시 변경 없음. 실제 CLI 2건에서 0.13.1 실행 파일과 확인 대상 설정 4개 지문 불변, Linux에는 실제 설치 폴더 연결 없음
- 외부 모음을 포함한 위키 재활성화는 [후속 동의·복구 검증](cli-index-reactivation-0.14.0.md)으로 연결. 공개 후보 수용은 미완료, 전체 설정 완료 기준으로 확대 금지

## 설정과 지식 재구축의 분리

- `447e5698`, `48a2ddeb`, `2da66957`: 설치가 확인한 사용자 폴더의 실제 식별자와 저장소 결합. 다른 폴더로 바뀐 경로 거부
- 검증된 게시 색인은 그대로 보존. 새 색인·손상된 파생 자료는 연결된 외부 모음이 없는 사용자 범위에서만 생성·복구
- 등록 정보만 확인하며 다른 프로젝트 폴더·문서를 자동으로 열지 않는 경로. 조회 뒤 바뀐 등록 정보의 빈 목록 덮어쓰기 거부
- 외부 자료가 필요한 복구는 명시적인 색인 재구축 요구. 기존 지식 명령의 전체 재구축 기능과 엄격한 프로젝트 경로 검사 유지
- [실제 전역 설정 변경](../../tests/results/runs/20261024T130259-1a71bda36ea5.md): 활성 등록 프로젝트를 다른 시험 폴더로 이동해 원래 경로를 없앤 뒤 답변 방식 변경 완료. 색인·세대 정보·검증 정보·등록 목록 바이트와 이동된 원문 보존
- Windows 설치 106개·공유 등록 16개·관련 코드 검사 통과. 위키 모듈 기본 검사 206개는 최초 사용자 범위 API 단계의 근거, 이후 변경 전체의 합격 근거로 전용 금지
- 게시 색인 보존은 현재 프로젝트 원문 전체를 새로 검사했다는 뜻과 구분

## 위키 해제의 원문 복구

- `a2730729`: 파생 파일 8개의 기존 바이트·권한·지문을 사용자 폴더 안에 먼저 보관하고, 백업 3판에 삭제 의도 기록 후 제거
- 복구는 프로젝트 문서를 재구축하는 대신 보관 원문 복원. 백업 1·2판 읽기 유지, 3판의 삭제 기록 누락 거부
- 변경된 현재 파일·변조된 백업·허용 경로 밖 항목·다른 사용자 폴더 거부. 초기 설정 선택이 없는 설치는 기존 색인 보존
- 중간 삭제를 위한 임시 보관 파일과 빈 보관 폴더도 복구. 기존 하네스 파일 한도 16MiB를 넘는 색인에 별도 128MiB 한도 적용
- [실제 종료·재개](../../tests/results/runs/20261024T124923-986272d6c741.md): 첫 색인 파일 삭제 뒤 종료 88→비대화형 재개→원래 색인 복원→해제 완료. 두 번째 해제의 백업 지문으로 원래 3개 색인 파일의 정확한 복원 확인
- 위 시험의 등록 프로젝트 원래 경로는 계속 부재. 등록 정보와 이동된 원문 보존, 프로젝트 재구축이나 폴더 재생성으로 복구를 대신하지 않는 확인
- Windows 설치 106개·색인 제거 4개·코드 검사, [Linux 색인 제거 4개](../../tests/results/runs/20261024T125326-b8b24cc3686a.md) 통과

## 종료 후 남는 잠금과 완료 판정

- 실제 시험에서 두 결함 확인: 진행 중인 설치 기록을 건너뛴 완료 판정, 프로세스 종료 뒤 남은 구형 파일 존재 잠금
- 설치 기록이 남으면 파일 모양만으로 검증 완료 판정 금지. 필요한 복구 후 재적용·검증 경로 연결
- `2081dfb3`: 새 잠금 2판은 운영체제 파일 잠금 사용. 완성된 표시 파일을 원자적으로 게시하고, 잠금 획득 뒤 파일 식별자 재대조
- 정상 종료 시 소유 표시만 정리, 갑작스러운 프로세스 종료 시 운영체제 잠금 해제. 다른 파일로 바뀐 잠금 경로 보존
- 구형 1판 표시와 알 수 없는 표시는 살아 있을 수 있으므로 자동 삭제·우회 금지. 소유 상태를 확인할 수 없는 구형 잠금의 수동 해결 가능성 유지
- Windows 위키 기본 검사 210개·잠금 4개·코드 검사와 [Linux 잠금 4개](../../tests/results/runs/20261024T125034-8c382de4526c.md) 통과. 경쟁 작업 4개·80회에서 동시 진입 없음
- 위키 기본 검사에서 사전 제외된 규모·성능 3개는 [기존 이유](cli-user-settings-0.14.0.md#프로젝트별-기준과-범위-검사) 유지. 이번 결과로 해당 규모나 지연 시간 성능 증명 없음
- 최초 시험 입력 지연·허위 완료·잠금 잔존·컴파일/정적 검사 실패 기록 보존. 수정 후 통과와 구분

## 남은 수용

- 위키 해제 뒤 외부 모음 재활성화의 순환 경로는 후속 CLI 동의·적용으로 해결. 개별 파일 교체 동작 내부의 강제 종료와 남은 임시 보관 파일의 일반 복구는 별도 미검증
- 실제 기한 종료·부모 종료·전원 손실, macOS, 실제 호스트 기능, 공개 0.14.0 파일 수용은 미검증
- 다른 기능에서 사용하는 일반 지식 재구축을 사용자 범위 준비로 대체했다는 주장 금지
