# 앱 유지와 세션 중단 0.12.1 검증

## 현재 범위

- Windows 11 x64, Codex 앱 패키지 26.1007.9446.0. 기존 앱의 현재 사용자 소유 로컬 통신 통로 연결·현재 대화 소유자 확인

- 앱의 `thread-follower-interrupt-turn` 요청과 `user-stop` 처리. 공식 `turn/interrupt`·목표 일시중지·하위 작업 정리 경로, 실제 `interrupted`·앱 생존 확인 필수

- Windows 지속 표시 창의 원인·중단 확인 대기/실패/성공·앱 상태. 닫기만으로 작업 재개 불가
- 현재 전역 설치 0.12.1-dev의 앱 종료 감시 비활성·예약 제거. 새 세션 중단 감시의 실제 수용과 조건부 교체 진행

## 수정한 실패

- Windows 프로세스 인수 32767자 제한: UTF-16 인코딩 명령의 34688자 실패 재현, 고정 UTF-8 본문을 전달하는 방식으로 수정 후 현재 앱 읽기 통과
- Windows 잠금 파일의 내용 읽기: 정상적인 동시 확인의 오류 33 오인. 부모 디렉터리 핸들·링크 미추적·바이트 잠금만 사용하는 방식으로 수정 후 경합 회귀 통과
- 설치 성공 판정의 생존 확인 부족: 실제 정상 관측 네 번·현재 앱 제어 연결까지 필수. 이전 성공 기록으로 새 기준 통과 처리 금지
- 최초 분할 메시지 시험의 불필요한 반환값 출력과 명령 실행기 인수 오류는 수정 뒤 재검사 통과. 원래 실패 기록 보존
