## 증거 해석

- 초기 회귀 실패: 기존 코드의 확장 경로 전달 재현
- 중간 컴파일·관련 시험 실패는 수정 과정 기록; 완료 근거에서 제외
- 관련 시험의 동시 기록 변경 표시는 소스 고정 근거에서 제외, 최종 전체 검사 기록으로 대체
- 실제 Claude CLI 시험은 구독·모델 호출 없는 로컬 플러그인 관리 명령에 한정
- 현재 사용자 홈·기존 설치·보호 브랜치·안정판 게시 변경 없음
- 시험 자료는 등록된 소스 시험 폴더에 보존, 자동 삭제 없음
