# 0.13.1 사용량 보호 보정과 검증

## 범위와 현재 경계

- 요청: 기존 하한 보호에도 진행 중 대화의 직접 중단 적용, 잦은 조회 실패 수정
- 대상: 개발 `0.13.1`, 다음 공개 시험 `0.13.1-test.1`; 현재 공개·사용자 설치 `0.13.0` 유지
- 현재 Windows 11 x64·Codex `26.1013.4894.0`에서 자동 회귀·읽기 전용 연결·실제 설치의 갱신 미리보기 실행
- 긴 추론·셸 중단·직접 재개: 시험 대화 생성 승인 대기, 이번 보정의 실제 중단 수용 미완료
- 앱 종료·재개 잠금 없음. 다른 운영체제·원격·클라우드의 직접 중단과 서버 처리·과금 종료는 증명 범위 밖

## 하한에서 실행 중단까지

1. 앱의 대화 위치·부모 관계로 소유 대화 확인
2. [공유 정책](../../crates/hive-cli/src/usage_control/monitor.rs)에서 기존 전역·프로젝트 최대 하한, 세션 제외, 구간·0% 보호 해석
3. [하한 사건](../../crates/hive-cli/src/usage_monitor/threshold.rs)을 소유 대화·실제 대상·정책·제어·계정·사용량 묶음·구간에 결합
4. 기존 앱 연결의 `thread-follower-interrupt-turn`, `mode=user-stop`으로 해당 실행에 한 차례 요청
5. 요청 전송과 실제 취소 확인을 별도 기록. 앱 유지와 2초 요청·5초 확인을 만족한 결과만 정상 중단으로 계산

- 첫 관측부터 하한 이하인 실행도 대상. 확인 불가 위치·부모 관계는 적용 불가로 표시, 다른 프로젝트 하한 대입 금지
- 확인된 같은 사건의 수동 재개만 사전 하한 차단에서 제외. 다른 대화·자동 실행에는 허용 전달 금지, 독립 0% 보호 유지
- 하위 작업은 소유 대화 정책 계승. 사용자가 재개한 대화의 새 하위 작업도 같은 사건으로 반복 중단하지 않는 처리
- 잔량 회복·새 기간·계정·정책 변경 뒤 새 사건 준비. 같은 관측의 초기화와 하한은 한 요청·알림으로 통합
- 알림은 공식 로고, 남은 비율·적용 하한·구간·중단 확인 상태와 닫기만 제공

## 조회 실패 보정

- [조회 작업](../../crates/hive-cli/src/usage_monitor/sensor.rs)을 감시 제어부와 별도 프로세스로 격리. 정리는 직접 만든 조회 자식에만 적용
- 기본 지속 연결 실패 시 폐기, 새 프로세스의 일회성 보조 조회. 경로별 5초 제한, 정상 시작 간격 15초·실패 뒤 2초 재시도
- 두 경로 중 하나의 유효 자료만으로 정상 관측 인정. 같은 제공자를 쓰는 두 연결이며 서버 장애의 독립 대체 서비스는 아님
- 측정 시각 역행과 초기화 예정 시각 보정 분리. 구간·계정·일정 변경은 새 연결의 독립 확인 뒤 기준 갱신
- 요청 식별자·계정·구간·신선도 검사, 늦거나 손상된 응답 폐기. 단순 예정 시각 경과를 초기화로 취급하지 않는 경계
- 시스템 시각과 별개인 경과 시간으로 연속 60초 판단. 유효 관측이 없는 장애당 한 번 중단, 정상 회복 뒤 다음 장애 감지

## 갱신과 제어

- 공개 `0.13.0` 고정 원본과 그 원본에서 만든 한국어 설명·Windows PS1 줄바꿈만 인증
- `Update` 인증 실패 시 데이터 삭제가 가능한 재설치로 전환 금지. 기존 지식·설정·실행 기록 보존
- [감시 전환](../../crates/hive-cli/src/usage_monitor/upgrade.rs)을 새 사용자 갱신 실행 파일에 연결. 기존 활성 선택, 사건·수동 재개 기록 보존
- 활성 감시의 고정 실행 파일·정확한 예약 작업 교체 뒤 실제 제어부와 네 정상 관측 확인. 실패 시 오류·미완료 기록, 이전 위험한 개발 실행 파일의 자동 재실행 없음
- 비활성 선택은 비활성 유지. Codex 미실행 시 새 제어부의 대기 상태만 확인, 정상 관측 완료로 오표시 금지
- `status`: 설정과 실제 실행 생존·버전·관측 경로·실패 원인·공백·전환 결과 구분
- 자연어 감시 해제는 [기존 Skill](../../harness/skills/usage-guard/SKILL.md)의 `disable` 대행. 일반 하한 해제와 구분, 비프로젝트 폴더도 허용, 사용자 PowerShell 입력 불필요
