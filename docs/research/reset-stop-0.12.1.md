## 실패와 복구

- [초기 후속 검사](../../tests/results/runs/20261015T065723-90a7eccf9c5b.md): 시험의 `unwrap_err`가 `ActionResult: Debug` 요구로 컴파일 실패. 오류 분기 추출로 수정, 최종 11개 통과
- [바이너리 잠금](../../tests/results/runs/20261015T070203-fc0036cd4e4e.md): 다른 CLI 검사와 동시에 같은 `hive.exe` 재작성 중 Windows 오류 5. 검사 종료 뒤 직렬 빌드 통과, 보호 권한 우회 없음
- [수용 준비](../../tests/results/runs/20261015T070723-8b99981889b5.md): Windows PowerShell의 `Get-FileHash` 명령 부재. .NET SHA256으로 교체 뒤 준비 통과
- 최초 Windows 표본의 문자열 오타·PowerShell 줄 연결 오류는 수정 뒤 4개 통과. 실제 앱에 종료 요청 없음
- 지침 읽기 예산 초과는 같은 보호 경계를 유지한 규칙 축약 뒤 해결. 예산 완화 없음

## 실제 앱 수용과 남은 범위

- `scripts/qualify-usage-monitor.ps1`: 별도 예약 검사기에서 격리 설치 → 과거 기준값 합성 → 실제 센서 관측 → 현재 앱 종료·결과 보존 → 시험 예약 작업 제거
- 시험 출력: `tests/work/usage-monitor-acceptance/20261015-reset-stop/result.json`. 실제 실행과 근거 검토 전 성공 처리 금지
- 합성 초기화와 실제 제공자 초기화의 구분. 현재 앱 종료 시 현재 대화도 중단하므로 코드·기록·커밋 뒤 마지막 실행, 사용자 수동 Codex 재시작 필요
- 코드 변경과 설치 승인 분리. 0.12.1 실제 사용자 설치·자동 시작은 버전별 명시 승인 대기
- 실제 장시간 추론·여러 실행의 동시 종료·관측 불응 알림·재시작 차단은 해당 실제 수용 전 미검증. 합성 상태 검사로 승격 금지
- Linux·macOS·원격·클라우드 실행 미지원. 로컬 종료만으로 서버 처리·과금 즉시 종료 또는 새 할당량 1~2% 상한 보장 불가

- 실제 앱의 CIM 시각과 핸들 시각 정밀도 차이를 핸들 원본 시각 저장으로 보정. 현재 앱 읽기 전용 식별 시각의 왕복 일치 포함 Windows 표본 4개 통과
