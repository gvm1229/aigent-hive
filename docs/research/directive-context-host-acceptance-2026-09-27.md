# 0.11.0 실제 호스트 수용 판정

- 대상: Windows 11, 앱 동봉 Codex 0.158.0-alpha.2, 기본 모델 gpt-6-astra, 공개 0.11.0-test.9 실행 파일
- 소유: DCR-006의 실제 호스트·비용 수용. [공개 패키지 수용](0.11.0-test9-qualification.md)과 별도 판정
- 실행 방식: 같은 모델·자료·요청의 복원 없음/전체 문구/선택 구절 비교. 고정 보호 검사는 동일하게 유지, 시작 안내만 시험 제어기로 선택
- 자료: 실제 소스 지침과 고정 합성 과제. 원문 대화·숨은 추론·훅 본문 저장 없이 사건·사용량·파일 결과만 확인

- 세 조건 각각 고정 과제 5개 기준 전부 충족. 선택 구절이 전체 문구보다 나빠지지 않은 표본이며, 모든 작업·모델에서의 준수율 보장은 제외
- 실제 같은 대화 재개 3회: 각 재개 안내 전달과 누적 RESUME 표식 추가·기존 USER-CONTENT 보존 확인
- 실제 하위 작업 3개: SubagentStart 안내 각각 2,537바이트, 서로 다른 사용량 문맥 3개, 하위 작업과 상위 작업의 완료 사건 총 4개 확인
- 하위 작업별 JSON 파일 3개에 기존 내용 보존·재개 표식 3개 확인 결과 기록. 실제 파일 생성 사건과 파일 바이트를 별도로 대조
- 수집기의 이전 agentsStates 필드는 새 subAgentActivity 형식의 세부 상태를 담지 못한 한계. 종료 사건·서로 다른 사용량 문맥·파일 생성·정확한 파일 값으로 독립 확인, 누락 필드를 임의로 채우지 않은 판정
- [독립 오프라인 판정](../../tests/results/runs/20260926T150433-d0a98d924a40.md), [정규화한 결과](../../tests/results/readiness-host-acceptance-2026-09-27.json)

## 입력 비용과 지연

- 같은 요청의 첫 입력: 복원 없음 23,518, 전체 문구 25,757, 선택 구절 24,044토큰
- 공통 기준 비용을 뺀 새 안내: 전체 2,239, 선택 526토큰. 선택 비용 약 76.5% 감소로 초기 50% 목표 충족
- 조건별 고정 과제 1개, 실제 호스트 입력 수치에 근거한 범위. 전체 대화·캐시·과금 절감률과 보편적 성능 향상은 미증명
- [공개 실행 파일 지연](../../tests/results/runs/20260926T151414-de7845da20d4.md): 조건별 준비 5회·교차 측정 30회. 정상 편집 p95 194.55→194.75ms, 증가 약 0.10%로 10% 목표 이내. 모든 정상 응답은 빈 결과, 실제 파일 변경·모델 호출 없음
- 위 지연은 생성된 PowerShell 훅 명령만 대상. 모델·앱 전체 응답 시간의 증명 제외

## 시험 제어의 실패와 보존

- 최초 조건은 입력이 40,000 기준에 못 미쳐 실제 압축 0회. [실패 기록](../../tests/results/runs/20260926T145225-ac381ff88dee.md) 유지, 세 조건 모두 관측 입력량에 맞춘 30,000 기준으로 재시험
- 최종 상위·하위 작업이 완료된 뒤 누적 보고 입력 1,137,263토큰 확인. 계획 1,000,000보다 137,263개 초과해 실행기 종료 1, 추가 모델 실행 중지
- [예산 초과 실행 기록](../../tests/results/runs/20260926T145406-8417fe21f7bc.md)은 실패 상태 유지. 제품 동작 기준은 이미 수집된 호스트 사건·파일을 별도 결정적 검사로 확인한 결과
- 사후 사용량 집계는 큰 하위 작업 단계의 초과를 사전에 막지 못한 한계. 엄격한 토큰 상한이나 검증형 실행기의 예산 준수 성공으로 제시하지 않는 범위
- 유지관리자 결정: 이 시험 예산 초과는 0.11.0 출시 차단 사유에서 제외. 측정 조건에 따른 토큰 집계 차이를 고려해 실제 사용에서 추가 관찰. 제품의 사용량 보호 해제나 향후 시험 예산 면제와는 별개

## 정리와 출시 경계

- 시험 훅 정의의 승인 지문 대조 후 원래 부재 상태 복원. 합성 자료·실패 기록·판정 결과 보존, 사용자 전역 신뢰 기록 변경 없음
- 소스 루트의 임시 훅·문맥 설정 부재 확인. 추가 시험 모델 실행 없음
- 소스 계획 절차의 수용 근거이며, 초기화·검증 영수증 없는 Hive 실행을 활성 또는 성공으로 주장하지 않는 경계
- DCR-006 실제 수용 기준 충족. 정식 게시·main 통합·안정판 태그·사용자 설치는 별도 승인 단계
