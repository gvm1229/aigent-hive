## 실패와 한계

- 초기 Codex CLI 시험: 잘못 지정한 시험 셸 경로로 관측 도구 실패. 경로 수정 후 CLI의 파일 읽기가 호스트 정책으로 차단, 편집·시험 미실행. 권한 확대·정책 해제 제외
- 별도 지원 경로인 현재 Codex의 네이티브 하위 에이전트로 합성 소비자 시험 수행. 앞선 CLI 실패를 통과로 변경하지 않는 별도 근거
- 정상 구성 시험의 추가 사용자 루트 단독 lint: 합성 설정에 Wiki 기본 폴더가 없어 종료 5. 해당 등록 프로젝트를 대상으로 한 지침상 올바른 lint는 오류·경고 0건. 완전한 사용자 설치 수용의 증명 제외
- 동시 빌드 중 Windows 실행 파일 잠금으로 시험 시작 실패 1회. 기존 시험 종료 후 순차 재실행 통과
- 전체 Python의 첫 문서 검사: 새 사실 목록 누락·옛 출처 지문 실패 후 수정. 다음 전체 검사: 문구 대소문자·이전 스킬 지문 고정 시험 실패 후 수정
- [수정 후 관련 42개](../../tests/results/runs/20260922T213618-7c85c8b92147.md): 40개 통과·2개 제외. Windows의 비관리자 심볼릭 링크 권한·POSIX 전용 FIFO 조건 제외, 제품 거부 완화 제외
