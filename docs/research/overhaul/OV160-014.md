# OV160-014a 갱신 인증과 공개 갱신 CI

## 변경

- `parse_three_part_version`와 반환 오류 형식의 crate 내부 공개 범위
- Claude 마켓플레이스 렌더링의 버전 인자 분리, 검증된 틀 목록 `0.15.0`–`0.15.3`
- Antigravity 입력·저장 인증 범위 `1.1.18` 이상, `2.0.0` 미만
- Antigravity 0.15.2 이상 설치 기록의 호스트 범위 `>=1.1.7 <2.0.0` 적용, 이전 기록 범위 유지
- 0.15.3 사용자 설치의 갱신 인증 회귀 시험과 이전 코드 실패 재현
- 공개 갱신 시험의 안정판 기준 동적 선택, 0.15.x 공개 이미지 지문 추가
- 수용 워크플로 버전 고정 제거와 고정 이유 검사

## 0.15.2→0.15.3 통과 기록 조사

- 0.15.2·0.15.3 태그의 Claude 렌더 함수 모두 실행 제품 버전을 마켓플레이스 JSON에 기록하고, 이전 인증 함수는 고정된 0.7.0 지문과 비교
- [OV153-010 test.3 기록](OV153-010.md): `0.15.3-test.2`에서 `0.15.3-test.3`으로 갱신. 두 패키지의 제품 버전은 모두 0.15.3이며, 당시 `latest=0.15.2`는 npm 안정판 태그
- 따라서 해당 통과는 0.15.2 제품 사용자 설치에서 0.15.3으로 투영을 갱신한 증거가 아님
- [OV160-012 진단](OV160-012.md): 실제 0.15.3 설치 기록의 Claude 지문이 고정값과 불일치. 기존 시험 보조 함수도 실제 marketplace 메타데이터를 기록하지 않아 회귀를 놓친 상태
- 결론: “0.15.2→0.15.3 사용자 설치 갱신 통과”를 입증하는 근거 미발견. 기존 기록으로는 시험판 실행 파일 갱신만 확인
