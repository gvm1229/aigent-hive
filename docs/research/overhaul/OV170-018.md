# OV170-018 — 디자인 묶음 주간 동기화 적용

- 기준일: 2026-11-28, 실행 장소: cloud 세션

## 변경

- `harness/upstream/UPSTREAM.lock`에 디자인 원본 네 개 등록(`used_by: design-curate`, hallmark는 `ai-slop-cleaner`와 공유)
- 동기화 PR 본문(`scripts/sync-upstream.py --pr-body`): 바뀐 원본마다 이전·새 commit, 추가·수정·삭제 수, 사용 Skill, 그리고 `design-curate/references/conflicts.md`에서 그 원본을 인용하는 충돌 판정 주제를 "Revisit conflict ruling"으로 나열
- 주간 워크플로가 동기화 뒤 `scripts/sync-user-plugin.py`를 실행해 Skill 사본과 생성 Rust 목록까지 한 PR에 포함
- 사용자 컴퓨터의 주간 확인 명령 없음. `hive design status`는 동봉 원본과 고정 commit을 읽기 전용 표시, 갱신은 Hive 업데이트로 전달

## 확인

| 항목 | 결과 |
| --- | --- |
| 이전 commit 고정 시험 | 로컬 bare 저장소에서 원본을 한 번 고정한 뒤 새 commit을 올리면 확인 모드가 `changed`, 수정 파일 목록, 그 원본의 충돌 주제, PR 본문의 "Revisit conflict ruling" 표시 |
| 실제 판정 파일 | hallmark → 라벨·글꼴·색·모션·밀도·카드·스크립트 주제, impeccable → 밀도 등, OMC 원본은 주제 없음 |
| 실제 원본 | `--check` 다섯 원본 `unchanged` |
