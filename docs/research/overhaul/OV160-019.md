# OV160-019 — local 확인 입력 수집

- 실행 환경: Codex, Windows PowerShell
- 범위: 호스트 확인 입력 자동 수집, 판정 기준
- 스크립트: `scripts/qualify-local-hosts.py`
- 출력 입력: Hive 버전, 사용자 설치 확인, 격리된 사용량 확인, Skill 이름, 훅 미리보기, 흐름 미리보기 지원 여부, 등록 프로젝트와 대상 디스크 항목
- 쓰기 경계: 사용량 명령의 사용자 루트·대상은 `tests/work/` 임시 폴더, 그 외 Hive 호출은 읽기 전용 옵션
- 판정: 스크립트의 verdict 필드 없음, 종료 코드는 수집 성공 여부만 표시
- 분류 규칙: 기본 `product-defect`, 사전 기록 또는 Hive 외부 재현 근거가 있는 경우에만 `host-limit`, 안정판 통과 확인의 퇴행은 `product-defect`, 새 한계의 COMPAT·결정·출시 안내 기록
- 가짜 Hive 시험: 2개 통과, 호출 결과 입력 보존과 판정 필드 부재 확인
- 실제 실행: Windows PowerShell에서 버전·Codex 설치 확인 통과, 격리 사용량 확인 exit 0(`hive.usage-not-configured`), 훅 미리보기는 소스 작업공간 보호로 차단
- 실제 실행 한계: 소스 작업공간을 소비자 프로젝트로 확인할 수 없어 훅 결과는 미검증. `flow start` 미리보기 선택지는 설치 CLI에 없어 실행 미지원
- 프로젝트 비교 입력: 등록 16개, 대상 작업공간 바로 아래 `.hive` 프로젝트 0개, 전체 디스크 목록 확인 범위 제외
- 판정 결론: 없음, 판정은 스크립트 범위 밖, 사용자 판정 입력만 기록
