# OV170-035 — 세션이 안내를 그대로 전달

- 기준일: 2026-11-29, 실행 장소: cloud(지침·Skill). 실제 세션 확인은 [local 인계](OV170-035-local.md)

## 변경

- 사용자 지침 표시 블록(영어·한국어): Hive 쓰기 명령 뒤 최종 응답에 신 호출 안내를 고치지 않고 포함. 사람용 출력의 안내 블록 또는 JSON `notice` 값. 개수만 말하기 금지
- `knowledge-capture` Skill 7단계: 쓰기 결과의 `notice`를 그대로 보고. 조회는 결과를 실제로 쓴 경우만 `Apollon called · used N related knowledge entries` 한 줄
- 이 Skill은 Hive 원본·사용자 플러그인·프로젝트 템플릿 투영에 같은 바이트로 반영

## 확인

| 항목 | 결과 |
| --- | --- |
| 지침 단위 시험 | 두 언어 블록에 `notice` 규칙 |
| Skill 투영 | `scripts/sync-user-plugin.py` 뒤 세 투영 동일 |
