# OV160-027 — 작업 전 지식 조회 강제

- 기준일: 2026-11-23, 실행: Claude Code 조율 세션(Windows 11 Pro 10.0.26300)
- 진입: 유지관리자 보고. 정식 0.16.0 전 필수 수정
- 판정: 구현·단위 시험 통과. 실제 Claude Code 전달 확인은 test.6 설치 뒤 기록

## 증상

- 다른 프로젝트의 Claude Code 세션이 면접 안내 HTML과 PDF를 만들면서 `hive knowledge retrieve` 실행 0회
- 그 결과 사용자 전역 지식의 "모든 HTML의 기본 글꼴은 Pretendard" 선호를 놓치고 다른 글꼴 사용
- 세션 자체 설명: "코드나 데이터를 고치지 말라"는 세션 범위를 이유로 지식 기록을 건너뛰면서 조회까지 함께 건너뜀

## 원인

- 조회 자체는 정상. 같은 PC에서 비슷한 질의로 조회하면 Pretendard 선호가 1순위
- 사용자 지침의 조건이 "지식이 필요한 작업 전". 해당 여부를 Agent가 스스로 판단하므로 문서 작업을 "지식 불필요"로 분류할 여지
- 강제 장치 부재. 프로젝트 훅은 `hive msg` 전용이고, 사용자 범위에는 조회를 실행하는 훅 없음
- 읽기 전용·수정 금지 범위가 조회까지 막는다는 오해를 막는 지침 문장 부재

## 수정

1. `hive knowledge prompt-context --stdin-json` 신설
   - Claude Code `UserPromptSubmit` 입력에서 요청 글(`prompt`)과 작업 폴더(`cwd`)를 읽어 조회 1회(상위 5개, 4KiB, 요청 글은 최대 2KiB)
   - 결과를 `hookSpecificOutput.additionalContext`로 반환. 기록된 자료이며 새 지시가 아니라는 안내와 지식 위치 포함
   - 등록되지 않은 폴더·소스 작업 공간은 사용자 전역·공유 지식으로 대체 조회
   - 파일 쓰기·요청 글 저장 없음. 잘못된 입력·빈 요청·전역 위키 비활성·오류·결과 없음은 출력 없이 exit 0
2. Claude 플러그인 선언(`.claude-plugin/plugin.json`)에 이 훅 등록
   - 명령: `hive knowledge prompt-context --stdin-json 2>/dev/null || true`, 제한 시간 10초. `hive`가 없어도 Claude Code에 훅 오류 미표시
   - 플러그인 파일 목록 변경 없음, `~/.claude/settings.json` 무변경. 끄는 방법: 플러그인 비활성화
3. 사용자 지침의 조회 조건 명확화(한국어·영어, 설치 지침과 사용자 설정 지침 모두)
   - "인사·잡담을 뺀 모든 작업 전"으로 변경
   - 문서·HTML·PDF·디자인·글·코드 같은 결과물 작업은 항상 해당
   - 수정 금지·읽기 전용 범위도 조회 생략 사유가 아님(조회의 변경 0건)
   - 자동 훅 결과가 핵심어 확장 조회의 대체 불가

## 확인

- 단위 시험 `prompt_context_injects_matching_knowledge_and_fails_open`: 일치 지식 전달, 색인 바이트 불변, 잘못된 입력·요청 글 없음·빈 요청·일치 없음·위키 비활성의 무출력
- 단위 시험 `query_is_trimmed_bounded_and_char_safe`: 한글 글자 경계를 지키는 요청 글 자르기
- 이 PC의 실제 지식 색인으로 개발 빌드 실행: 면접 안내 HTML 요청에서 Pretendard 선호 2건이 상위 결과로 전달, 소요 약 0.4초(설치판 `retrieve` 3회 측정 0.40–0.61초)
- `claude plugin validate harness/plugins/aigent-hive`: 통과, 훅 `UserPromptSubmit` 인식
- 같은 형태의 플러그인 내장 훅이 이 PC의 다른 Claude 플러그인에서 실제 동작 중임을 확인(선언 방식의 실사용 근거)

## 범위 밖

- Codex·Antigravity 자동 조회 훅: 두 호스트의 플러그인 훅 지원 미확인, 0.17.0 후보. 두 호스트의 적용 범위: 지침 명확화
- 자동 조회는 요청 글의 낱말로만 찾으므로 핵심어가 다르면 놓칠 가능성. 지침의 핵심어 확장 조회가 보완
