# OV151-011 등록부 기반 과거 플러그인 포함

- 선택: P4 권고안. 버전별 수동 배열 제거, project-bases/registry.yml의 사용자 원본 등록을 빌드 입력으로 사용. 이유: 새 원본 등록과 실행 파일 포함 목록의 누락 방지
- 재사용: 기존 파일 수집·정렬·SHA-256·include_bytes 생성 그대로 유지, hive-render 빌드의 등록부·순서·원본 검증 방식 적용
- 경계: 0.9.0부터의 플러그인 형식 20개. 0.7은 사용자 플러그인 없음, 0.8은 기존 별도 어댑터 읽기 유지. 역사적 시험판 폴더·원문 변경 없음
- 검사: 엄격한 버전·정렬·중복·필수 등록·실제 폴더 누락·안전한 상대 경로·연결 경로/Windows 재분석 지점·비정규 파일 거부
