# OV160-016 보존 재설치의 백업 먼저와 삭제 허용 목록(핵심)

- 기준일: 2026-11-21, 실행 장소: local 세션(Windows 11), 구현: Claude 조율 세션(Codex 진행분 일부 재사용, 브랜치 `fix/ov160-016-transactions`)
- 계획: [재계획 OV160-016](OV160-replan.md#ov160-016-설치-거래-통합과-삭제-허용-목록s-b). 범위 축소: 데이터 손실을 직접 막는 핵심만 이 항목, 나머지는 [OV160-023](../../plans/active/0.16.0-local-fixes.md)

## 변경

- `execute_preserving_reinstall`: 제거 전 사전 백업. 대상: `projects.yml`·`collections.yml`·`user-setup.yml`·`user-feature-answers.yml`·`user-preferences.json`·`rag-trust.json`·`.hive/roster.toml`·사용량 감시 `config.json`·`disable.json`·호스트 안내 파일(`.claude/CLAUDE.md`·`.codex/AGENTS.md`·`.gemini/GEMINI.md`, Claude 호스트면 `.claude/settings.json`)·세 호스트 설치 기록·사용자 투영 기록. 위치 `.hive/backups/user-install/<host>/<시각>-<pid>-<난수>/`(기존 설치 백업 형식 `UserBackupManifest`), 결과 `data.preinstall_backup`과 `changed_paths`에 표시
- 재설치 전용 삭제 허용 목록 `REINSTALL_REMOVABLE_TREES`(`install`·`install-transactions`·`marketplaces`·`plugins`·`index`·`guides`)·`REINSTALL_REMOVABLE_FILES`. `projects.yml`·`.hive/runtime`·`.hive/backups`·`.hive/claims`는 재설치에서 삭제 금지. 사용자 제거 명령의 기존 목록은 변경 없음
- dry-run `preserved`에 위 보존 경로와 `backup_transaction_planned: true`
- 오류 종류 `hive.backup-too-large`(백업 512MiB 초과 시 변경 전 실패), `hive.user-install-prior-not-adoptable`(OV160-023 채택 흐름용 예약)
