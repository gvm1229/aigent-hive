- 대상: 사용자가 자기 구독 계정으로 공식 CLI를 실행하고, 외부 도구가 `send-keys -l`로 질문을 넣고 `capture-pane`으로 답변을 읽는 구성. 제공자 API·새 로그인·인증 파일 접근 제외
- 판정 기준: `permitted` 허용, `not permitted` 불허, `unclear` 불명확. 공식 기능의 존재와 외부 자동 입력의 약관 허용을 구분. 명시적 허용 근거가 부족한 부분은 불명확
- 한계: 개인 구독을 전제로 한 공개 자료 검토. 실제 계정 계약·개별 서면 허가 확인 없음. 아래 판정은 근거에 대한 작업상 해석, 제공자의 법적 확답과 구분
