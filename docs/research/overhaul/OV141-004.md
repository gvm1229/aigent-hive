# OV141-004 근거 — 공통 지식 연결 상태 수정

> 기준일: 2026-11-10
> 결정: [OV141-003](OV141-003.md)의 4건

## 변경

- ①·② `crates/hive-wiki/src/collection.rs`·`store.rs`: `CollectionRecord.explicitly_detached` 추가(기본 false, false면 저장 생략). `set_collection_attachment`의 해제는 true, 연결은 false. 동기화는 true인 연결을 해제 상태로 유지, 프로젝트 비활성화의 자동 해제는 false라 재활성화 때 복원. 연결 상태에 true가 붙은 기록은 검증 오류
- ③ `sync_project_registry`: 잠금 안에서 현재 `projects.yml`을 다시 읽어 호출자 목록과 다르면 `Conflict`. `shared::sync_current_project_registry`가 목록을 다시 읽어 최대 3회 시도. CLI `ensure_rag_registry`와 `rebuild_shared_index`가 사용
- ④ `hive_wiki::prepare_ingest`: 원본·초안의 읽기·빈 값·자격 증명·초안 형식 검사. CLI `run_ingest`는 공유 준비 전에 검사하고, `ingest_shared_prepared`로 같은 바이트 사용. 억제 목록 등 상태 의존 검사는 기존처럼 잠금 안에서 실행
