# OV141-006 근거 — 미완료 감시 갱신 복구(축소 범위)

> 기준일: 2026-11-10
> 상태: 2026-11-11 사용자 결정으로 진단 표시까지 0.14.1에 포함, Windows 재현·추가 복구는 [백로그](../../plans/backlog/monitor-upgrade-recovery.md)

## 원인 조사

- 오류 문구 "Windows monitor adapter failed"는 `crates/hive-cli/src/usage_monitor/platform.rs`의 `call`에서 PowerShell 어댑터가 0이 아닌 종료 코드를 낼 때 기록. 어댑터 오류 원문의 의도적 폐기로 실패 단계(`inspect`·`unregister`·`register`·`start`) 기록 부재
- `upgrade_with_choice` 순서: 사전 `inspect`(Codex 앱 확인) → 이전 작업 `unregister` → 설정 교체 → `register` → `start` → 준비 확인. `inspect` 실패는 아무 변경 전이라 다음 `hive update --apply`에서 재시도 가능. `unregister`·`register` 실패 시 설정은 이전 값으로 복원
- 재시도 경로: `user_install`의 갱신 성공 뒤 `upgrade_existing` 재실행. 같은 버전 갱신에서도 호출

## 이번 변경

- 어댑터 실패 문구에 단계 이름 추가(예: "Windows monitor adapter failed during inspect"). 원문 오류 기록 제외 유지
- 시험 `adapter_failures_name_the_step_without_native_text` 통과, clippy 통과, [usage_monitor 시험](../../../tests/results/runs/20261110T180139-9f25250ef3f1.md) 101개 통과(이 컨테이너에서 멈추는 `activation_phase_recovery_preserves_one_registration_and_start` 제외)

## 백로그로 이동한 일

- 격리 Windows 사용자 폴더에서 `phase: incomplete` 재현과 단계 확인, 필요한 복구 구현. Linux 클라우드 세션에서는 PowerShell·작업 스케줄러 실행 불가
