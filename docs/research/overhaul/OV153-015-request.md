# OV153-015 요청 — CLI 입력 오류 추천과 도움말 재작성

- 기준일: 2026-11-19. 유지관리자 local 세션 요청(원문 영어, 요지 번역)
- 환경: Aigent Hive 0.15.2, Windows 11

## 보고

- 유지관리자: `hive install`로 시작하는 명령인 줄은 알았지만 플래그를 몰라 `hive --help`를 열었더니 읽기 어려운 긴 글(65줄의 명령 형식 나열)이라 포기. 같은 일 여러 차례 반복
- 현재 동작: `hive instal` → "Unknown command: instal", `hive install --flags` → "Unknown option: --flags", 두 경우 모두 "--help로 사용 방법을 확인" 안내만 있음. 추천 없음

## 범위(0.15.3 필수)

- H1 오타 추천: 알 수 없는 명령·하위 명령·옵션이면 AI 없이 알고리즘(편집 거리·접두어 일치)으로 가장 가까운 후보를 "혹시 이것인가요?" 형식으로 제시. 후보는 실제 명령 표에서만, 최대 3개, 거리 기준 밖이면 추천 없음
- H2 다음 행동: 추천과 함께 바로 실행할 수 있는 완성 예시 1개(필수 옵션 포함)와 그 명령의 짧은 도움말 위치(`hive install --help`) 표시. 필수 옵션 누락이면 누락된 옵션 이름과 예시를 표시
- H3 도움말 재작성: `hive --help`는 목적별 묶음(시작하기·설정·지식·갱신·진단·고급)과 명령마다 한 줄 설명의 짧은 목록, 자세한 형식은 `hive <명령> --help`로. 주요 명령(`install`·`setup`·`update`·`knowledge`·`usage`·`project upgrade`)은 자체 `--help`에 설명·필수/선택 옵션 표·예시 2개 이상
- H4 언어: 저장된 언어(ko 기본)로 표시, `--output json`은 추천을 `data.suggestions`·`next_action`으로
- H5 에이전트 안내: 사용자 질문에 답하는 Hive Skill(예 `quick-answer`·설정 Skill)이 같은 도움말 구조를 가리킴
- H6 시험: 오타 명령·옵션의 추천 결과, 추천 없음 경계, 필수 옵션 누락 안내, 도움말 스냅샷(80열 줄바꿈 없음), JSON 출력 형식
