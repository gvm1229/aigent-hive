## OVX-009 권고 보존

- 검토자 권고 (b): 공식 확장점만 사용, 키 입력 주입·화면 긁어 읽기 제외. 제공자 서면 확인은 주 작업을 막지 않는 별도 조사
- 상태: 검토자의 후속 범위 제안만 보존. OVX-009 선택·초안·승인으로 취급 금지, 기존 OVX-005–007 차단 상태 변경 없음

## 실행 순서와 완료 기준

1. M1: 기존 고정 30종 입력을 추적 표시 파일·기대표로 보존, 빈 사례는 측정용 빈 디렉터리로 분리. 추적 입력에서 설치 Hive 0.14.2 질문 30회 재측정, 숫자 확인 후 개별 커밋
2. M2: 기존 JSON 그대로 추적, 방해 사실 원문 5개·실패 진단·보류 n=10 추가. JSON 구조·문체 확인 후 개별 커밋
3. M3·M4: 실행 방식을 OVX-009 대기 제안으로 표시, 02의 현재 절·행만 정정. 지적별 개별 커밋
4. 낮은 지적: OVX-004 집계 방식 기록, OVX-005 로그인 셸의 명령 경로만 재확인. 항목별 개별 커밋
5. 부록 A: 공식 웹 문서만 열람, 기능별 구독 로그인 근거·불명확 부분·확인일 표시. 정책 날짜와 함께 개별 커밋
6. 마무리: 근거 SHA-256·Source Wiki 사실 갱신. documentation·문체 `--all`·계획 상태·Source Wiki lint·branch-policy 확인 후 결과 기록·커밋·단계 브랜치 push·원격 HEAD 확인·세션 기록 제거

- 중단 조건: 사용자 중단·설치된 사용량 보호 차단·새 권한이 필요한 작업. 외부 자료 부족은 해당 표의 미확인으로 한정, 독립 보완 지속
- 검증 한계: 문서와 고정 입력의 재현성 확인. 실제 제공자 실행·모델 호출·Linux/macOS 제품 동작의 증명 제외
