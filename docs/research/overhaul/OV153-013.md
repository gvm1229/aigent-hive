# OV153-013 — 변경 0건 프로젝트의 갱신 검증 실패

- 기준일: 2026-11-17, 실행 장소: cloud 세션. 이 PC 재현(B5)은 [local 인계](OV153-local-handoff.md)
- 요청: [요청 원문](OV153-013-request.md)
- 브랜치: `fix/ov153-013-zero-change-upgrade`(OV153-011 브랜치 위), 독립 검토 뒤 `develop`에 병합

## 원인(B1)

- 재현: 사용자 설정 완료 상태에서 새 빈 프로젝트에 `--input-channel agent --apply` 뒤 `hive project upgrade --scan` → `hive.project-upgrade-available`, 보고 117개 전부 `unchanged`, `changed_paths`는 `.hive/config/project-overrides.json` 하나. `--validate`는 exit 5 `hive.update-release-verification-failed`
- 원인: 프로젝트 설정 단계의 로컬 변경 기록 파일(`project-overrides.json`) 미생성. 갱신 계획은 기록이 빈 경우에도 빈 기록 파일을 항상 생성 대상에 넣고, 파일이 없으니 "바뀐 파일"로 집계. 이 파일은 병합 대상이 아니므로 보고 목록에서도 누락
- 터미널 빠른 설정도 같은 작성 경로라 같은 결과

## 수정

- B2: 빈 변경 기록과 파일 부재는 같은 의미(`hive-render` `local_overrides::has_records`가 둘 다 기록 없음). 기록이 비어 있고 파일도 없으면 생성 대상에서 제외. 이미 있는 기록은 기존처럼 새 버전으로 다시 씀
- 결과: 변경 0건이면 `--scan`·`--validate` 모두 `hive.project-upgrade-current`, 검증 성공
- B3: 모든 변경 경로에 사유 하나를 붙여 결과 `data.change_reasons`(`path`·`reason`)로 표시. 사유는 `projection-content`, `setup-support-file`, `retired-support-file`, `project-base-ledger`, `project-override-ledger`, `legacy-derived-index-cleanup`. 사유 없는 변경 경로는 내부 오류로 중단(`change_reasons_for`). 지난 색인 정리 사유는 그 단계가 새로 넣은 경로에만
- 같은 내용은 기존에도 바이트 비교로 제외(`insert_exact_if_changed`, 병합 경로의 전체 바이트 비교). 이번 수정으로 예외 경로 없음

## 시험(B4)

- Rust `a_fresh_terminal_quick_setup_has_no_project_upgrade`: 터미널 빠른 설정 직후 갱신 계획의 변경 0건, 기록 파일 미생성
- 계약 시험 `test_fresh_agent_apply_has_no_project_upgrade`: 에이전트 적용 직후 실제 CLI `--scan`·`--validate`가 `hive.project-upgrade-current`, `changed_paths`·`change_reasons` 빈 목록, 대상 바이트 불변
- Rust `every_changed_path_needs_a_reported_reason`: 사유 없는 경로 거부
- 기존 `project_upgrade` 시험 62개와 프로젝트 수명 주기·Skill 투영 계약 시험 통과
