# OV170-014 — 남은 Skill 통합 검토

- 기준일: 2026-11-28, 실행 장소: cloud 세션(다섯 앱의 Skill 이름 표시는 local)
- 근거: 단계 6 검토 P1([stage-6-review](stage-6-review.md)). 범위: project-* 계열, setup 계열, team-execution, multi-goal. 이름 이전 최대 1회

## 측정

| 항목 | 값 |
| --- | --- |
| 내장 Skill | 33개(신 진입 10, 기능 23). 0.16.1의 31개에서 `design-curate`·`aphrodite` 추가, `verified-workflow`→`autonomous-workflow`, `code-polish`→`ai-slop-cleaner` 교체 |
| 묶음 | daily-work 29, web-developer 19, game-developer 20, non-developer 14 |

## 검토와 판정

| 후보 | 판정 | 이유 |
| --- | --- | --- |
| `project-setup`·`project-refresh`·`project-transition` | 유지 | 설정(새 프로젝트), 갱신(기존 지침 다시 쓰기), 이전(무결성 묶인 버전 이전 경로)의 권한과 부작용 등급 차이. 합치면 이전 경로의 확인 단계가 일상 갱신에 섞임 |
| `user-setup`·`project-setup` | 유지 | 전역과 프로젝트 범위의 대상 폴더 차이. 0.16.0에서 이미 질문 목록 하나로 정리 |
| `team-execution`·`multi-goal` | 유지 | 병렬 lane 조율과 목표 그래프 집계의 사용 주체 차이. multi-goal이 team-execution을 의존으로 사용 |

- 이름 이전: 0.17.0은 이미 두 Skill(`verified-workflow`, `code-polish`) 이름 변경과 두 Skill 추가가 있어, 추가 통합의 옛 이름 안내 부담은 보류. 이번 항목의 이름 이전 0회
- 옛 이름 안내: 0.17.0 두 이름 변경은 `retired-names.yml` lifecycle과 라우팅 `renamed_from`으로 확인([OV170-020](OV170-020.md)·[OV170-021](OV170-021.md))
