# OV170-030 — 버전 범위와 앞으로만 규칙

- 기준일: 2026-11-29, 실행 장소: cloud

## 규칙

- 범위: `[hive] range = "0.17"` 또는 `"0.17.x"`. 같은 `MAJOR.MINOR`의 새 판만 자동 적용
- 앞으로만: 기록 버전은 `project.lock`과 기준 장부 중 높은 쪽. 전역 Hive가 더 오래되면 쓰지 않고 경고(`hive.project-sync-older-hive`)
- 범위 밖: 쓰지 않고 경고(`hive.project-sync-out-of-range`). 사람이 범위를 올리면 다음 실행에서 적용
- lock 충돌: 충돌 표시가 남은 lock은 검사에서 실패. 적용 모드는 기준 장부와 `project.toml`에서 다시 계산해 덮어씀
- 한쪽만 바뀜: lock의 장부 지문·버전이 실제 기준 장부와 다르면 "다른 커밋에서 바뀜"으로 검사 실패
- 검사 전용: `hive project sync --target . --check`. 쓰기 0건, 문제가 있으면 종료 코드 5

## 확인

| 시험 | 결과 |
| --- | --- |
| 범위 안 갱신 | 0.16.1 고정물, 범위 `0.17`에서 `hive.project-synced` |
| 범위 밖 경고 | 범위 기본값 `0.16`에서 파일 변경 0건 |
| 오래된 Hive 쓰기 거부 | lock 버전을 `0.17.99`로 둔 뒤 파일 변경 0건 |
| 충돌 lock 다시 계산 | 검사 종료 5·쓰기 0건, 적용 뒤 원래 lock과 바이트 동일 |
| 한쪽만 바뀐 상태 | 장부 지문만 다른 lock에서 검사 종료 5 |
