# OVX-002 지식 회수 기준선

- 상태: 완료. 실행일 2026-11-12, Codex·Windows 11, 설치된 Hive 0.14.2
- 범위: 사용자 실데이터와 분리한 합성 사실 10개·방해 사실 5개, 한·영 질의 40개. 검색 결과 다섯 개 안에 정답 사실 포함 시 적중
- 결과: 회수율 Recall@5 22/40 (55.0%), 개발 19/30 (63.3%), 보류 3/10 (30.0%)
- 분리: 각 사실의 첫 세 질의는 개발 30개, 마지막 바꿔 쓴 질의는 보류 10개. 전 질의·정답·분리표를 첫 저장·검색 전 고정, 검색 결과에 따른 동의어·질의 확장·조정 없음
- 명령: `hive knowledge remember --user-root <temporary-user> --user-statement <fact> --claim-key ovx-<id> --kind preference --output json` 15회
- 명령: `hive knowledge retrieve --user-root <temporary-user> --target <temporary-user> --scope auto --query <query> --top-k 5 --byte-budget 16384 --output json` 40회
- 격리 위치: `tests/work/overhaul-2-baseline/retrieval-user/`. 실제 사용자 저장소 접근·설정 변경 없음
- 기본 검색 `fts`: 단어 검색. 별도 벡터 모형 다운로드·제공자 API 호출 없음. 한·영 의미 일치 검색과 실제 기억 품질 전체의 증명 제외
- 재현: [고정 입력 JSON](OVX-002-inputs.json)에 사실 10개·방해 사실 5개·사실별 질의 4개·분리 규칙 원문 보존. `retrieval.py`·원본 결과 JSON은 `tests/work/overhaul-2-baseline/`에 보존
- 검증: 저장 15개·검색 40개 종료 0, 정답 본문의 실제 반환 포함 여부와 질의 수·보류 수 검증. Linux·macOS 실행 없음
