## 변경

- 정본 `harness/skills/usage-guard/SKILL.md`: 핵심 절차·경계만 유지. 세부 절은 `references/control.md`의 절 이름으로 안내
- `references/control.md`: 대상 분류·자동 배정 사전 확인·설정과 수동 확인·경계 세부·Windows 중간 감시 절 추가. 옛 본문 문장 그대로 이동, 기존 제어 절 유지
- 새 reference 파일 없음. 출시 표면 목록·과거 표면 기록의 경로 변경 회피 목적
- 복사본 4곳과 `active-skills.yml.jinja` 해시는 `python scripts/sync-user-plugin.py`로 재생성
- hook 호출 확인: `harness/`·`crates/`·`scripts/`·`packaging/`·`tests/fixtures/`·과거 `project-bases`·`user-bases` 검색 결과 hook·Skill·템플릿·설치기의 `hive route`·`hive prompt` 호출 0건. 설치 hook은 `hive hook`만 호출
- 결정: 최상위 `hive route`·`hive prompt` 퇴역. 실행 없이 안내만 출력, 종료 코드 2. JSON은 `code=hive.command-moved`와 `next_action` 예시
- 새 `hive advanced route`·`hive advanced prompt validate|approve`: 기존 처리기 그대로 실행. `hive advanced`·`hive advanced --help`는 명령 형식 출력
- 신 이름 별칭 `hive artemis route`·`hive apollon prompt`는 `hive advanced` 경로로 연결
- 도움말 목록·오타 후보·도움말 스냅샷·Python 적합성 시험·`scripts/accept-verified-workflow.py` 호출 갱신. `test_roster_gods`의 신 이름 소유 명령 집합은 `hive advanced` 하위 명령 기준
- 인용 원본 변경에 따른 `docs/facts` 해시 갱신: `main.rs`·`tests/human_output.rs`·`control.md`·`accept-verified-workflow.py`
