# OV170-015 — Apollon⇄Demeter 일 맞바꾸기

- 기준일: 2026-11-28, 실행 장소: cloud 세션(계획 표기 local은 코드·생성물 작업이라 cloud로 진행, 실제 호스트 진입 Skill 확인은 OV170-009)
- 결정: Apollon은 지식(Horizon Zero Dawn의 APOLLO가 인류 지식 데이터베이스), Demeter는 글쓰기. 별칭 `Apollo`·`아폴로`는 계속 apollon

## 변경

- `harness/gods.toml`: apollon `knowledge`·`지식`·`hive-research-specialist`·명령 `knowledge, source-wiki, index`·Skill `knowledge-capture, knowledge-recall, knowledge-manage`. demeter `writing`·`글쓰기`·`hive-article-writer`·명령 `prompt, korean`·Skill `humanize-kor, prompt-refine`. 두 역할 단계 끝에 0.17.x 전환 안내 한 줄
- 생성: `python scripts/generate-gods.py`로 진입 Skill·Codex 메타데이터·`gods_generated.rs`·소유 문서·Skill 목록·활성 Skill 원장 갱신, `scripts/sync-user-plugin.py`로 호스트 사본
- 의존성: `apollon → [knowledge-recall]`, `demeter → [humanize-kor]`(`skill-suites.yml`·`user-setup/catalog.yml`)
- 옛 호출: `crates/hive-cli/src/gods.rs` 고정 전환표 `{(demeter, knowledge|source-wiki|index)→apollon, (apollon, prompt|korean)→demeter}`. 맞는 호출은 stderr에 "Since 0.17.0, <명령> belongs to <새 역할>"(한국어 설정이면 "0.17.0부터 <명령>은 <새 역할> 담당") 한 줄 뒤 새 담당으로 실행, JSON stdout 유지. 표 밖 조합은 기존처럼 오류. 0.18.0에서 표 삭제
