- E1 `project.rs`: 실행 기능 미검증 안내를 `UNVERIFIED_RUNTIME_NOTE` 두 줄로 분리(각 줄 80칸 이하)
- E2 `interactive.rs`·`project.rs`·`monitor_review.rs`: 마지막 확인에서 거절하면 결과 `data.declined=true`. `human_output.rs`는 이 결과를 실패 대신 변경 없음 안내와 터미널 이어가기 명령으로 표시. JSON `code`·`status`·종료 코드 2와 에이전트 경로(`next_action`) 유지
- E3 `terminal.rs` `checking_apps`: 프로젝트 대화형 설정 시작, 사용자 설정 미리보기 계산 전에 앱 상태 확인 중 안내 한 줄 표시. 고정 화면 2개 갱신
- E4 `host_windows.rs` `expand`: 앱별 5시간·주간 기준 질문의 기본값을 전역 `usage_guard.stop_remaining_percent`로. 저장된 앱별 값은 기존대로 현재값으로 유지
- E5 `user_install.rs`·`user_setup.rs`: 항상 적용되는 사용자 지침(한국어·영어)의 지식 저장 문장에 원자 사실 나누기, 사실마다 `--subject`/`subject`, 기존 주제 재사용(`subjects list`), `앞으로·항상·금지·기억` 같은 지속 선호의 필수 기록 추가
- E7 `project.rs`·`project/preferences.rs`·`messages.rs`: `--question`의 밑줄을 하이픈으로 해석(`project_kind` → `project-kind`). 모르는 질문은 가까운 질문 이름 추천
- E8 `summary.rs`: `--summary` 조합 거부 문구에 "Run the same command without --summary" 추가
