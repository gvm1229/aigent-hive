## 검토 뒤 변경

- OV153-003: 주제는 사실 ID 계산에서 제외, 같은 사실의 새 주제는 `update`(제자리 변경), 주제 없는 재기록은 no-op. `hive knowledge subjects list` 추가, 비슷한 철자 경고는 철자만 다른 경우로 한정, 주제의 자격 증명 검사
- OV153-004: 보이기 판정 뒤 사실 단위 최대 16개·최신 순, 첫 적중의 `subject_truncated`, 의미 검색 결합의 주제 보존
- OV153-005: `--expansions`는 `,` 구분, 접두 일치는 비ASCII 2자·ASCII 4자 이상
- OV153-006: 규칙 없는 사실은 제안 `null`, 미리보기 `--limit`·`--offset`, 최대 1,000개·중복 ID 기록 전 거부, 주제 밖 필드 변경 거부, knowledge-maintain Skill 절차

## 결정

- 주제 이전은 읽기 호환: 0.15.2 이하가 쓴 사실은 다시 쓰지 않고 그대로 유효. 주제가 붙은 사실은 schema 2라 0.15.2 이하가 저장소 전체를 거부(하위 버전 되돌림 미지원, 출시 노트 COMPAT-03)
- 묶음 기록은 user-root 사용자 발화만. 검토 artifact·다른 범위는 기존 `--request` 1회
- 주제 부여 모델 판단은 호스트 소유. Hive는 규칙 기반 제안·검증·기록·복원만, 모델·제공자 호출 없음
- 접두 일치는 검색 질의 쪽만 변경. 색인·정본 바이트와 Wiki 페이지 질의는 그대로
