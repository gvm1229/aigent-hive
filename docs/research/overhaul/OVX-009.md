- 범위: 단계 2 브랜치의 결정·소스 지침·미래 단계 계획 문서. 제품 0.14.2 유지

## 선택과 경계

- 선택: 공식 문서의 확장점만 사용. 사람이 앉아 쓰는 Claude Code와 Codex·Gemini 비대화형 작업자, 파일 수신 상자·훅 연결
- 이유: 창 자동 입력·화면 읽기의 세 제공자 약관 허용 미확인. 제공자 서면 확인은 비차단 별도 조사
- 제외: OVX-010·develop 병합, 실제 제공자 CLI·모델 실행, `claude -p`, 전역 호스트 설정·인증 변경, 지정 미추적 문서 두 개 변경·추적
- 작업 완료 조건: 아래 문서 반영·검사·관심사별 커밋·단계 브랜치 push와 원격 HEAD 일치. 단계 3 실험의 실제 성공과 구분
