# OVX-001 프로젝트 판별 기준선

- 상태: 완료. 실행일 2026-11-12, Codex·Windows 11, 설치된 Hive 0.14.2
- 범위: 표시 파일만 둔 독립 프로젝트 30종. 현재 CLI 질문의 기본 `project_kind` 관측, 실제 자동 판별 기능 존재 주장 제외
- 결과: 기본 `general` 30/30, 비율 100%. `effective=null` 30/30, 자동 선택 결과 없음. 제시 선택지 `general`, `custom` 두 개
- 원인 근거: `crates/hive-cli/src/user_setup/setup_engine/project/questions.rs`의 `defaults`에 고정 `general`, 신규 답안의 project_kind 수동 필수
- 기대 열: 앞으로 필요한 구분을 위한 정답표, 현재 제품이 약속한 선택지라는 뜻 아님
- 사용자 요청 우선 적용: 추적 fixture 추가 없이 `tests/work/overhaul-2-baseline/project-detection/`에 임시 코퍼스 구성. 제품 바이트 변경 없음
- 재현: 아래 표의 파일을 최소 내용으로 생성 후 각 경로에서 `hive setup --target <case> --user-root <temporary-user> --describe --question project-kind --output json`. 위 일회성 `measure.py`와 `OVX-001-inputs.json`에 정확한 입력·원본 JSON 보존
- 확인: 30개 명령 종료 0, 스크립트의 행 수·기본값·실효값 검증 통과. 내용 기반 자동 판별 정확도·Linux·macOS 미증명
