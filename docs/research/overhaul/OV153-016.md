# OV153-016 — npm 설치 뒤 `hive update`의 이전 버전 투영 인증

- 요청: [OV153-016 요청](OV153-016-request.md). 실행: local 세션, Windows 11
- 변경: `crates/hive-cli/src/user_install.rs`, `user_install/deactivation.rs`, `user_install/host_state.rs`

## 수정

- C1·C2 `authenticate_saved_projection_host`: 제품 버전이 다르면 `authenticate_prior_release_projection_host`로 설치 경로와 같은 기준(`authenticated_user_inventory`, `validate_manifest_against_authenticated_inventory`, `validate_authenticated_installed_bytes`)을 적용. 같은 제품 버전이면 기존 엄격 확인 뒤 실패 시 같은 이전 판 인증으로 재시도, 둘 다 실패하면 기존 오류 유지
- 같은 제품 버전의 다른 패키지(번호 시험판 → 다음 시험판·정식): `same_product_package_inventory` 추가. 설치 기록의 모든 경로가 실행 중 제품이 소유하는 경로·소유 종류·권한과 같을 때만 인증(새 경로 추가 허용, 낯선 경로 거부). 기존 `-dev` 빌드 인증과 같은 자기 일관성 검사에 경로 제한 추가
- 위조·변조·해석 불가 기록은 계속 실패
- C5 Claude 마켓플레이스 제거 3곳(`remove_host_activation`, 비활성화, 조정)에서 `--scope user` 제거. 이미 범위 없이 지우던 잔여 등록 정리 경로와 같은 방식
- C6 `execute_uninstall`: 모든 호스트 활성화 제거 뒤 파일 삭제. 실패 시 오류 종류 유지, 메시지에 `hive install --scope user --hosts <제거된 호스트> --apply` 추가

## 시험(Windows 11, 이 PC)

- `cargo test -p hive-cli --bin hive authenticated_saved_projection`: 6 통과(새 4: 이전 판 인증·변조 거부·위조 판 거부, 같은 제품 다른 패키지 인증·낯선 경로 거부)
- `cargo test -p hive-cli --bin hive -- user_install update_activation uninstall`: 165 통과(C5 알려진 목록 전용 등록 제거, C6 뒤 호스트 거부 시 파일 보존 시험 포함)
- `cargo clippy -p hive-cli --all-targets -- -D warnings`: 통과(외부 vendor `process-wrap` 경고만), `cargo fmt --check` 통과
- 이 PC 실제 Claude CLI 2.1.325: 범위 있는 제거 `not_configured` 확인, 범위 없는 제거 `ok` 확인
