## 변경

- 새 `crates/hive-cli/src/storage.rs`, `main.rs` 연결과 USAGE 2줄, `--help`
- `hive storage [--user-root P] [--output json]`: `.hive` 아래 일반 파일 바이트를 vector·index·knowledge·monitor-binaries·backups·other로 분류. 기호 링크 미추적, 변경 없음. 읽기 실패는 `hive.storage-read-failed`(종료 1)
- `hive prune --dry-run|--confirm`: `usage_monitor::prune_unused` 사용. 감시의 `control.lock` 안에서 설정(`config.json`)과 마지막 갱신 기록(`upgrade.json`)의 `from`·`to` 실행 파일 유지, 나머지 `hive-*.exe`만 후보. 설정이 없거나 읽을 수 없으면 거부(`hive.storage-prune-refused`), 삭제는 `.hive/runtime` 안의 바이트 일치 삭제. 사람용 출력은 삭제·건너뜀을 각각 표시
- 출력 접두 `[Hades]`
