# OV153-015 — CLI 입력 오류 추천과 도움말 재작성

- 기준일: 2026-11-19, 실행 장소: local 세션(Windows 11 Pro 10.0.26300, Git Bash)
- 요청: [요청 원문](OV153-015-request.md)
- 브랜치: `fix/ov153-015-cli-suggest`. 병합·게시 없음

## 변경

- H1 명령 표: `crates/hive-cli/src/cli_help.rs`의 `COMMANDS` 하나에 명령·하위 명령·옵션·예시·묶음·한 줄 설명. 분기 전 `precheck`가 표로 판정
  - 알 수 없는 명령: 명령·신 이름·`--help`·`--version` 후보 중 추천
  - 알 수 없는 하위 명령: 가까운 후보가 있을 때만 추천과 함께 중단. 후보가 없으면 기존 분석기 오류 유지
  - 알 수 없는 옵션: 어느 분석기에도 없는 옵션만 거부. 표 누락이 정상 명령을 막지 않게 하는 안전 장치
  - 추천: 편집 거리(이웃 글자 교환 포함, 3자 이하 1·6자 이하 2·그 이상 3)와 접두어(2자 이상) 일치. 최대 3개, 표의 실제 항목만
  - 문구: ko `혹시 이것인가요?`, en `Did you mean?`. 저장 언어 기준
- H2 다음 행동: 추천과 함께 필수 옵션을 포함한 완성 예시 1개(`hive install --scope user --hosts codex,claude --dry-run`)와 `hive <명령> --help` 표시. 하위 명령을 알면 그 하위 명령의 예시 우선
  - 필수 옵션 누락: 기존 안내에 누락 옵션 이름·완성 예시·명령별 도움말 위치 추가. `Missing --target` 형태도 인식
- H3 도움말: `hive --help`를 6개 묶음(시작하기·설정·지식·갱신·진단·고급, en 대응)과 명령당 한 줄로 재작성(65줄 → 50줄 안팎)
  - `install`·`setup`·`update`·`knowledge`·`usage`·`project upgrade`: 설명, 필수·선택 옵션 표, 예시 2개 이상, 전체 형식
  - `hive knowledge <하위 명령> --help`: 그 하위 명령 형식만 표시(기존에는 오류)
  - 80열 맞춤: 긴 형식 줄은 단어 단위 줄바꿈. 기존 명령 형식 줄은 모두 어느 `--help`에서든 확인 가능
- H4 JSON: 기존 결과 형식 유지(`UnknownAction`, 명령은 `hive.unknown-action`, 하위 명령·옵션은 `hive.invalid-input`). `data.suggestions`(배열)·`data.help_command` 추가, `next_action`에 예시. 후보가 없는 명령 오류는 `next_action: null`
- `hive doctor --output json`·`hive check-target <path> --output json`: 도움말이 보여 주는 대로 JSON 결과 지원(기존 `hive.unknown-action`). JSON에서는 식별 줄 생략, 사람용 출력은 그대로
- H5: `harness/skills/quick-answer/SKILL.md`에 Hive 명령 질문은 `hive --help`·`hive <명령> --help` 안내 추가. 설정 Skill은 이미 정확한 명령을 쓰므로 변경 없음(OV153-014와 충돌 회피)
