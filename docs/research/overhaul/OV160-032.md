# OV160-032 — 완료 알림의 실제 실행 모델 측정

- 기준일: 2026-11-25, 실행: Claude Code 조율 세션(Windows 11 Pro 10.0.26300)
- 진입: 유지관리자 보고. 정식 0.16.0 전 필수 수정
- 판정: 구현·단위 시험·test.8 공개·세 OS 수용·이 PC 확인 통과

## 증상

- test.7 완료 알림의 역할 줄이 `codex gpt-5.6-luna · max`처럼 Codex 모델 표시
- 실제 처리는 Claude 세션. 이 PC 시험에 Codex 모델 관여 0건
- 유지관리자 판단: 알림의 모델은 실제 측정값이어야 함. 역할 표는 제안일 뿐

## 원인

- 알림이 보낸 쪽 봉투에 적힌 역할 표 배정값을 표시
- 시험 폴더에 `.hive/roster.toml`이 없어 내장 기본값 `harness/roles/defaults.toml`(작업 공간 제공자 `codex`)이 적용
- 작업자가 실제로 쓴 모델의 관찰 경로 부재

## 수정

- `hive msg ack --worker codex:<세션 id>|claude:<subagent id>` 선택 인자
  - Codex: 사용자 루트 `.codex/sessions/<연>/<월>/<일>/rollout-*-<id>.jsonl`의 `turn_context` 항목에서 `model`·`effort`만 읽기
  - Claude: 사용자 루트 `.claude/projects/*/*/subagents/agent-<id>.jsonl`의 assistant 항목에서 서비스가 답한 `message.model`과 `effort`만 읽기
  - 마지막으로 보고된 값 사용. `<synthetic>` 같은 값과 이상한 문자 제외
  - id는 6–64자 영문·숫자·하이픈. 일치 파일이 0개나 2개 이상이면 측정 실패, 심볼릭 링크와 128 MiB 초과 파일 거부
- 측정 기록 `.hive/mediation/measurements/<message-id>.json`: 제공자·모델·추론 강도·출처·기록 파일 digest·측정 시각. 대화 본문과 파일 경로는 저장 대상 밖
- 측정 실패에도 확인증 유지. 결과에 `measurement_error` 표시
- 완료 알림의 역할 줄
  - 단일 메시지: `보낸 역할: <이름>`, `받은 역할: <역할> · 실행 모델: <측정값 또는 측정 안 됨>`
  - 흐름: 단계마다 `<신 이름> ▸ <단계 상태> · 실행 모델: <측정값 또는 측정 안 됨>`
  - 역할 표의 모델은 알림에서 제거
- 중재 참고 문서(네 사본)에 `--worker` 전달 방법 추가, 설계 지침 `02-architecture.md`에 규칙 한 줄 추가

## 확인

- 단위 시험: `--worker` 형식 검사, Codex·Claude 기록에서 마지막 모델·강도 추출, 사용자 루트 안 파일 찾기
- 단위 시험 `msg_ack_worker_measures_the_real_model_from_the_host_session_log`: 확인증 뒤 측정 기록 생성, 기록에 대화 본문·경로 0건, 알림 역할 줄 `실행 모델: Claude Opus 5.5 · high`
- 측정이 없을 때 `실행 모델: 측정 안 됨` 시험
