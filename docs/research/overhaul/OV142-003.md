- 51 MiB+17 바이트 정확 삭제·끝부분 변조·길이 변경 복구·Windows 삭제 공유 잠금은 [OV142-002](OV142-002.md)

## 미실행 범위

- Rust 5개 제외: 별도 동의가 필요한 실제 벡터 실행·4회 실제 센서 관측·50,000개 초과 비공개 자료 검사·SSD에서 release 모드로 수행할 규모 검사 2개. 현재 Windows 실행에서 해당 실제 관측·규모 성능의 증명 없음

- macOS/Linux 공개 수용·정식 0.14.2·실제 사용자 감시 정리는 미실행, 각각 OV142-007·008의 소유 범위
