# OV141-005 근거 — 감시 실행 파일 보관 2개 제한

> 기준일: 2026-11-10
> 브랜치: `fix/overhaul-1-0.14.1`

## 변경

- `crates/hive-cli/src/usage_monitor/upgrade.rs`: 감시 갱신 성공(`phase: complete`) 직후 `prune_binaries` 실행. `runtime/usage-monitor/bin/hive-*.exe` 중 현재(`next.executable`)와 직전(`old.executable`) 외 정리
- 각 파일을 읽은 바이트로 `remove_runtime`의 정확 삭제. 실행 중·잠긴 파일과 바뀐 파일은 건너뛰고 `skipped`에 이유 기록. 목록 실패 시 삭제 없음
- 결과를 `upgrade.json`의 `binary_cleanup`과 명령 결과에 기록. 정리 실패는 갱신 실패로 바꾸지 않음. `hive-`로 시작하는 `.exe`(대소문자 무시) 외 파일 유지
