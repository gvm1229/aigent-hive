- 작성: 2026-11-29 cloud 세션. 필요 조건: 이 기능을 담은 0.17.0 시험판 설치와 사용자 지식 기능 활성
- 금지: `claude -p`, 전역 `~/.claude`·`~/.codex` 직접 수정

1. Claude Code 새 세션에서 오래 남길 선호 하나와 결정 둘을 말해 지식 자동 기록을 일으킴

3. 같은 사실을 다시 말해 `기록할 새 지식 없음` 한 줄 확인
4. Codex 새 세션에서 1–3 반복
5. 부정 사례: 개수만 있고 목록이 없으면 실패로 기록
