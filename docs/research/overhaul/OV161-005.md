# OV161-005 — 버려진 세션 조정 잠금 자동 정리

- 기준일: 2026-11-26, 실행: Claude Code local 세션(Windows 11 Pro 10.0.26300)
- 진입: 유지관리자 보고. 직접 지운 프로젝트 폴더 때문에 JLPT 세션의 지식 기록 3건 실패
- 원칙: Hive는 감독관이 아닌 도구. 항목 하나의 삭제·손상으로 인한 관계없는 작업 차단 금지
- 판정: 구현·단위 시험 통과. 공개 시험·이 PC 확인은 OV161-006

## 증상

- 프로세스 ID를 쓰기 전에 죽은 프로세스, Windows의 프로세스 ID 재사용으로 세션 조정 잠금이 영구 잔존
- 오류: `session coordination lock has no valid process id`, `session coordination is busy or its lock owner cannot be verified`

## 수정

- `crates/hive-cli/src/session.rs`: 소유자 생존 확인 우선. 죽은 소유자의 잠금은 즉시, 소유자를 확인할 수 없는 잠금(프로세스 ID 없음·확인 불가)은 5분 뒤 정리
- 단계 검토 3번 반영: 살아 있는 소유자의 잠금은 나이와 관계없이 유지, 잠금에 소유 표식을 기록하고 자기 표식일 때만 해제

## 확인

- 시험: 새 잠금은 존중, 수정 시각이 10분 전인 빈 잠금은 정리 뒤 획득, 10분 전이라도 살아 있는 소유자의 잠금은 유지, 바뀐 잠금은 이전 소유자의 삭제 대상에서 제외
