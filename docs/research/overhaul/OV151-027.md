# OV151-027 앱 기억 대신 Hive 지식 기록 규칙

- 근거: 2026-11-14 유지관리자 요청. Hive 핵심 기능인 앱 기억 대신 Markdown 지식 기록의 전역·프로젝트 지침 강제, 다음 정식 0.15.1 범위
- 전역 사용자 지침: 전역 위키가 켜진 경우 한영 첫 규칙 추가. 앱 자체 기억(자동 기억·기억 파일·저장된 기억)에 남길 사실은 Hive Markdown 지식으로 기록, 앱 기억 중복 금지. Hive를 쓰는 프로젝트의 사실은 그 프로젝트 지식, 한 프로젝트를 넘어 적용되는 사실만 전역 user-root 지식
- 프로젝트 설치 지침: `harness/directives/01-project-knowledge.md`와 같은 내용의 템플릿 사본에 같은 규칙. user-root 승격은 기존 승격 조건 그대로
- 전역 위키가 꺼진 경우: 기존 규칙대로 지식 기록 금지, 이번 규칙 미적용
- 시험: 전역 지침 생성 시험의 한영 단언 추가 통과, 프로젝트 지침 두 사본의 동일성과 규칙 문장 시험 통과
- 한계: 실제 호스트의 기억 기능 사용 억제는 지침 준수에 의존. 호스트 기억 파일의 직접 차단·삭제 없음. 실제 설치·다른 OS 미확인
