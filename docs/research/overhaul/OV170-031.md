# OV170-031 — 프로젝트를 열 때 자동으로 맞추기

- 기준일: 2026-11-29, 실행 장소: cloud(코드·훅·고정물·시험). 실제 세션 확인은 [local 인계](OV170-031-local.md)

## 변경

- 명령: `hive project sync --hook claude|codex [--stdin-json]`. Claude 세션 시작 입력의 `cwd`를 대상 폴더로 사용
- Claude: 플러그인 선언에 `SessionStart` 훅 1개 추가. 출력은 `systemMessage`와 `additionalContext`의 같은 한 줄. 할 말이 없으면 출력 없음, 실패해도 세션 진행
- Codex: 같은 명령의 `--hook codex`는 한 줄 텍스트 출력. Codex 훅 등록 위치 확인과 등록은 local 단계
- Antigravity: 훅 없음. 동기화 코드는 `git` 외의 프로그램을 실행하지 않음(`agy` 재호출 0건, 계약 시험)
- 자동 적용 조건: `.hive/` 있음, 범위 안 새 판, 겹치는 수정 없음(`omitted_incoming_hunks` 0). 겹치면 `hive.project-sync-needs-review`와 `hive project upgrade --dry-run` 안내
- 건너뛰기: rebase·merge·cherry-pick·revert 도중, Hive 파일·설정에 커밋하지 않은 수정이 있을 때
- 알림: 신 호출 안내 첫 줄. 예: `Eileithyia called · project Hive 0.16.1 → 0.17.0, files: 12`. 자동 커밋 없음
- 끄기: `HIVE_PROJECT_SYNC=off`. 훅 예외는 [hook-consent](../../architecture/hook-consent.md)에 기록

## 확인

| 시험 | 결과 |
| --- | --- |
| 고정물 범위 안 자동 적용 | 통과, 한 줄 안내, 새 커밋 없음 |
| 충돌 시 미적용 | 사용자가 다시 쓴 Skill 파일에서 `needs-review`, 파일 변경 0건 |
| merge 중 건너뜀 | `.git/MERGE_HEAD`에서 `rebase-or-merge`, 변경 0건 |
| 커밋 안 한 Hive 수정 | `uncommitted-hive-changes`, 변경 0건 |
| 끄기 | `HIVE_PROJECT_SYNC=off`에서 출력·변경 0건 |
