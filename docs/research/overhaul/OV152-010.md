# OV152-010 — 앱 여러 개 선택 안내

- 기준일: 2026-11-15
- 요청: 대화형 설치에서 Hive를 설치할 앱을 여러 개 고르고, Codex·Claude를 한 번에 충돌 없이 설치

## 기존 동작

- `user-hosts` 질문은 이미 목록 입력(최소 1·최대 3)이며 빠른 설정에서도 질문. 적용 단계는 선택한 모든 앱을 한 번에 활성화, 앱마다 별도 마켓 폴더·등록
- 화면에 여러 개 선택 안내가 없고, 공백 구분 입력 `1 2`는 거부

## 변경

- 선택지가 있는 다중 선택 목록 질문에 안내 표시
  - 최소 1: "하나 이상 선택: 번호나 이름을 쉼표나 공백으로 구분해 입력, 예: 1,2" / "Choose one or more: enter numbers or names separated by commas or spaces, e.g. 1,2"
  - 최소 0: "여러 개 선택 가능: …" / "You can choose several: …"
- 선택지 목록은 쉼표와 공백 모두 구분자로 인정. 빈 항목·중복·범위 초과는 계속 거부, 자유 입력 목록은 쉼표만 구분
- 질문 카탈로그 바이트 불변, 저장된 진행·기록의 카탈로그 지문 유지

## 시험

- `choice_lists_accept_spaces_and_commas_but_free_text_lists_split_on_commas_only`
- `app_choice_shows_multi_select_hint_and_accepts_space_separated_numbers`
- `one_interactive_setup_selects_several_apps`: `1,2`·`1 2` 답변이 Codex·Claude 선택으로 저장
- 실제 두 앱 동시 활성화는 이 PC의 공개 시험 설치에서 확인
