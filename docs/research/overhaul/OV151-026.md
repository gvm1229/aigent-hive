# OV151-026 모든 Skill 설명의 하는 일 요약

- 근거: 2026-11-14 유지관리자 요청. 신 Skill 9개의 설명이 이름 목록뿐인 "명시한 신 이름에만 사용" 형태
- 점검: 현재 Skill 40개 중 신 Skill 9개만 하는 일 설명 없음. 나머지 31개는 하는 일을 먼저 설명
- 변경: `harness/gods.toml`에 신별 `summary_en`·`summary_ko` 추가. 0.15.0 안내의 검토된 설명과 같은 뜻
- 생성: 영어 설명은 "(이름) 하는 일. Use only when the user names …", 한국어 설명은 "(이름) 하는 일. 사용자가 … 중 하나를 부를 때만 사용". `openai.yaml`의 짧은 설명은 Rust 투영과 같은 전체 설명. Skill 안내 표의 기능 칸은 한국어 요약

- 시험: 모든 현재 Skill 설명에서 이름 꼬리표 뒤 "Use only when" 앞의 하는 일 설명 4단어 이상, 신별 영어·한국어 요약 포함, 옛 일반 문구 부재, 안내 표 일치. 신 묶음 10개 통과
