- 기준일: 2026-11-25, 실행: Claude Code 조율 세션(Windows 11 Pro 10.0.26300)
- 진입: 유지관리자 보고와 Fable 5.2 자문 검토. 정식 0.16.0 전 필수 수정
- 판정: 구현·단위 시험·test.8 공개·세 OS 수용·이 PC 확인 통과

## 증상

- Hive 프로젝트가 아닌 `google-tasks-mcp`에서 Claude로 만든 Skill은 `.claude/skills`에만, Codex로 만든 Skill은 `.agents/skills`에만 생성
- 이 PC는 Codex·Claude·Antigravity 세 호스트에 Hive 설치. 다른 세션이 Skill 6개를 손으로 복사하고 일치 시험 추가
- 유지관리자 판단: 단일 호스트 설치는 지금 동작 유지, 여러 호스트 설치에서는 금지

## 원인

- `.hive/`가 없는 폴더에는 사용자 전역 Hive 블록만 적용
- 전역 블록과 프로젝트 지침 어디에도 여러 호스트용 Skill 작성 규칙 부재

## 규칙 범위 검토(Fable 5.2 자문)

- 이미 전역: 언어, 계획 Markdown 기록, 안전한 작업 먼저 완료, 계속 진행·종료 분류, 출시 권한, 지식 조회·기록
- 프로젝트 전용 유지: 시작 규칙·조건별 경로, `hive run closure`, 하네스 업그레이드, 세션 예약, 프로젝트 지식 경로. 모두 `.hive/` 파일 전제
- 전역에도 필요: 여러 호스트 Skill 작성, Hive 없는 프로젝트의 경계, 다른 도구 공존. 편집 규율과 한국어 검사 절차는 0.17.0 후보

## 수정

- 사용자 전역 블록(`render_user_guidance`)에 규칙 묶음 추가
  - 선택 호스트 2개 이상일 때만: 프로젝트 Skill을 선택 호스트 폴더 모두(`.agents/skills/<name>/`, `.claude/skills/<name>/`)에 본문이 같은 사본으로 작성, 한쪽 수정 시 같은 작업 안에서 맞춤, 사용자가 지정한 호스트만 작성 허용, 사용자 전역 Skill 폴더 제외
  - 선택 호스트 2개 이상일 때만: 함께 쓰는 저장소에 없는 호스트 폴더는 만들기 전 한 번 질문
  - Antigravity 선택 시: 프로젝트 Skill 경로 미검증이라 사본 대신 보고
  - 항상: `.hive/` 없는 프로젝트에서 요청 없는 프로젝트용 Hive 명령·설치 권유 금지, 다른 도구·하네스의 설정·훅·지침 파일 보존
- 호스트 1개 설치에는 Skill 규칙 문장 미출력. 단일 호스트 동작 유지
- 프로젝트 템플릿 `00-project-harness.md`의 호스트·Skill 경계 절에 같은 Skill 문장 추가

## 확인

- 단위 시험: 호스트 1개 블록에 여러 호스트 문장 0건, 공존·Hive 없는 프로젝트 문장 존재. 호스트 3개 블록에 두 폴더 문장·질문 문장·Antigravity 보고 문장 존재
- `user_install` 단위 시험 전체 통과
