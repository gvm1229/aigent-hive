## 변경

- `crates/hive-cli/src/user_setup.rs`의 `set_operational_usage_threshold`: 숫자 변경 직후 후보 설정을 JSON 선언으로 바꿔 기존 `reconcile_decisions(..., PreferenceScope::User)`를 적용한 뒤 직렬화·투영·게시
- 다시 읽기 일치 검사, 되돌림, 프로젝트별 상한 검사, 같은 값 무변경 경로는 그대로 유지. 새 입력 출처·CLI 인자·질문 추가 없음
- 새 시험 `global_threshold_with_valid_provenance_updates_atomically`: explicit·legacy-unknown 기록 각각에서 같은 값 무변경, 25·0·99·10 변경, 다시 읽은 값·지문 일치, `ExternalChange`·답변 시각 제거, 무관한 `/wiki/enabled` 기록 보존, 게시 바이트 재읽기 일치, 투영 결합 확인
