## 변경

- R3 상대 경로: `hive project upgrade --target .`와 `--user-root` 상대 경로를 현재 폴더 기준으로 해석(`project_upgrade.rs`, `user_install.rs`, `update_discovery.rs`, `update_activation.rs`)
- R3 대상 지문: 디스크 실제 글자 크기 경로로 지문 계산(`target_scope_digest`), 입력 그대로의 이전 지문 위치에 제어·Claude 기록·중단 기록 중 하나가 있으면 이전 위치 사용(`bind_runtime_session`). c32fe646 동작 보존
- R5 교차 검토: `hive msg flow start --reviewer-provider <codex|claude|gemini>`, `Roster::resolve_named_for`, 흐름 기록 공급자로 `profile_current` 재검증. 작성자와 다른 선택 호스트 공급자가 하나일 때만 자동 선택, 그 밖은 정확한 명령을 담은 `next_action`
- R4·R6: `hive msg hooks apply` 안내에 Codex 훅 신뢰 승인·Claude 자동 모드 허용 규칙, `harness/plugins/aigent-hive/README.md`·`docs/releases/0.16.0.md` COMPAT 갱신

## 통합 중 발견·수정

- Windows `canonicalize`의 확장 접두(`\\?\`)로 같은 폴더의 지문이 달라지고, 이전 위치 확인이 중단 기록을 보지 않아 `test_source_rechecks_and_removes_a_legacy_halt_in_user_runtime` 실패(0.16.0-test.2 Windows 수용 실패와 같은 시험). 접두 제거와 중단 기록 확인 추가 뒤 통과(`tests.conformance.contracts.test_usage_control` 38개, 건너뜀 1)
