- 실행 환경: Claude Code cloud 세션·Linux·develop(`18fe034f` 기준). 이 세션에 실행 가능한 `hive` 없음 → 07 사전 확인 생략(2026-11-10 규칙)
- 범위: [요청](OV160-013-request.md) U1–U6, [계획](../../plans/active/0.16.0-mediation.md) OV160-013
- 결정 기록: [사용량 보호 승인 2026-11-21](../../decisions/usage-guard-approvals.md)

## 변경

| 기준 | 변경 |
| --- | --- |
| U1 경고 후 계속 | 측정 없음(기록 없음·오래됨·한도 누락·센서 사용 불가·대체 측정 동의 필요)은 exit 0 v2 `hive.usage-observation-warning`. `missing_windows`·`observation_cause`·`fix_command`·`next_action` 포함, 차단 기록·"작업 중단" 알림 없음. 측정된 한도가 기준 이하이면 다른 한도가 빠져도 차단. 0% 보호·초기화 보호·형식·세션·중복 오류 차단 유지 |
| U2 소스 폴더 기록 | `hive usage capture`가 `hive-source.json` 대상 허용. 기록 위치 `<사용자 루트>/.hive/runtime/usage-guard/targets/<대상 지문>/claude/<세션 지문>.json`, enforce 읽기와 같은 경로. 대상 지문은 끝 구분자·`.` 무시, Windows 대소문자 무시. 일반 프로젝트 경로 그대로, Hive가 아닌 폴더는 기록 없이 `hive.usage-capture-not-configured` |
| U3 실패 사유 | 거부된 기록은 `<사용자 루트>/.hive/runtime/usage-guard/claude/capture-failure.json`에 사유 코드·짧은 문구만 보존(원문 입력 저장 없음). 경고의 `capture_failure`·`usage status`의 `claude_capture_failure`에 표시, 같은 폴더의 성공 기록이 삭제. 새 `hive usage statusline`은 출력 없이 항상 exit 0, `--pass-through`는 입력 그대로 출력 |
| U4 연결 설정 | `hive setup --scope user --section usage --claude-statusline preview\|apply\|revert`. 미리보기의 `approval_digest` 없이는 변경 없음. `~/.claude/settings.json`의 `statusLine` 항목만 교체, 다른 바이트 그대로. 기존 명령은 `hive usage statusline --host claude --pass-through \| <기존 명령>`으로 이어 실행. 되돌리기 기록 `~/.hive/state/claude-statusline.json`. 사용량 구역 설정 결과에 연결 안내 추가 |
| U5 알림 | 측정 없음 전용 한국어·영어 Discord 문구(경고·빠진 한도·원인·해결 명령), 실패 구간당 1회 발송. 중단 알림 호스트 줄의 `Claude Code · 세션(5시간)` 형식, 실행 계획 부재 시 요청·진행 칸의 "실행 계획 없음" 표시, 옛 계속 진행 요청 안내 대신 회복 조건 안내 |
| U6 데스크톱 앱 | cloud에서 Code 탭의 `statusLine` 실행 확인 불가. 출시 노트 COMPAT-05·설정 결과 `desktop_app_limit`·플러그인 README에 한계와 대안(터미널 Claude Code, 경고 후 계속) 표시. 실제 확인은 OV160-012 |
