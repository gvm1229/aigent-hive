# OV151-020·021 결과 코드별 한영 문장과 명령별 구조 출력

- 근거: [재검토](stage-4-review-2.md)의 H1·H2·M1·M2와 L 묶음 일부
- 작성: Claude Opus 5.5, Windows 11

## OV151-020 결과 코드별 문장

- 결과 코드표: 업데이트·사용량 보호·저장 공간·세션 예약·문제 보고·프로젝트 갱신·설정 조회의 결과 코드별 한영 문장
- 한국어 성공: 코드 문장 우선, 설정의 완성된 한국어 안내 다음. 둘 다 없으면 주제 문장과 함께 영어 원문을 "안내(영문 원문)"으로 표시. 고정 주제의 구체적 결과 대체 금지
- 실패: 영어 단어로 한국어 원인을 추측하던 처리 삭제. 코드 문장, 한국어 원문, "원인(영문 원문)" 순서. 설정 충돌의 원래 원인을 "원래 원인"으로 표시
- 빠진 옵션: "missing required option", "missing value for", "requires"의 정해진 문장에서 옵션 이름을 읽어 정확한 다음 단계 제시. `--output`은 제외
- 전역 설정이 없으면 다음 단계 `hive setup`
- 사람용 문장에서 JSON 안내 문장, ` --output json`, Windows 경로 앞의 `\?\` 제거. JSON 원문 불변

## OV151-021 명령별 구조 출력

- storage: 전체 크기와 항목별 쉬운 이름·크기·파일 수
- usage monitor status: 감시 실행·실제 감시 확인·사용량 읽기 상태만 표시
- roster: 신별 맡은 역할, 앱별 기본 모델과 작업 수준, 프로젝트에서 바꾼 역할 수, 자동 실행의 꺼진 상태
- setup show: 프로젝트 자체 설정이 없으면 전역 설정 사용 안내
- setup describe: 질문과 번호 붙은 선택지, 현재 값
- report preview: 포함·제외 정보의 쉬운 이름과 외부 전송 여부
- update check 꺼짐·24시간 제한: 의미 없는 "업데이트 가능: 아니요" 생략
- knowledge·source wiki 검색 0개: "찾은 항목: 0개"
- 범용 출력: 내용 없는 제목 생략, 저장된 보호 선택과 현재 적용 여부의 이름 분리

## 확인

- 사람용 출력 단위 14개·통합 6개 통과. 새 시험: 업데이트 확인 꺼짐의 실제 결과, 세션 예약 충돌의 원인과 세부 내용, 설정 충돌의 원래 원인·경로 앞부분 제거, 전역 설정 부재의 `hive setup`, JSON 안내 부재
- 실제 바이너리 확인: storage·usage monitor status·roster·setup show/describe·report preview·update --check·usage check·role validate를 한국어·영어로 실행
- 한계: 결과 코드 339개 중 사용자 명령 계열 우선 표 작성. 나머지는 원래 영어 원문을 붙여 표시, 추측 번역 없음. 도움말 본문은 영어 유지
