## 재현과 범위

- E1 빈 폴더 `hive setup --target <폴더>` 미리보기의 실행 기능 미검증 안내 한 줄이 약 88칸이라 80열 창에서 낱말 중간에서 줄바꿈 발생. 고정 화면(`tests/fixtures/setup/screens/`)에는 이 줄이 빠진 상태. 범위: 두 줄로 나누고, 미리보기 출력의 모든 줄이 80칸 이하인지 시험
- E2 터미널에서 마지막 확인에 `아니요`라고 답하면 사람에게 `처리 실패:`와 AI 에이전트용 안내(`--show --summary`, `--input-channel agent --dry-run`)가 먼저 표시. 사용자가 고른 거절은 실패와 별개. 범위: 대화형 거절은 변경 없음 안내와 터미널 이어가기 명령만 표시. JSON의 `code`·`status`·종료 코드는 유지(에이전트 경로 호환). 사용자 설정·프로젝트 설정 모두
- E3 첫 질문 전과 마지막 미리보기 전에 화면에 아무것도 없이 30초 넘게 멈춘 듯 보임. 원인은 Hive가 부르는 `codex plugin list --json`이 이 PC에서 가끔 30초 넘게 걸리는 것. 범위: 대화형 화면에서 앱 상태 확인 전에 `설치된 앱 상태를 확인하는 중입니다…` 한 줄 표시
- E4 사용량 질문에서 전역 `잔여량 기준`에 10을 유지해도 앱별 기준 질문의 기본값이 20으로 나옴. 범위: 앱별 기준의 기본값은 저장된 앱별 값, 없으면 전역 기준값
- E5 기억 저장 지침: 사용자 발화 `앞으로 HTML 화면 디자인: 미니멀, 색은 남색과 흰색, 보라색 그라데이션 금지`에 Claude 에이전트는 주제 없는 사실 1개로 저장(`--user-statement`, `--subject` 없음), Codex(`codex exec`, gpt-6-luna)는 저장 명령 미실행. 원인: 항상 적용되는 사용자 지침 묶음(`user_install.rs`·`user_setup.rs`의 Hive 사용자 지침)의 저장 문장에 `--subject`와 "여러 조건은 원자 사실로 나눠 같은 주제로 `--batch` 1회`가 없고, `앞으로·항상·기억" 같은 지속 선호 발화에 저장이 필수라는 문장도 부족. 범위: 지침 묶음(한국어·영어)에 세 내용 추가, 관련 시험·고정 자료 갱신
- E7 에이전트가 `--describe --question project_kind`(답변 키 모양)를 쓰면 `unknown project setup question`만 받음(Claude·Codex 모두). 범위: 밑줄을 하이픈으로 받아들이고, 모르는 질문은 가까운 질문 이름 추천
- E8 에이전트가 `--dry-run --summary`를 쓰면 거부 문구에 고치는 방법이 없음(Claude·Codex 모두). 범위: 문구에 `--summary 없이 같은 명령 다시 실행` 추가
