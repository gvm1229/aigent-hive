# OV170-027 — Antigravity 1.2 실제 콜백 고정물

- 기준일: 2026-11-28, 실행 장소: local(이 Windows 11 Pro PC). 항목은 미완료
- 결과: 캡처 미실행. 콜백을 받으려면 전역 `~/.gemini/antigravity-cli/settings.json`에 `statusLine` 명령을 넣어야 하고, 이 작업은 세션 규칙상 사용자 승인 필요

## 확인한 사실

| 항목 | 값 |
| --- | --- |
| 설치된 Antigravity CLI | `agy --version` 출력 `1.2.17` |
| 상태 표시 설정 파일 | `~/.gemini/antigravity-cli/settings.json` 없음. 콜백 명령이 연결되지 않은 상태 |
| 해석기 | `crates/hive-cli/src/usage_control/antigravity.rs`, 지원 범위 `1.1.18 <= version < 2.0.0` |
| 수용 시험 | `antigravity_accepts_real_1_2_17_callback`은 아직 `#[ignore = "needs local 1.2.17 fixture"]` |

## 캡처 절차(승인 뒤)

1. `~/hive-backups/<날짜>/`에 현재 `~/.gemini/antigravity-cli/` 목록 기록(설정 파일 없음 확인)
2. 임시 연결 스크립트가 표준 입력을 `tests/work/ov170-027/raw.json`에 저장하도록 `statusLine` 등록([설정 안내](../../guides/host-support-0.11.2.md))
3. `agy` 대화 한 번 실행 뒤 연결 제거, 설정 파일을 원래 없던 상태로 복원
4. 원본에서 `email`·`conversation_id`·`session_id`·작업 경로를 시험용 값으로 바꾼 사본만 `tests/fixtures/`에 저장. 원본은 커밋하지 않고 삭제
5. 시험의 `#[ignore]` 제거, 고정물 해석 통과 확인, `docs/releases/0.16.0.md` COMPAT-09 문구는 그대로 두고 0.17.0 출시 노트에 검증 완료 기록

## 증명 범위

- 증명 범위: 이 PC에 Antigravity CLI 1.2.17이 있고 콜백은 미연결
- 미증명 범위: 1.2.17 콜백의 실제 자료 구조가 해석기와 맞는지
