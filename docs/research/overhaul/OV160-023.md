# OV160-023 Hive 밖 백업과 복원

- 기준일: 2026-11-23, 실행 장소: local 세션(Windows 11), 구현: Claude 조율 세션
- 계획: [재개 계획 OV160-023](OV160-resume.md#ov160-023-hive-밖-백업과-복원test4-차단)
- [OV160-016](OV160-016.md)의 `.hive` 안 사전 백업을 대체

## 변경

- 위치: `~/hive-backups/<작업>-<시각>-<난수>/`. 파일 재읽기 대조 뒤 `manifest.json` 기록, 자동 삭제 없음
- 시점: 설치 적용, `hive update` 마무리의 첫 쓰기, 보존 재설치의 제거, 사용자 제거의 첫 변경 전
- 대상: 바뀌거나 지워질 파일, `.hive/config` 설정 파일, 설치 기록, 명부, 상태 표시줄 되돌리기 기록, Hive가 고치는 호스트 파일 5종
- 제외: 재생성 가능한 색인·플러그인 사본, 잠금 파일, 호스트 로그인 자료
- 사용자 제거의 `.hive/backups` 삭제 중지
- `hive storage backup list|restore`: 기본 복원은 설정 5종과 명부만(허용 목록), 실행 상태·안내·지식·설치 기록·호스트 파일은 `--path` 지정 때만. 미리보기 지문 확인, 덮어쓰기 전 재백업, 파일 삭제 없음

## 확인

- `user_install::backup` 시험 5개: 바이트 복원, 미리보기 뒤 변경 거부, 사본 변조·경로 탈출·로그인 자료 거부, 쓰기 실패
- 보존 재설치 시험: 백업 실패 시 변경 0건, 성공 시 바깥 사본
- 사용자 제거 시험: `.hive/backups`와 바깥 사본 생존
- 빌드한 실행 파일: 임시 사용자 폴더에서 목록·미리보기·확인 복원
- 한계: 폴더 권한은 운영체제 기본(파일은 소유자 전용 0600), 지식 전체·기록·`hive setup` 변경은 백업 범위 밖, Hive 밖 도구의 삭제, 같은 디스크의 고장, 0.15.x 자체의 삭제 동작
- 남은 범위: 채택 흐름·등록 목록 재구성 명령(OV160-025)
