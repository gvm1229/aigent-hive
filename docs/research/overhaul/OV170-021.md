# OV170-021 — `ai-slop-cleaner` 이름 복원과 범위 확대

- 기준일: 2026-11-28, 실행 장소: cloud 세션
- 결정 근거: 유지관리자 2026-11-28 논의. 이미 만든 결과물에서 AI 티를 걷어내는 Skill, 대상은 코드·문서·디자인, 수정 전 계획 확인 필수

## 변경

- 이름: `harness/skills/code-polish/` → `ai-slop-cleaner/`, Hephaistos Skill 목록·단계, catalog·묶음·의존성(Hephaistos·Hades)·copier·활성 Skill 원장·스키마 enum 교체. `retired-names.yml`: `ai-slop-cleaner → code-polish` 삭제, `code-polish → ai-slop-cleaner`(0.17.0 이름 변경 lifecycle), `clean-ai-slop` 대상도 새 이름
- 구조: `SKILL.md`는 읽는 순서·우선순위(사용자 선호 > `hive-overrides.md` > 대상별 참고 파일 > 동봉 원본)와 공통 절차만. 대상별 점검표 `references/code.md`·`writing.md`·`design.md`, 원본과 다른 점 `references/hive-overrides.md`
- 공통 절차: 정리 계획 먼저와 수정 전 사용자 확인(`autonomous-workflow` 아래에서는 승인 단계로 마지막 질문에 포함), 범위 제한, 지킬 것 고정, 확인 항목만 종류별 정리, 보고. 검토 모드는 1단계에서 멈춤
- 한국어 문장 다듬기는 `humanize-kor`, 디자인 방향은 `design-curate`로 넘김. `SKILL.md`에 출처 링크 없음
- 동봉 원본 연결: `scripts/sync-user-plugin.py`가 `harness/upstream/`의 원본을 Skill의 `references/upstream/<원본>/`으로 바이트 그대로 복사하고, 호스트 사본과 `crates/hive-projection/src/upstream_resources.rs`(생성 파일) 갱신. OMC 원본은 전체, hallmark는 lock의 `projection` 목록(`SKILL.md`·`LICENSE`·Markdown 참고 파일·`sloplint` 스크립트)만. 원본 폴더마다 `LICENSE`
- 투영 경계: 소유 목록(`harness/manifest.toml`)과 `hive-core`의 Hive Skill 투영 경로 검사에 새 참고 파일과 `references/upstream/<원본>/…`(이름 구성 요소 검사, 깊이 상한) 추가
- 0.17.0 표면 목록과 시험 고정물 갱신
