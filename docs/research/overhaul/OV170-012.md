# OV170-012 — 봉투·확인증 모델 단일화와 ADR

- 기준일: 2026-11-28, 실행 장소: cloud 세션
- 계획의 두 선택지 중 "비인증 조율 계층 이유를 ADR로 기록" 선택

## 변경

- [ADR-0027](../../decisions/ADR-0027-envelope-receipt-layers.md): 서명 소환은 작업자 실행 권한 층, 파일 수신 상자는 비인증 조율 층. 조율 층의 권한 동작은 소비(받는 역할만)·확인(claim 토큰)·중지 해제(지문 확인) 셋으로 고정, 야간 반복의 작업자 실행은 서명 권한 필수
- 시험 추가: 받는 역할이 아닌 역할의 claim 거부와 본문 속 명령 문구가 권한을 만들지 않음(`msg_only_the_addressed_role_may_consume_and_a_body_grants_no_authority`)

## 확인

| 항목 | 결과 |
| --- | --- |
| 새 시험 | 통과 |
| 기존 권한 시험 | 잘못된 claim 토큰 거부, 동시 claim 하나만 성공, 중지 해제의 지문 확인은 기존 시험 유지 |
