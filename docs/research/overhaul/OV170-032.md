# OV170-032 — Hive 없는 프로젝트 불간섭 보장

- 기준일: 2026-11-29, 실행 장소: cloud

## 보장

- `.hive/`가 실제 폴더가 아니면(없음·심볼릭 링크) 동기화의 읽기·쓰기 0건. 훅 모드는 출력도 없음
- 사용자가 지운 `.hive/` 재생성 0건. 설치·설정 권유 문구 없음
- 이름 이전 등 다른 자동 경로: 0.17.0의 자동 경로는 이 세션 시작 훅뿐. 기존 프로젝트 쓰기 경로(`hive project upgrade`·`hive setup`)는 사람이 직접 실행할 때만
