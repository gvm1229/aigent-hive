# OV161-004 — 지식 폴더 잡파일·symlink 건너뛰기

- 기준일: 2026-11-26, 실행: Claude Code local 세션(Windows 11 Pro 10.0.26300)
- 진입: 유지관리자 보고. 직접 지운 프로젝트 폴더 때문에 JLPT 세션의 지식 기록 3건 실패
- 원칙: Hive는 감독관이 아닌 도구. 항목 하나의 삭제·손상으로 인한 관계없는 작업 차단 금지
- 판정: 구현·단위 시험 통과. 공개 시험·이 PC 확인은 OV161-006

## 증상

- Claims 폴더의 `Thumbs.db`·`desktop.ini` 같은 비 Markdown 파일 하나로 모든 기록·rebuild 실패(`claim collection contains a non-Markdown entry`)
- Wiki 폴더의 symlink·특수 파일 하나로 전체 실패

## 수정

- Claims의 비 `.md` 항목, Wiki의 파일이 아닌 항목: 읽거나 따라가지 않고 건너뜀
- 단계 검토 6번 반영: `Claims/` 바로 아래의 폴더가 아닌 항목도 건너뜀
- 민감 정보 검사·파일 이름과 ID 불일치 검사는 그대로 유지

## 확인

- 시험: 삭제된 연결 폴더와 `Thumbs.db`·`desktop.ini`·`Claims/.DS_Store`가 있는 상태의 rebuild와 현재 상태 검증 통과

## 공통 확인

- Rust 시험(단계 검토 반영 뒤): `hive-wiki` 215개 통과, `hive-cli` 1068개 통과. 실패 2개(`summon_signed_prepare_writes_once_and_never_launches`·`summon_commit_crash_then_head_advance_does_not_wedge_action`)는 변경 없는 기준 브랜치에서도 같은 실패
- `cargo fmt --check`·`cargo clippy --all-targets --all-features -D warnings`(hive-wiki·hive-cli) 통과, 브랜치 정책 커밋 검사 통과
