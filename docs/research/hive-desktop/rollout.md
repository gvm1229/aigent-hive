# 단계·작업량·검증

## 작업량 추정의 전제

- 추정 단위: 익숙한 개발자 1명의 주당 약 40시간 작업인 1인주
- 기준: 현재 Hive 코드·Rust·웹 화면에 익숙한 개발자, Windows 우선, 실행 엔진 하나
- 포함: 새 화면, 필요한 CLI 업무 분리, 대화·승인·중단·복구, 편집·터미널·Git, 설치·갱신, 관련 시험
- 제외: 전체 IDE 확장 생태계, 음성·컴퓨터 조작·브라우저 엔진, 클라우드 서비스·협업, 모든 제공자, 기존 제품과의 전체 기능 동등성
- 추정 성격: 이번 코드 관찰에 따른 설계 추정. 실제 생산성·성능 측정과 확정 일정의 구분
- 외부 대기: 인증·제공자 승인, 운영 지원 확약, 코드 서명·스토어 검토; 아래 작업시간과 별도

## 권장 순서

| 단계 | 선행 조건·작업 | 산출물·실제 수용 기준 | 추정 |
| --- | --- | --- | ---: |
| 1. 작은 검증 앱 | 새 제품 버전·실행 책임·허용된 인증 경로 확정 후 Tauri·엔진 하나 검증 | 한국어 입력·순서 있는 답변·승인 거부·실제 중단·재시작 복구, 고정 버전 기록 | 1–2인주 |
| 2. 공통 업무 분리 | 1의 구조 통과 후 `hive-app`과 필요한 현재 CLI 경계 분리 | 같은 요청의 CLI·화면 처리에서 동일 변경 경로·오류 코드·승인 판단 | 2–4인주 |
| 3. 대화와 실행 관리 | 2 이후 `hive-runtime`, 프로젝트·대화 목록·작업·승인·취소·복구 | 창 재생성·엔진 종료·연결 손실에도 작업 중복 실행 없음, 실제 결과 확인 | 3–5인주 |
| 4. 실사용 기능·배포 | 3 이후 편집·차이 비교·터미널·Git·지식·설정·설치·갱신 | 일반 사용자 설치 환경, 손상 갱신 거부·복구, 작업 폴더 밖 접근 거부 | 4–6인주 |

- Windows 연결형 실사용 시험판: 기본 합계 `10–17인주` + 불확실성 여유 `2–5인주` = **총 `12–22인주`**
- Windows·macOS·Linux 실사용 시험판: 운영체제별 통합·설치·화면 검증 `4–8인주` 추가 = **총 `16–30인주`**
- Hive 자체 실행 엔진: 위 Windows 앱에 최소한의 모델 연결·도구·문맥·권한·비용 구현 `16–32인주` 이상 추가, **총 `28–54인주` 이상**의 낮은 확신 추정
- 자체 엔진의 범위: 소수 제공자·로컬 작업. Claude Code·Codex·Hermes 전체 기능 동등성의 기간 추정 제외
- 여러 개발자의 병렬화로 합계 인주와 달력 기간의 단순 나눗셈 금지. 실행 계약·서비스 분리·복구 같은 선행 의존성 존재

첫 검증 뒤의 갱신 자료: 실제 변경 파일·작업 시간, 실행 프로토콜의 결손, 인증 지원 범위, 실패 복구 결과. 이 자료에 따른 다음 단계의 기간·범위 재산정.

## 첫 검증의 구체적 범위

- 조사 후보 경로: 새 `apps/desktop/`, `crates/hive-desktop/`, `crates/hive-runtime/`; 최소 UI와 한 엔진의 연결만
- 기존 코드 참고: `usage/codex_native.rs`의 실행파일 확인·입출력 제한, `run.rs`의 완료 조건, `orchestration.rs`의 불확실 실행·중복 방지
- 엔진 계약 검사: 새 세션, 답변 조각, 파일·명령 승인 수락·거부, 요청 취소, 네이티브 작업 ID, 재시작 뒤 재개
- 자료: 엔진·프로토콜·OS·Rust·WebView의 고정 버전, 안전하게 정리한 실행 결과와 실패 경우
- 중단 기준: 제공자가 금지한 인증 경로, 실제 취소·복구 지원 결손, Hive 승인 범위를 엔진이 집행하지 못하는 결과
- 실패 복구: 해당 엔진 연결 비활성, 독립 화면·서비스 작업 계속; 다른 엔진의 소유권으로 기존 작업 자동 변경 제외
- 현재 상태: **미실행**. 이번 요청의 조사 범위; 코드 구현·모델 실행·실행 정책 개정의 증명 없음

## 필요한 시험

| 대상 | 실제로 확인할 행동 | 증명 한계 |
| --- | --- | --- |
| 업무 분리 | 이전 CLI와 새 업무 함수의 요청·결과·파일 변경 비교 | 화면이나 실제 모델 연결의 증명 없음 |
| 실행 연결 | 시작·진행·도구 승인·중단·재개, 잘못된 요청 ID·늦은 결과 거부 | 모형 엔진만의 통과로 실제 제공자 지원 증명 불가 |
| 고장·복구 | 실행 중 앱·엔진 강제 종료, 재시작, 중복 시작 방지 | 전체 외부 서비스 장애의 재현과의 구분 |
| 자료 보호 | 경로 이탈·링크·외부 설정 보존, 동시 수정·설정 갱신 충돌 | 화면 권한 설정만으로 도구 실행 격리 증명 불가 |
| 화면 | 한국어 입력·복사·접근성·큰 대화·긴 터미널 출력·변경 비교 | 브라우저 화면 시험만으로 세 OS 앱 통과 주장 불가 |
| 설치·갱신 | 새 사용자 환경, WebView 설치, 서명된 갱신·손상 거부·기존 자료 보존 | 개발 환경의 빌드만으로 공개 설치 통과 주장 불가 |

화면 시험 후보: React 구성 요소 시험, 브라우저 화면의 Playwright 시험, 패키지 앱의 WebdriverIO·Tauri 시험, Rust의 기존 안전·보존 회귀 검사. 실제 엔진 시험은 허용된 계정·배포 범위의 별도 실행.

현재 [Tauri WebDriver 문서](https://v2.tauri.app/develop/tests/webdriver/)에서 기본 내장 서버의 Windows·Linux·macOS 지원 확인. 직접 `tauri-driver` 방식은 Windows·Linux로 제한; macOS의 시험 경로 선택 시 구분 필요. 시험용 서버의 사용자 배포 활성화 제외.

## 설치·갱신의 추가 책임

- 사용자가 Rust·Node.js·Python 개발 환경 없이 시작할 설치 프로그램
- Windows 실행파일 서명, macOS 서명·공증, Linux 배포 형식·필요 라이브러리
- 앱·Hive 라이브러리·실행 엔진·지침 묶음의 호환 표와 각 버전 고정
- [Tauri 갱신](https://v2.tauri.app/plugin/updater/)의 서명과 현재 Hive 지침 갱신의 별도 책임. 기존 `hive-update`만으로 앱 실행파일 교체 완성이라는 주장 제외
- 갱신 중 작업 중단·복구, 설치 실패의 재시도, 기존 프로젝트·사용자 자료 보존
- 기존 `harness/project-bases/`·`harness/user-bases/`의 불변 보존
- 앱 구현과 번호 공개 시험의 후속 범위 확정; 정식 게시·보호 브랜치 통합·설치는 해당 버전의 명시 승인 필요

## 이번 조사의 검증 기록

- 검사 호스트: Codex, Windows
- 실제 코드 읽기·줄 수 집계·공식 문서 조회 완료
- 제품 코드 변경·앱 빌드·설치·모델 실행 없음: 연구 요청의 범위와 현행 실행 정책에 따른 미착수
- macOS·Linux 실행 없음: 현재 Windows 호스트의 문서 조사만; 앱 지원과 성능의 증명 제외
- 한국어 문체: `python scripts/check-human-documentation-style.py --all --output json`, 2,988개 문서 검사·발견 0건·미검토 0건. 실제 Windows 실행, 문서 문체의 증명; 앱 작동의 증명 제외
- Markdown 링크: `python scripts/check-markdown-links.py --root . --output json`, 3,243개 내부 링크 검사·실패 0건. 실제 Windows 실행, 문서 경로·제목 연결의 증명; 외부 사이트의 계속 이용 가능성 제외
- Source Wiki: `hive source-wiki index`·`lint`, 234쪽·오류 0건·경고 0건. 실제 Windows 실행, 사실 쌍·원본 지문·파생 색인의 검증; 외부 모델 실행의 증명 제외
- 초기 사실 검사 실패: 연결 목록 정렬과 본문 800바이트 제한 위반. 새 사실 쌍만 교정 후 위 최종 색인·검사 통과; 제품 결함과의 구분
- 사용자 선호: `user-root`의 명시적 데스크톱 선호 1건, 정본 Markdown·파생 색인 기록 확인. 자동 관계 기능의 비활성 상태 유지
- 작업 경로: 조사 문서·새 사실 쌍·사실 목록만 변경. 기존 AI_Learning·문서 색인 변경 보존, 제품·활성 출시 계획·버전·설치 변경 없음
