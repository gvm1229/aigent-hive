# Hive 데스크톱 앱 조사 계획

- 기준일: 2026-10-14
- 기준 제품: `0.12.0`, `develop`
- 목적: 완전한 데스크톱 앱에 필요한 기능·기술 조합·기존 코드 변경 범위 판단
- 권한: 저장소 읽기, 공식 자료 조회, 조사 문서·검토한 지식 기록
- 제외: 제품 코드 변경, 새 제품 버전 확정, 모델 실행, 설치·게시, 현재 출시 계획 변경
- 가정: Windows 우선, macOS·Linux 확장 가능 구조; 실제 지원 확정과 다른 제공자의 비용·계약 승인 별도
- 결과물: `README.md`의 결론·구조·코드별 변경표, `sources.md`의 공식 근거

## 조사 순서

1. HDR-01: `Cargo.toml`, 여섯 Rust 패키지의 공개 함수·CLI 연결·호스트 실행 계약 확인. 현재 실행 소유권과 재사용 가능한 코드 식별
2. HDR-02: Tauri·Electron·대안 화면 기술, Codex App Server·Claude Agent SDK·Hermes Agent의 공식 문서 확인. 버전·운영체제·인증·라이선스 근거와 불확실성 분리
3. HDR-03: 화면·실행 관리·에이전트 실행 엔진의 역할 결정 후보, 구체적 변경 경로, 단계별 산출물·수용 기준 작성. 추정 작업량의 전제와 증명 한계 표기
4. HDR-04: 새 문서의 링크·한국어 문체 검증, Source Wiki 사실 쌍·사용자 선호의 정본과 파생 색인 확인. 기존 변경 보존과 제품 코드 변경 없음 확인

## 완료 조건

- 각 기술 권고와 중요한 외부 제약에 직접 공식 근거 연결
- 현재 코드의 관찰과 새 구조 제안·작업량 추정 구분
- 데스크톱 화면 추가와 Hive 자체 실행 엔진 도입의 변경량·승인 경계 구분
- Windows의 문서 검사 실제 실행, macOS·Linux 실행과 앱 성능·인증 미검증의 명확한 구분
- 조사 완료와 제품 구현 미착수의 정확한 구분

## 복구·중단 조건

- 외부 근거 부족: 해당 항목만 미확인 처리, 독립 조사 계속
- 예약 충돌: 충돌 경로만 대기, 기존 변경 보존
- 제품 실행·인증 정책 변경: 조사 제안으로 보존, 현행 정책 자동 변경 제외
