# 0.13.1의 갱신된 현재 Windows 앱 수용

- 10월22일 재개 시 Windows 11 x64·Codex26.1016.6573.0 확인. 이전26.1013.4894.0 수용과 별도 결과, 앱의 갱신 원인·방식은 증명 범위 밖
- 현재 설치의 로컬 코드에서 `thread-follower-interrupt-turn` 버전3·`mode=user-stop`·`interruptedTurnId` 응답과 `turn/interrupt`·하위 작업 정리 연결 확인

- 읽기 전용 연결 통과, 실제 같은 앱의 실행 상태 수신·앱 생존 확인. 최초 생성 시각은 WMI의 낮은 정밀도로 거부, 운영체제 핸들의 정확한 시각으로 수정한 입력만 통과
