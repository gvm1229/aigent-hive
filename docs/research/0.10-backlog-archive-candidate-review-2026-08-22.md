### 승격 판단

#### Alternative indexes

- `0.10.0` 포함: 의미 유사성 질문 기준선과 FTS·alias 결손 측정
- `0.10.0` 제외: Qdrant·vector database·embedding runtime dependency
- 재검토 조건: 재현 가능한 recall failure와 host-owned embedding receipt

#### Graphify 전면 지식 graph

- Active 승격: full-rebuild `--code-only` adapter
- Backlog 유지: Graphify의 Markdown 의미·upstream `global`·incremental update
- 재검토 조건: 증분 동등성·collection 격리·provider-free 의미 추출

#### 작업 자동 분담

- 가치: 긴 작업 병렬화·독립 검토·session 복구
- 현재 제외: host runtime의 signed exact receipt 부재
- `0.10.0` 편입 시 영향: graph·scan과 별도 대형 host E2E 추가
- 권장: `0.11.0` 또는 host receipt 확보 뒤 재검토

#### Notion Wiki backend

- 가치: Notion 편집과 Hive 검색 결합
- 현재 제외: 외부 OAuth·scope·freshness·write confirmation
- 권장: 최소 한 host의 공식 연결 E2E 확보 전 Backlog 유지

#### Obsidian integration

- 가치: 사람이 보는 Markdown graph
- 현재 `0.10.0` 대체: platform-neutral JSON·HTML graph export
- 권장: export 사용성 검증 뒤 `.obsidian/` 직접 연동 재검토

#### Platform signing

- 가치: 운영체제 경고 감소와 publisher identity
- 현재 제외: 인증서·notarization·외부 승인 비용
- 권장: 제품 기능과 분리한 release-infrastructure 후보 유지
