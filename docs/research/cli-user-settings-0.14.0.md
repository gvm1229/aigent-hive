# 0.14.0 전역 맞춤 설정과 등록 정보 조회 검증

## 범위

- Windows 11 x64의 개발 실행 파일, 임시 사용자 폴더, 전용 가짜 Codex
- 실제 CLI 시험 3건에서 실제 0.13.1 실행 파일과 확인 대상 설정 4개 지문 불변. 전체 사용자 폴더 불변의 증명으로 확대 금지
- 실제 알림·모델·호스트 변경, 다른 운영체제, 공개 후보 수용은 미실행

## 알림의 공개 범위와 항목

- `5e87ba66`: Discord 요청 공개 범위와 전송 항목 질문. 요약 기본값, 원문은 별도 직접 선택
- 알림 해제 시 환경 변수 참조 제거, 기존 공개 범위와 전송 항목 선택 보존. 전체 보호 해제 상태에서 저장 선택의 자동 활성화 없음
- [실제 한국어 CLI](../../tests/results/runs/20261024T092158-254022c69b9e.md): 알림 묶음만 선택→원문 공개·남은 사용량/앱 항목 지정→적용→해제→검증
- 전송 주소 자체의 입력·실제 메시지 전송 없음. 보고서의 전체 보호 값은 저장값 확인이며, 실제 알림 전송 억제 호출 시험과 구분
- Windows 설정 178개·코드 검사 통과. 기존 조건부 팝업 질문과 겹친 최초 질문 추가는 계약 검사 실패 후 제거, 팝업 동작 변경 없음

## 배경 설명의 추가와 제거

- `7bf48b19`: 배경 종류와 설명의 동시 지정, `:clear` 제거, 최종 미리보기의 없음 표시
- 제거는 실제 답변 시각과 빈 값 지문으로 기록. 재개 시 반복 질문 없이 유지, 파일 재적용에서도 선택 출처 보존
- 빠른 설정에서 배경 종류가 없으면 설명 요구. 입력 종료를 제거 답변으로 저장하지 않는 처리
- [실제 한국어 CLI](../../tests/results/runs/20261024T093158-2e267fac8511.md): 추가→제거 미리보기 거부→기존 파일 보존→재개 후 제거→파일 재적용의 설정 바이트 동일
- Windows 설정 181개는 최종 없음 표시 보완 전 범위. 보완 후 해당 설명 시험 1개·코드 검사·위 실제 CLI 통과

## 프로젝트별 기준과 범위 검사

- `39a6f77d`, `ea252b7b`: 설정용 등록 정보 조회와 실제 프로젝트 경로 검사 분리. 목록 부재는 빈 목록으로 조회, 손상·연결 경로·중복 식별자는 거부
- 설정 검증은 사용자 폴더의 목록만 조회. 없는 프로젝트 폴더의 등록 식별자도 확인 가능하며 해당 폴더 생성 없음
- 실제 지식 재구축은 기존의 엄격한 경로 검사 유지. 등록 정보 조회 결과만으로 프로젝트 접근 권한 부여 없음
- CLI에서 등록 식별자와 전역 기준 이상의 0~99 정수 확인. 잘못된 식별자·범위는 해당 질문만 반복, `{}`는 별도 기준 해제
- [실제 한국어 CLI](../../tests/results/runs/20261024T100030-820e95f0ddca.md): 미등록 식별자 재질문→등록 항목 99 저장→선택 출처와 프로젝트 원문 보존
- 위 실제 CLI는 지식 공유가 비활성인 등록 프로젝트 1개 범위. 활성 프로젝트의 문서 재구축을 막는 전체 설치 범위 수용과 구분
- 최종 Windows 설정 182개·공유 목록 15개·관련 코드 검사 통과
- 등록 조회 분리 시점의 위키 기본 검사 202개 통과. 사전 제외 3개는 5만 개 초과 비공개 자료 구성 시험 1개, 배포용 빌드·로컬 SSD가 필요한 5만 조각 조회 및 100개 모음 묶음 성능 시험 2개. 이번 기본 검사에서 미실행, 규모·지연 시간 성능 미증명
