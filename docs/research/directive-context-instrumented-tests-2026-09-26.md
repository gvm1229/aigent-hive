# 압축·사용량 계측 시험

- 범위: DCR-006, Windows의 앱 동봉 Codex와 공개 test.8. 안정판·전역 설정·제품 코드 변경 제외
- 승인: 실행 가능한 추가 시험. 수동 조작이 필요하면 즉시 중지

## 실행 순서

1. `.agents/work/directive-context-approval/instrument.py`에서 앱 동봉 실행 파일의 표준 입출력 연결 구성. `initialize` 뒤 `hooks/list`로 신뢰·활성 상태 확인. 원문 대화·추론·훅 출력 저장 금지, 사건 종류·상태·수치만 기록
2. 기존 승인 구절과 같은 훅을 공식 미리보기·적용 절차로 임시 복구. 명령·선택 구절 변경이나 신뢰 불일치 시 수동 확인 전 실행 중지
3. 구독 인증을 사용하는 호스트의 시험 대화 시작. 모델 기본값 유지, 제공자 API 호출·자격 증명 요청 금지. 최초 한 턴으로 사용량 사건과 훅 완료 사건 관측 여부 확인
4. 관측 성공 시 해당 시험 프로세스에서만 자동 압축 기준 조정. 합성 자료를 순서대로 처리하는 한 턴에서 실제 압축 2회 이상과 압축 후 보호 시험 확인. 자료·파일은 `tests/work/directive-context-live/`로 제한
5. 같은 모델·요청의 기존/전체/선택 전달 비교는 동일 실행 조건과 신뢰된 정의 확보 후 실시. 입력·출력·캐시 토큰, 훅 지연을 분리. 최초 조건별 1회, 변동 확인 필요 시 최대 3회. 토큰 사건 부재는 미측정이며 바이트로 대체 금지
6. 프로세스별 최대 180초, 전체 모델 시험 최대 6턴·입력 누적 300,000토큰. 한도 도달 시 해당 시험 중지·미검증 기록. 실제 이벤트 없는 압축 추정 금지
7. 완료·오류·수동 중지 시 자체 시작한 프로세스만 정리하고 임시 훅 철회. 설정 복원·원본 보존 확인, 결과 기록 후 DCR-006/RFR-001 판정

## 증명 범위

- 프로그램 입력 재생, 호스트의 실제 사건, 모델 행동을 별도 판정
- 시험 조건에서의 동작과 사용량 비교만 대상. 모든 프로젝트·모델의 장기 준수와 과금 절감 보장 제외

- 계측 연결 보완: 기본 모델 지침 비용을 포함한 첫 두 시험 입력 106,212토큰 관측. 전체 상한을 300,000으로 조정, 모델 턴 상한 6회 유지. 기본 연결의 파일 도구 실행 사건 부재로 압축 0회; 공개 동적 도구 규격으로 합성 파일 3개만 반환하는 읽기 도구 제공 후 1회 재시험

## 발견 결함의 수정·검증

- 재현: test.8의 구절 복원 훅 등록 → 철회 → 재등록 미리보기에서 종료 3. 이전 SubagentStart 위치가 철회 기록에 남지만 현재 구절 없음 기준의 목록에서는 제외되어 정당한 기록 거부
- 수정: `crates/hive-cli/src/policy/configure.rs`의 `validate_intent`에서 이미 정본 대조를 통과한 이전 훅 위치도 생성 위치 검증에 포함. 임의 위치 허용·지문 검사 생략 제외
- 회귀: `tests/conformance/contracts/test_directive_context.py`에 재등록·상태 조회·두 번째 철회·외부 설정 바이트 보존 검사 추가. 공개 test.8 실패와 수정 빌드 통과 별도 기록
- 수정 바이너리 경로로 실제 훅을 등록할 때는 새 명령의 호스트 신뢰 필요 여부 확인. 필요 시 수동 지점에서 중지

## 실행 결과와 수동 인계

- Windows 앱 동봉 Codex `0.155.0-alpha.16.4`, 기본 모델 `gpt-6-astra`, 구독 인증. 별도 제공자 API·키 사용 없음
- 계측 연결 통과: 입력·출력·캐시 토큰과 훅 시작/완료 사건 수집. 원문 대화·추론·훅 출력 저장 없음
- 자동 압축 경로 통과: 합성 자료 3개를 순서대로 읽는 한 턴에서 실제 압축 완료 3회, 각각 뒤 SessionStart 완료 확인. Hive 프로젝트 훅은 미등록 상태였으므로 Hive 복구·보호 통과의 근거에서 제외
- 위 한 턴의 호스트 보고 합계: 입력 85,563·출력 84·캐시 입력 62,976토큰. 캐시 입력은 입력의 부분집합. 압축 직후 사용량 사건의 합계는 증가하지 않아 내부 압축 비용 포함 여부 미확정. 과금·Hive 절감률 주장 제외
- 아래 후속 비교는 전체/선택 문구 전달의 입력 비용만 대상. 기본값 대조와 실제 훅 세 방식의 장기 행동·과금 비교는 미실행
- 공개 test.8 결함 재현: 등록→철회→재등록 미리보기 실패. [격리 재현](../../tests/results/runs/20260925T181711-5b1aebe7e5d6.md)
- 수정 빌드: 이전 정본 훅 위치까지 소유 범위 검사에 포함. [구절 복구 계약](../../tests/results/runs/20260925T181840-cc599e8f8fa9.md) 12개 통과·심볼릭 링크 권한 1개 제외, [기존 훅 계약](../../tests/results/runs/20260925T181900-2b476a8cb458.md) 14개 통과, [Rust 스냅샷 검사](../../tests/results/runs/20260925T182015-c03f085dbcce.md) 1개 통과. 형식 검사 통과; 제품 전체·다른 운영체제·새 공개 패키지 미검증
- 이전 Rust 검사 명령의 필터 불일치로 선택 0개인 실행은 통과 개수에서 제외. 실제 검사를 선택한 후속 실행으로 보완
- 원래 소스의 임시 훅·구절 설정은 부재 유지, 기존 철회 기록 보존. 수정 바이너리 위치가 기존 기록의 실행 파일 위치와 달라 그 기록의 검증 우회 없이 별도 합성 프로젝트 사용
- 격리 대상: `tests/work/directive-context-instrumented-consumer`. 수정된 실행 파일의 시험 훅 4개 등록, `hooks/list`에서 모두 `untrusted` 확인. 사용자 신뢰 전 모델 시험 중지, 자체 시작한 연결 프로세스 종료
- 사용자 신뢰 완료 후 조회에서 프로젝트 훅 4개 모두 trusted 확인. 추가 수동 조작 없음
- 후속 시험과 공식 철회 완료. 아래 결과·한계 참조

## 신뢰 이후 최종 계측

- 실제 Hive 프로젝트 훅 포함, 한 턴에서 합성 자료 1→2→3 순서 처리와 자동 압축 완료 3회 확인. 각 완료 뒤 프로젝트 SessionStart 완료·문맥 항목 1개·566바이트를 호스트 사건에서 관측. 시작 때에도 동일 전달 1회, 한국어 응답 유지
- 복원 훅 처리 시간: 시작 1,036ms, 압축 뒤 501·489·493ms. 비교 표본 1회로 지연 증가율의 통과 판정 제외
- 한 턴 호스트 보고: 입력 87,262·출력 116·캐시 입력 59,520토큰. 내부 압축 비용 포함 여부와 과금은 미검증
- 읽기 도구만 사용한 자동 시험이므로 자동 압축 직후 실제 파일 수정 거부는 미실행. 앞선 수동 10회 시험의 파일 보호 근거와 구분
- 입력 문구 비교: 같은 기본 모델·작업 위치·짧은 요청·간소화한 공통 기본 지침, 두 조건 모두 해당 세션에서만 훅 비활성화. 기존 승인 구절 2,351바이트와 그 출처 문서 전체 10,221바이트를 참고 자료로 전달. 실제 훅 세 방식의 비교와 구분
- 선택 구절: 입력 17,403·출력 5·캐시 입력 7,296토큰. 전체 문서: 입력 19,065·출력 5·캐시 입력 9,088토큰. 입력 차이 1,662개(전체 조건 대비 약 8.7%). 조건별 1표본, 캐시 차이가 있어 과금·장기 성능 절감률 추론 금지
- 이번 계측 6턴의 보고 입력 합계 315,505개. 최종 사용량 사건 수신 후 계획상 300,000 상한보다 15,505개 초과 확인. 추가 모델 실행 중단; 사전 입력 크기 상한 없는 사후 관측의 한계로 기록
- 격리 훅 공식 철회 완료, 수정 바이너리의 철회 후 상태 조회 성공. 격리 `.codex/hooks.json` 부재, 소스 루트의 훅·임시 구절 설정 부재 확인. 합성 자료와 철회 영수증 보존, 자체 시험 연결 종료
- 현재 수정 코드의 다른 운영체제·전체 회귀·다음 공개 시험 수용은 별도 필요. 모든 지침의 보편적 준수, 실제 작업별 지연·과금 절감 보장 제외

## 정식 출시 준비의 추가 검토

- 독립 코드 검토에서 문맥 기능 해제→일반 훅 갱신→철회에도 과거 SubagentStart 소유 기록의 거부 재발 확인
- 수정: Codex의 정확한 과거 SubagentStart 컨테이너만 빈 컨테이너 정리에 허용. 훅 정의 정본·지문 대조 유지, 다른 이름·하위 경로·외부 위치 거부
- [추가 회귀](../../tests/results/runs/20260925T215447-f7c2db4f183c.md): Windows 14개 통과·심볼릭 링크 권한 조건 1개 제외. 문맥 해제 뒤 재등록·두 번째 철회·외부 설정 바이트 보존 포함
- 독립 정적 코드 검토 승인. 실제 모델의 세 조건 고정 의미 비교·재개·하위 작업과 새 지침 토큰 50% 목표는 별도 근거 필요. 기존 생성 명령 p95 증가 1.86%는 해당 명령의 10% 목표 근거이며 전체 모델 지연과 구분
- 제품 수정 커밋 `06aab135`. 다음 공개 수용 `0.11.0-test.9`, 안정판 동작에 test.8 근거 재사용 금지
