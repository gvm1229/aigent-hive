- 통과: Windows Codex의 실제 수동 중지와 같은 작업의 후속 실행 완료. 모델의 자체 설명이 아니라 호스트 상태 조회로 판정
- 재개 응답은 시각 조회 완료와 `2026-09-20 08:38:28 UTC`를 보고. 조회 API에 해당 도구 항목은 노출되지 않아 호출 횟수의 독립 검증 제외
