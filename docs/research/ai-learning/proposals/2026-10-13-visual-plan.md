# Hive 개선 제안의 시각 설명

- 요청: `show-me`로 직전 개선 목록을 더 쉽게 시각적으로 확인
- 근거: [개선 목록과 버전 제안](2026-10-13-improvements-and-version.md)
- 결과: [선택 가능한 개선 지도](show-me-hive-roadmap.html)
- 범위: 사용자 지정 `0.12.1`·확인된 불편·추가 근거·실사용 조건의 시각적 설명
- 갱신 순서: 버전·후보의 근거 상태 정정, 선택 상세의 사용자 가치 조건 반영, 모바일·키보드·선택 재검사
- 상태: 필요성 재평가·버전 정정·재검사 완료, 제품 구현·활성 계획 변경 제외

## 실행 순서

1. 현재 제품 → 첫 시험 후보 → 사용자 지정 목표의 관계 표시
2. 후보 4개 묶음의 근거 수준과 외부 증거가 필요한 작업의 의존 관계 표시
3. 항목 선택 시 기존 기능·남은 작업·근거 ID의 간결한 표시
4. 후보 8개·미완료 기준 9개·별도 대기 2개 포함 여부 대조
5. Windows의 렌더링·선택·키보드·320px와 데스크톱 화면 확인

## 완료 기준

- 버전·항목·의존 관계의 제안서 일치, 가짜 진행률·일정·효과 수치 제외
- 기본 화면에서 핵심과 조건부 범위의 구분, 작은 화면에서 가로 잘림 없음
- 선택과 키보드 동작 확인, 새 후보·구현 승인 의미의 추가 없음
- 원래 제안·후보·구현 계획의 내용 보존

## 검증 결과

- Windows·Codex의 로컬 Chromium 검사: 선택 항목 16개, 후보 ID 8개·미완료 ID 9개·별도 대기 2개 포함
- 320·540·736·1024px 화면 조건의 가로 잘림·버튼 범위 이탈 0건, 밝은·어두운 화면 확인
- 키보드 선택·단일 선택 상태·저장 상태 이벤트 복원 통과, JavaScript 실행 오류 0건
- 모바일 핵심 순서의 두 줄 흐름과 선택한 묶음 옆 상세 표시 확인
- 이번 재평가: `0.12.1`과 근거·이익 조건의 갱신, 16개 선택·키보드·320·736·1024px 화면 재검사 통과
- 보존 확인: 구현 계획·상태·결정·출시 129개 문서의 이번 재평가 시작·종료 지문 일치
- 소스 사실 범위: `current-project`의 분리 방침과 조사 위치만 유지, 후보·버전 결정의 전역·공유 승격 제외
- 검증 한계: 로컬 미리 보기와 복원 이벤트의 확인. 실제 대화의 장기 상태 저장·새 호스트 세션 재개·제품 기능 구현의 증명 제외
