# 세션 중단 첫 차수의 로컬 설치 확인

## 설치 결과

- 2026-10-18 Windows 11 x64·Codex 26.1013.4894.0의 `0.12.1-dev` 로컬 설치와 상시 감시 활성화
- [설치 기록](../../tests/results/session-stop-one-shot-installation-0.12.1.json): 설치·검증 명령 성공, 지식·선호 파일 567개 보존, 로그인 자동 시작과 실제 정상 관측 네 번 이상 확인
- 현재 앱의 제어 연결 정상·미확인 대상 0개·재개 잠금 없음. 설정의 활성 값과 실제 정상 조회를 함께 확인
- 공개 안정판은 0.12.0, 공개 0.12.1 게시·태그·보호 main 통합은 별도 단계

## 멈추는 방법과 재개

- 독립 감시기의 15초 간격 조회. 초기화 확인 또는 정상 조회의 연속 60초 공백 때 Codex 자체의 중단 경로 사용
- Codex가 쓰는 `thread-follower-interrupt-turn` 요청으로 감지 당시 작업에 한 번 중단 요청, 앱의 `turn/interrupt`와 취소 처리 이용
- 모델에게 정리·마지막 답변을 요청하지 않는 중단. 앱 화면과 저장 파일 유지, [별도 알림](usage-stop-notice-0.12.1.md)으로 원인과 확인 결과 표시
- 사건 기록은 중단 이유의 보관과 중복 억제 목적. 재개 잠금·해제·확인 명령 없음, Codex에서 직접 재개·새 메시지 허용
- 시작 전 검사도 감시기가 이미 처리한 초기화로 첫 재개 입력을 다시 중단하지 않는 동작. 하한·0%의 새 관측 보호는 유지

## 증명 범위

- [결합 수용](../../tests/results/session-stop-one-shot-qualification-0.12.1.json): 이전 네 실제 실행 중단 283~306ms·앱 유지와 정확한 실행의 읽기 4/4. 최종 중단 요청 본문·신원 확인 코드의 동일성 확인
- 최종 한 차례 제어·재시작 중복 억제·첫 재개 입력 허용은 Windows 모의와 Rust 회귀, 알림 창은 현재 Windows의 실제 표시 검증
- 사용자 요청에 따른 추가 실제 중단 시험 없음. 이전 실패한 전체 자동 확인은 실패로 보존, 바뀐 제어 수명을 새 실제 중단 통과로 표시하지 않는 경계
- 긴 셸의 작업 취소는 이전 실제 확인, 개별 OS 자식 프로세스의 정확한 5초 종료는 미측정
- 실제 제공자 할당량 초기화·서버 처리·과금 종료 시각은 미검증. 다른 OS·원격·클라우드 실행은 미지원

## 설치 중 복구

- 첫 갱신의 Windows 지문 앞 단일 이스케이프 표식으로 안전 검사 중지. 실제 파일 지문 대조와 격리 원복 시험 뒤 형식 호환 수정
- 다음 갱신의 개발 빌드 표시 누락으로 기존 안정판 실행 파일 원복. 개발 빌드 신원 고정과 교체 전 검사 뒤 최종 설치 통과
- 두 설치 거부·복구에서 Codex 종료 없음. [개발 설치 지문 회귀](../../tests/results/runs/20261017T210421-568f0341c1e5.md)의 Windows 경로·손상 거부·이전 형식 원복 통과
