# 0.12.1 추가 지시 보존 검증

## 결과와 범위

- 실행 환경: Windows 11 x64, Codex, Rust MSVC. 소스 브랜치 develop
- 구현: 새 지시의 기본 추가, 이전 목표·조건·승인 유지, 명시적 교체 범위 한정
- 명시적 교체 없는 충돌: 명백한 모순도 선택 질문, 답변 전 충돌 행동·종속 변경 보류, 독립 작업 지속
- 취소 즉시 존중, 침묵·시간 경과의 승인 간주 금지, 대화 요약·재개 시 미해결 조건 보존
- 기존 구현 조사: `loop_engineering.rs::verify_steering_envelope`는 그래프 변경 승인 검사. 일반 대화의 이전 지시 보존·충돌 질문과 별개
- 올바른 사용자 루트: 사용자 홈 디렉터리. `.hive` 자체를 루트로 지정한 이전 오류 교정 후 설치된 사용량 보호의 허용 확인

## 규칙 사례 검토

| 이전 조건과 새 요청 | 요구 동작 |
| --- | --- |
| 파일 삭제 금지 → 불필요한 파일 정리 | 삭제 허가 추정 금지, 충돌 행동 전 질문 |
| 삭제 금지 → 앞선 금지를 취소하고 지정 파일 삭제 | 지정 범위의 명시적 변경, 나머지 조건 유지 |
| 한국어 답변 → 시험도 실행 | 기존 언어 유지와 시험 추가 |
| 기존 작업 → 지금 중단 | 즉시 중단 |
| 충돌 질문 → 무응답·상태 질문·대화 요약 | 충돌 미해결 유지, 해당 행동 실행 금지 |

- 위 표: 지침 의미의 검토 사례, 실제 호스트 모델 실행 시험 아님
- 자연어 충돌 판단의 소유자: 호스트. Hive의 모든 실행 차단·충돌 완전 탐지 보장 없음
- Linux·macOS 실행, 세 호스트 실제 대화, 공개 0.12.1-test.1 패키지 수용: 미실행·미증명
- 이번 범위: 구현·로컬 검증·로컬 커밋. 공개 시험의 패키징·이전 안정판 기준본 추가·게시 및 현재 설치 갱신은 별도 출시 작업, 성공 주장 없음
- 사용자 승인 0.12.1 개발 메타데이터 반영. 공개 안정판 0.12.0·기존 설치·역사 기준본 유지
