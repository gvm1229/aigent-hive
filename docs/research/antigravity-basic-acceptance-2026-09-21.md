# Antigravity 기본 호스트 수용

- 범위: `0.11.0`의 `RFH-003`, Claude 제외 후 Antigravity 실제 실행
- 환경: 사용자 확인 Antigravity IDE `2.5.5`, Windows x64 `10.0.26200`, `Gemini Flash 3.8 Medium`
- [파일 편집](antigravity-file-acceptance-2026-09-20.md): 사용자 도구 실행 보고와 제어 작업의 바이트 검사로 일반 허용·보호 거부 확인, 기준 파일 복원
- [새 대화 근거 대조](../../tests/results/runs/20260920T190647-c582875b9e02.md): 사용자 답변의 대기열·claim·chunk·검증 순서가 동결 자료와 일치, 후속 답변도 같은 순서 유지
- 수동 취소·재개: 사용자가 45초 대기 시작, 중지 후 같은 대화에서 이어 가기 확인 답변을 보고. 대기 명령 반복 없이 후속 응답 완료의 사용자 결과
- 증거 출처: 실제 IDE 동작·중지·후속 응답은 사용자 보고, 합성 근거와 편집 파일은 제어 작업의 독립 대조
- 미증명: IDE 내부의 `interrupted` 상태 영수증·정확한 호출 횟수·자동 스킬 선택·Hive 자동 중단·15초 감시. 사용자 수동 시험을 자동 제어 API 검증으로 대체하지 않는 경계
- 오류·시간 초과·자식 실행·지침 단독 비교의 추가 범위는 `HK-003`·`HK-004` 소유, 이 기본 수용에 포함해 완료 주장 금지
