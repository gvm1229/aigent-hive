## 검증 상태

- [Windows Rust 전체](../../tests/results/runs/20260919T090517-19fad210004a.md): 941개 통과·별도 조건 4개 제외. 이후 과거 지식 표시 변경은 [지식 회귀](../../tests/results/runs/20260919T093150-0191af3eefae.md)와 [이식·스키마](../../tests/results/runs/20260919T093244-06ee23e85c42.md)로 추가 확인
- Python 전체 시도: 문서 117개·보안 98개·계약 470개 통과, 운영체제·권한 조건 등 각각 4·5·13개 제외
- 통합의 이식 조회 실패는 현재성 표시로 보완. 배포 시험의 옛 버전·Windows 가상환경 기대값 보완. 전체 재검증 필요, 미실행·실패 자료를 통과로 합산하지 않는 경계
- 지식 22개 질문의 근거·순서 유지, 반복 저장·조회·비밀값 거부의 불필요한 쓰기 0건. 교대 p95 +8.95%, 질문별 11개는 10% 초과
- 큰 자료의 release 검색 엔진은 기존 50,000개 수용 기준 통과. 실제 앱·최신 CLI 전체 성능과 별도 범위
- 고정 지침 일반 경로 21.68%·지식 경로 20.03% 바이트 감소. 모델 토큰·품질·질문 횟수의 증명 제외
- 실행 8개 비교: 7개 결과 유지, 세션 없는 자동 호출 1개는 승인된 입력 거부. 파일 보존·센서 호출 수 별도 확인
- 새 코드·지침 반영 후 Source Wiki 출처와 전체 시험의 최종 정합화 진행

## 실제 호스트와 권한

- Codex 격리 작업에서 등록 후 보호 파일 편집도 성공: 차단 수용 실패. 정의별 신뢰·로드·검사 실행은 미확인
- 등록된 Windows 명령을 직접 실행하면 보호 파일 거부·일반 파일 중립 정상. 이 결과를 앱 호출의 증거로 대체 금지
- `tests/work/codex-policy-acceptance-1/`에 설정·실행 파일·실패 기록 보존. 사용자 보류 해제 전 신뢰 우회나 실제 앱 재시험 없음
- Claude·Antigravity 실제 수용, 15초 감시·진행 중 추론 중단은 미검증. 버전 조회·모사 시험과 구분
- macOS·Windows CI에 공통 파일 처리·설정·갱신 모듈 추가. 다른 운영체제 실제 실행 결과는 아직 대기
- 원격 푸시·번호 시험판 게시 없음. 안정판 통합·태그·게시·실설치는 `0.11.0`의 별도 명시 승인 필요
