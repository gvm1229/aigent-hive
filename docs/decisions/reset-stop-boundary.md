# 초기화 감지와 실행 중단의 경계

- 결정일: 2026-10-15
- 범위: 0.12.1-dev 검증을 보존하는 0.13.0 Windows Codex 사용량 보호 출시
- 목적: 초기화 전 사용 지속, 감지 뒤 실행 중단으로 새 할당량 보존
- 선택: 독립 15초 감시·공유 초기화 세대·사건별 한 차례 중단
- 2026-10-16 최종 정정: 정상 관측 공백 60초 뒤 보호 중단. 실제 초기화 확인 때 즉시 중단, 조회 실패와 초기화 이유 구분. 30초 기준과 초기화만 중단 선택의 교체
- 최종 출시 번호0.13.0: 세션 중단에 필요한 관측·상태·안내만 포함, 다른 예정 기능은 후속 유지·버전 미지정
- 2026-10-18 명시 정정: 재개 잠금·해제·사건 확인 명령 제외. 감지 당시 작업에 한 번 중단 요청, 같은 사건으로 새 입력·재개·앱 재시작 차단 금지. 연속 조회 실패당 한 번, 정상 관측 뒤 다음 실패 감지 준비
- 안내 창: 공식 로고·중단 원인·확인 결과·Codex 직접 재개 안내와 닫기만 제공. 다른 동작 버튼·명령 복사·자동 재개 없음
- 현재 사용자 결정: Codex 앱 전체 종료 금지. 진행 중 대화 실행만 중단, 앱 화면에서 원인·상태 확인
- 이전 앱 비상 종료 승인 철회. 모델 제공자 호출·자격 증명·호스트 내부 상태 변조 금지 유지
- 2026-10-15 사용자 승인: 실제 앱 중단 시험 통과 뒤 제품 0.12.1 로컬 빌드 설치·상시 감시 등록. 현재 앱을 유지하는 세션 중단으로 수용 기준 변경
- 2026-10-18 최종 선택: 기존 버전 규칙의 예외 없이0.13.0 안정판 공개·main 통합·태그·게시 승인. 현재 사용자0.13.0 설치는 별도 승인 범위
- 실행 중 감시·알림은 선택형. 설치·업데이트만으로 새 활성화 없음, preview와 정확 확인·세션 중단 승인을 전제로 활성화. 기존 활성 선택은 유지
- 설치 소유자 변경 제외. 기존 npm 네이티브 파일의 관리된 백업·원복과 지식·선호 바이트 보존
- 실행·검증·복구 정본: [구현 계획](../plans/active/reset-stop-0.12.1.md)
