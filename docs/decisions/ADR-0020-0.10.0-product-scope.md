- Source·project·user-root·shared·private·confidential scope별 물리 격리
- Vector 검색 결손 기준선과 Qdrant Edge·SQLite engine 비교
- Hard gate 통과 시 승인형 non-generative local embedding indexer와 optional vector adapter
- Hard gate 실패 시 vector database·embedding runtime product dependency `0건`
