# ADR-0022: `0.10.2` 전역 사용자 설치 수렴

- 상태: accepted
- 날짜: 2026-09-07
- 기준 stable: `0.10.1`
- 첫 공개 시험: `0.10.2-test.1`

## 문제

- 실행 파일만 최신일 때 불완전한 사용자 투영의 복구 누락
- 구형 설정·새 질문 처리에 별도 `install`·`setup` 지식 요구

## 결정

- `0.10.2` 출시 범위에 소스·harness 지침 감사 후 승인된 품질 개선 포함
- 조사 가능한 문제는 허용 범위에서 해결, 새 권한·실질적 사용자 선택만 질문
- 검사 범위는 파일 확장자보다 실행·승인·배포 행동 변화 기준

- `hive update`: 실행 파일 버전과 무관한 Hive 소유 전역 사용자 상태 점검·수렴
- npm: 실행 파일만 설치. 최초 `hive update`: 대화형 호스트 선택과 최소 투영 준비
- 버전별 질문 목록의 미응답: `setup-required` 상태와 일반 작업 차단
- 마지막 답 뒤 저장된 작업을 지문에 결합해 재개, 전역 설정·호스트 투영 적용·검증
- 질문 없는 갱신: 인증된 기존 답과 선언된 Skill 이관만 사용해 자동 완료
- 프로젝트 등록표·harness 읽기·변경 제외

## 결과

- 전역 설치 목표 경로: `npm install -g aigent-hive` 다음 `hive update`
- 새 설정 선택: 다음 호스트 세션의 명시적 답변까지 대기
- 현재 stable 출시는 유지보수자 요청으로 보류; 지침 개선 완료와 별도
