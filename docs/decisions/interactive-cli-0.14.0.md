# 대화형 CLI·사용자 선택 기록의 0.14.0 전환

- 결정일: 2026-10-23
- 사용자 확정: 프로젝트 설정까지 CLI 제공에 따라 대상0.14.0 변경. 미출시0.13.2의 기존 수정 통합,0.13.2 정식 전환 보류 유지
- 필수 결과: 공개0.13.1에서 시작한 첫 갱신 중 새 질문·답변·적용. 특정 코어 교체 순서는 목표가 아닌 수단, 다음 버전 대기로 대체 금지
- 기본 정책: 정보·짧은 안내 제공, 모든 자동 중단·새 작업 차단·상시 감시·외부 알림은 명시 선택. 전체 보호 해제에0%·관측 실패 포함
- 이전 정책: 기존 비활성 보존, 활성과 출처 불명은 CLI에서 현재 효과와 권장 변경 안내 후 질문. 사용자 직접 선택과 권장값 수락·상속·옛값의 출처 불명 구분
- 비대화형 갱신: 기존 선택 보존, 새 선택형 기능 활성 없음, 질문 보류. 선택형 미응답을 일반 작업 차단에 사용하지 않는 선택
- 언어: 미선택 시 한국어/영어부터, 기존 언어 재사용. 모든 질문·오류·결과·복구 안내에 같은 언어 적용
- 공통 엔진: CLI가 질문 조건·검증·답안·진행·미리보기·적용 소유. AI는 시작 안내와 결과 설명, 공급자 모델 호출과 자격 증명 수집 없음
- 제거 범위: 미리보기·확인·정확한 감시 종료·사용자 자료 보존만. 전체 자료 삭제 선택 제외
- 사용량 품질: 신고의 원인 미확인 유지, CLI 직접 설정은 모델 호출0회. AI 설정은 작은 모델·일반 속도 권고와 실측, 고급 모델/Fast 탓으로만 분류 금지
- 이전 계획의 무조건 기존 사용자 일괄 해제와0.13.2-test.3 목표는 [새 계획](../plans/0.14.0-implementation.md)으로 교체. 기존 검증·실패·승인·공개 파일 보존
- 2026-10-25 실행 방식: [남은 검증·커밋 단위](../plans/details/0.14.0-delivery-milestones.md)로 진행 표시, 한 단위 검증 뒤 ship. 구체적 실패·변경 없는 반복 검토 제외, 실제 0.13.1 설치의 시험 사용 금지. 기존 15개 제품 완료 기준 유지
