# ADR-0013: `0.8.0` 공개 릴리스 범위

- 상태: accepted
- 날짜: 2026-07-31
- Target: `0.8.0`
- 관련 결정: ADR-0008 verifier-only TUF, ADR-0010 native usage sensor,
  ADR-0012 global onboarding

## 결정

### Release identity

- 공개 명칭: `Aigent Hive 0.8.0`
- GitHub normal release와 npm `latest`
- 별도 `preview` label·GitHub prerelease·npm `preview` dist-tag 없음
- `<1.0.0` SemVer 자체를 pre-1.0 성숙도 신호로 사용
- Production-ready 보증 없이 known limitation과 검증 host exact version 공개

### Host qualification

| Host | `0.8.0` gate |
| --- | --- |
| Codex | 실제 install·update·usage·prompt refine 검증 |
| Antigravity | 실제 install·update·fallback usage 검증 |
| Claude Code | Package·fixture·projection conformance와 unverified disclosure |
| Windows | 실제 기기 사용자 acceptance 필수 |
| Linux | x86_64·arm64 musl build·install·runtime qualification 필수 |

Claude Code 실제 subscription session과 Pro/Max usage parity:

- `0.8.0` 차단 조건 제외
- Subscription 확보 뒤 별도 qualification 재개
- 실제 검증 전 verified 지원 주장 금지

### Platform과 artifact baseline

- Protected `main`·tag와 exact source commit
- GitHub Actions의 macOS arm64·x86_64, Linux musl x86_64·arm64,
  Windows MSVC x86_64 native build
- Release asset SHA-256
- GitHub artifact attestation과 source provenance
- GitHub archive와 npm-installed native binary의 byte identity
- Package manager 또는 digest 고정 직접 install·update
- Network self-update 비활성

### npm 배포

- Public unscoped umbrella package `aigent-hive`
- `npm install -g aigent-hive` 단일 사용자 명령
- `@aigent-hive/*` platform package의 exact-version optional dependency
- Registry package 내부 native binary와 executable shim
- Postinstall network download·source build 없음
- Platform package 선행, umbrella package 최종 publication
- Node.js/npm은 npm channel에만 필요한 installer dependency
- Package name·scope ownership과 최초 public publication은 사용자 외부 authority

### 직접 설치와 Windows shell boundary

| Surface | 결정 |
| --- | --- |
| Consumer binary·harness | Node.js·PowerShell runtime dependency 없음 |
| Unix direct installer | `install.sh`와 Linux·macOS OS/architecture 선택 |
| Windows direct installer | Windows 기본 PowerShell 5.1 지원 |
| `cmd.exe` | Exact-version PowerShell 5.1 bootstrap 호출 명령 지원 |
| Consumer PowerShell 7 | Dependency·탐지 경고·설치 prompt 없음 |
| Source development·release | PowerShell 7 LTS dependency |
| Source dependency install | Exact command·package·scope preview와 명시적 동의 뒤 Microsoft 지원 installer 위임 |
| Ownership | Microsoft 또는 package manager 소유, Hive update·uninstall 없음 |

PowerShell 7 부재는 consumer install 차단 사유에서 제외. Source dependency 설치 거절은
외부 mutation 0건과 해당 PowerShell 7 전용 검증의 명확한 미실행 상태로 처리.

### Deferred hardening

- macOS Developer ID signing·notarization
- Windows Authenticode 또는 Azure Artifact Signing
- External TUF 2-of-3 production authorization
- Independent key-holder 운영 ceremony

ADR-0008의 verifier·migration·rollback 구현 보존. Deferred 항목은 future hardened
channel의 자산으로 유지하고 `0.8.0` publication 필수 gate에서 제외.

## 근거

- Pre-1.0 단계의 release friction 대비 과도한 private-key·external signer 운영 비용
- Download·self-update channel 부재에 따른 TUF production quorum의 낮은 즉시 효용
- GitHub artifact attestation·SHA-256·protected tag로 확보 가능한 초기 provenance
- Windows 실제 사용성 검증과 red CI 수정의 더 높은 release 위험 감소 효과
- Claude subscription 부재를 숨기지 않는 명시적 미검증 상태
- 일반적인 CLI 설치 방식과 일치하는 npm 전역 설치·curl channel
- Linux x86_64·arm64 지원을 통한 macOS·Windows 편중 해소
- 별도 preview channel 없이 SemVer pre-1.0 의미 활용
- Windows 기본 PowerShell 5.1을 활용한 consumer dependency 최소화
- `cmd.exe` 사용자의 동일 signed bootstrap·verification 경로
- Source tooling dependency와 shipping runtime dependency의 분리

## 결과

- `0.8.0`의 현실적 공개 경로
- 실제 검증과 이론 지원의 분리
- Heavy signing 미비를 안정성 검증 완료로 오인할 위험 차단
- Existing verifier code와 future hardened channel의 보존
- Production publication credential과 사용자 최종 확인의 외부 경계 유지
- Consumer PowerShell 7 설치·업데이트 ownership 확대 방지
- npm과 직접 설치를 같은 native artifact 계보에 결합
