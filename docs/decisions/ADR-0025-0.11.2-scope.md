# ADR-0025: 0.12.0 범위와 Windows 우선 검증

- 상태: accepted
- 날짜: 2026-10-05
- 범위: 후속 목록의 사용자 결정과 구현 가능성 조사
- 근거: [조사 결과](../research/followup-feasibility-0.11.2.md)

## 결정

- 0.12.0: 주기 사용량 감시·현재 작업 중단, 호스트 소유 자동 분담, Graphify의 미완료 확장 범위 편입
- 추가 구현 후보: Antigravity 공식 사용량 수신, Windows 실제 훅 범위 검증, 토큰 계측·예산 제어, Windows 샌드박스 진단, macOS 오류 진단
- 기본 개발·검증 환경: Windows. macOS 전용 수용은 모든 독립 Windows 작업 뒤 마지막 기준
- Claude 실제 대화·구독 사용량: 사용 가능한 환경 부재로 버전 미정 대기. 게시자 서명: 기존 외부 승인 대기 유지
- Notion 정본 후보 폐기. ADR-0018의 Notion 채택 결정 대체, 이미 완료된 Discord 범위 보존
- 벡터 검색 완료·종료. 엔진 비교 연구는 참고 자료로 보존, 구현 과제 재개 제외
- Obsidian: 기존 Markdown 폴더와 기본 그래프로 사용 가능. 별도 플러그인 후보 종료, 권한·출처 차이 안내만 유지
- 로고 완료. 0.9.0 발표 자료 폐기, 갱신·로고 교체 할 일 종료. 외부 저장소의 실제 파일 삭제와 구분

## 실행 경계

- 구현 승인: 2026-10-05 최종 계획 전체 구현·검증·번호 공개 시험
- 활성화 기준: 실제 검증된 기능만 활성. 미지원 연결·증명은 비활성·대기 표시, 지원 기능의 시험판 수용 지속
- 관계 갱신: 활성 범위의 지식 저장 뒤 자동 분석. 저장·색인 완료 뒤 현재 호스트에 제한된 분석 요청, 실패 시 원문 성공 보존
- 한 번의 분석: 변경 문서 최대 10개·본문 16KiB, 분석 1회·형식 교정 최대 1회. 동일 지문 중복·관계 결과의 재저장 순환 제외

- 현재 요청의 완료 범위: 구현·검증·번호 공개 시험. 미지원 실제 호스트 기능은 성공 수와 분리
- 제품 구현 착수 시 0.12.0과 첫 공개 시험 0.12.0-test.1 적용. 제품 버전0.12.0, 설치본·공개 배포물0.11.1 보존
- 구현·검증·번호 공개 시험의 기존 정책 유지. 0.12.0 안정판·보호 main·게시·설치는 버전별 승인 전 제외
- Hive의 제공자 API·자격 증명·모델 실행 소유 금지. 현재 호스트가 제공한 지원 연결만 사용
- 자동 중단·엄격한 분담은 실제 대상 결합과 실행 영수증 검증 선행. 선언형 상태만 완성한 경우 사용자 기능 완료 판정 제외
- 조사로 확인한 공식 기능과 로컬 설치·로그인·실제 수용을 각각 구분. 미검증·외부 결손의 임의 완료 제외

## 0.12.0 추가 결정

- 사용자 지정 새 기능 버전 0.12.0, 첫 공개 시험 0.12.0-test.1. 이전 0.11.2 목표 대체·버전 규칙 예외 불필요
- 기본 활성 0% 보호, 일반 보호 해제와 독립. 정확한 현재 대화 결합의 별도 확인으로만 제외
- 공개 안정판·현재 사용자 설치 0.11.1 유지. 안정판·보호 main·게시·설치의 0.12.0 승인 별도
- 2026-10-06 자동 작업의 필요한 수동 승인 허용. Antigravity 상태 표시 연결의 변경·복원과 Windows 공식 복구부터 실행, 실제 관리자 조작·호스트 연결 존재를 승인만으로 성공 처리 금지
