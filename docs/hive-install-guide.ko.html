Stable CLI 설치

TERMINAL

Version 확인

명령 인식과 stable version label 확인. 현재 예상값: AIgent Hive v0.10.0 (released 2026-09-02)

TERMINAL 
hive --version

사용할 host에 Hive 연결

한 host는 --host, 여러 host는 쉼표 구분 --hosts 또는 반복 --host로 지정. --hosts 값의 쉼표 앞뒤 공백 허용. 공백 포함 시 전체 값을 따옴표로 묶고 빈 항목은 금지. 다음 단계의 전역 설정에서도 같은 host를 모두 선택.

HOST 한 개 · CODEX 예시 
hive install --scope user --host codex --apply --output json
HOST 여러 개 · 쉼표와 공백 예시 
hive install --scope user --hosts "codex, claude" --apply --output json
HOST 여러 개 · 반복 FLAG 예시 
hive install --scope user --host codex --host claude --apply --output json

복수 host apply 전 전체 dry-run 점검. 이후 입력 순서대로 활성화하며, 실패 시 완료·실패 host와 변경 경로를 JSON으로 보고. 각 host CLI의 설치·로그인 완료 상태 필요.

Codex--host codex
Claude Code--host claude
Gemini Antigravity--host antigravity

연결한 host를 열고 아래 요청 입력. 현재 project를 검사하지 않고 사용자 범위만 설정.

HOST 대화창 
이 host의 전역 Aigent Hive 환경을 설정하거나 다시 설정해 줘.
현재 project, repository, folder는 검사하거나 변경하지 말고
사용자 범위 설정을 대화형으로 시작해 줘.

Project 한 개 설정

대상 repository를 host에서 연 뒤 아래 요청 입력. Exact write preview 확인 뒤 project 범위만 변경.

PROJECT 대화창

기존 전역 Hive 선호를 사용하고 이 project만 검사한 뒤

macOS · Linux

  https://unpkg.com/aigent-hive@0.10.0/install.sh | sh
Windows PowerShell 5.1+
POWERSHELL 
irm https://unpkg.com/aigent-hive@0.10.0/install.ps1 | iex
Windows 명령 프롬프트
CMD 
curl.exe -fLo install-aigent-hive.cmd https://unpkg.com/aigent-hive@0.10.0/install.cmd && install-aigent-hive.cmd
03

Update

새 version 확인과 설치 제안. Hive가 설명과 확인 없이 update를 자동 설치하는 경로 없음.

TERMINAL 
hive update

안전 원칙: 거절·입력 종료·비대화형 실행에서는 설치 변경 0건. 기존 install owner와 exact update 내용 확인 뒤에만 진행.

04

다른 컴퓨터로 전역 지식 이전

.hivekb bundle로 전역 지식 이전. --user-root 값은 .hive 폴더가 아닌 사용자 홈 디렉터리.

포함 범위: 전역 정본 Markdown 지식. SQLite 색인·runtime 상태·project-private 지식·비밀 값·절대 경로 복사 없음.

현재 운영체제의 셸 예시만 사용. macOS·Linux의 $HOME과 Windows PowerShell의 $env:USERPROFILE 교차 사용 금지.

macOS · Linux 셸

내보내기와 SHA-256 확인

SHELL 
bundle="$HOME/Downloads/aigent-hive-knowledge-YYYY-MM-DD.hivekb"
hive knowledge export --user-root "$HOME" --scope global --bundle "$bundle" --output json
shasum -a 256 "$bundle"

대상 컴퓨터: bundle 경로와 기대 SHA-256 값 교체 후 dry-run 우선 실행. 파일 존재·SHA-256 일치·충돌과 검증 오류 0건 뒤에만 apply.

SHELL 
bundle="$HOME/Downloads/aigent-hive-knowledge-YYYY-MM-DD.hivekb"
shasum -a 256 "$bundle"
hive knowledge import --user-root "$HOME" --bundle "$bundle" --dry-run --output json
hive knowledge import --user-root "$HOME" --bundle "$bundle" --apply --output json
hive knowledge lint --target "$HOME" --user-root "$HOME" --output json
Windows PowerShell

내보내기와 SHA-256 확인

POWERSHELL 
$bundle = "$env:USERPROFILE\Downloads\aigent-hive-knowledge-YYYY-MM-DD.hivekb"
hive knowledge export --user-root $env:USERPROFILE --scope global --bundle $bundle --output json
Get-FileHash -Algorithm SHA256 $bundle

대상 컴퓨터: Hash 값과 bundle 검증 뒤 dry-run 우선 실행. 충돌과 검증 오류 0건 뒤에만 apply.

POWERSHELL 
$bundle = "$env:USERPROFILE\Downloads\aigent-hive-knowledge-YYYY-MM-DD.hivekb"
Get-FileHash -Algorithm SHA256 $bundle
hive knowledge import --user-root $env:USERPROFILE --bundle $bundle --dry-run --output json
hive knowledge import --user-root $env:USERPROFILE --bundle $bundle --apply --output json
hive knowledge lint --target $env:USERPROFILE --user-root $env:USERPROFILE --output json
