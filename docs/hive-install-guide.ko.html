시작 전 준비

가장 간단한 경로: Node.js·npm 확인 → stable package 설치 → 현재 host 활성화 → 전역 설정 → project 설정

아래 명령으로 Node.js와 npm 확인. 둘 중 하나라도 인식되지 않으면 공식 Node.js LTS 설치 뒤 새 terminal에서 다시 확인.

TERMINAL

npm --version
01

5단계 설치

Stable CLI 설치

npm latest의 현재 stable release 설치

TERMINAL 
npm install -g aigent-hive

Version 확인

명령 인식과 stable version label 확인. 현재 예상값: AIgent Hive v0.8.0

TERMINAL 
hive --version

사용할 host에 Hive 연결

--host는 명령 한 번에 하나만 지정. 여러 host를 쓰려면 host별 명령을 한 번씩 실행하고, 다음 단계의 전역 설정에서도 같은 host를 모두 선택.

HOST 한 개 · CODEX 예시 
hive install --scope user --host codex --apply --output json
HOST 여러 개 · CODEX + CLAUDE CODE 예시 
hive install --scope user --host codex --apply --output json
hive install --scope user --host claude --apply --output json

--hosts나 한 명령 안의 반복 --host는 미지원. 각 host CLI의 설치·로그인 완료 상태 필요.

Codex--host codex
Claude Code--host claude
Gemini Antigravity--host antigravity

전역 선호 설정

연결한 host를 열고 아래 요청 입력. 현재 project를 검사하지 않고 사용자 범위만 설정.

HOST 대화창 
이 host의 전역 Aigent Hive 환경을 설정하거나 다시 설정해 줘.
현재 project, repository, folder는 검사하거나 변경하지 말고
사용자 범위 설정을 대화형으로 시작해 줘.

Project 한 개 설정

대상 repository를 host에서 연 뒤 아래 요청 입력. Exact write preview 확인 뒤 project 범위만 변경.

PROJECT 대화창 
이 project의 로컬 Aigent Hive harness를 설정해 줘.
기존 전역 Hive 선호를 사용하고 이 project만 검사한 뒤
정확한 쓰기 미리 보기를 먼저 보여 줘.
02

Node.js 없는 직접 설치

직접 installer도 npm의 동일 native package byte와 exact-version SHA-256 검증 사용. 설치 뒤 2–5단계는 동일.

macOS · Linux
SHELL 
curl --proto '=https' --tlsv1.2 -LsSf \
  https://unpkg.com/aigent-hive@0.8.0/install.sh | sh
Windows PowerShell 5.1+
POWERSHELL 
irm https://unpkg.com/aigent-hive@0.8.0/install.ps1 | iex
Windows 명령 프롬프트
CMD 
curl.exe -fLo install-aigent-hive.cmd https://unpkg.com/aigent-hive@0.8.0/install.cmd && install-aigent-hive.cmd
03

Update

새 version 확인과 설치 제안. Hive가 설명과 확인 없이 update를 자동 설치하는 경로 없음.

TERMINAL 
hive update

안전 원칙: 거절·입력 종료·비대화형 실행에서는 설치 변경 0건. 기존 install owner와 exact update 내용 확인 뒤에만 진행.

04

대상 project의 preview 검토 뒤 로컬 harness 생성 확인
