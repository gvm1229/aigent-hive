# Aigent Hive v0.13.1 업데이트 내역:

## 수정

- **설정한 사용량 하한에 도달해도 작업이 계속되던 문제 수정**
  - 중간 중단 감시를 켠 경우 진행 중인 Codex 대화와 하위 AI 작업에 같은 하한 적용
  - Codex 앱 유지, 잠금 없이 직접 재개·새 메시지 허용. 같은 사건의 반복 중단 방지
  - 이미 시작한 일반 외부 명령의 계속 실행 가능, 별도 로컬 AI 대화·하위 에이전트는 중단 대상 유지

- **사용량 조회 실패로 작업이 자주 멈추던 문제 수정**
  - 기존 연결 실패 시 새 조회 프로세스로 재확인, 정상값이 확인되면 작업 유지
  - 오래된 측정값·시각 보정의 처리 개선, 연속60초 정상 조회 부재의 보호 기준 유지
  - 앱 재시작 전 기록·만료된 값에 따른 초기화 오판 수정

- **갱신 뒤에도 감시 설정과 사용자 자료를 지키도록 수정**
  - 일부 스킬만 고른 설치·Windows 경로 차이·같은 감시 파일의 반복 갱신 오류 수정
  - 지식·설정·중단 기록·감시 활성 선택 보존, 실제 감시 버전과 정상 조회 상태 확인

## 개선

- **작업 중단 안내와 Codex의 감시 해제 안내 개선**
  - 공식 로고의 닫기 전용 창에 남은 사용량·적용 하한·실제 중단 확인 표시
  - Codex에 중간 중단 감시 해제를 요청하면 기존 해제 명령 대행, PowerShell 직접 입력 불필요
  - Windows 11 x64·Codex26.1013.4894.0·26.1016.6573.0 지원, 감시는 선택형. 다른 운영체제·원격·클라우드의 직접 중단 미지원
  - 감지 전 추가 사용량 소비 가능, 서버 처리·사용량 반영의 동시 종료 보장 제외
