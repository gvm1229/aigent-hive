# Aigent Hive 0.15.3

## English

### Scope

- [SCOPE-01] `hive knowledge remember --batch <facts.json>` records up to eight facts from one turn in one commit. One rejected fact cancels the batch.
- [SCOPE-02] Each fact carries one optional subject, such as `design/visual-style`. `hive knowledge subjects list` shows existing subjects before capture.
- [SCOPE-03] A matching fact returns up to 16 more facts of its subject. `--top-k` counts these groups and marks a truncated group.
- [SCOPE-04] The knowledge-recall Skill reads subject groups first and runs at most two follow-up lookups with host-supplied query expansions.
- [SCOPE-05] Existing knowledge receives subjects through a rule-based preview, host review, confirmation and restore.
- [SCOPE-06] Search words of two or more Korean characters, or four or more ASCII letters, also match longer stored words.

### Compatibility

- [COMPAT-01] Upgrade from public 0.15.2 and earlier supported versions keeps user answers, knowledge and project files.
- [COMPAT-02] Single-fact `--user-statement` and `--request` capture keep their inputs, outputs and exit codes. Claims without a subject stay readable.
- [COMPAT-03] Hive 0.15.2 and earlier refuse a knowledge store that holds a claim with a subject. Downgrade after subject capture is unsupported.

### Verification

- [VERIFY-01] Rust and Python tests cover batch capture and rollback, subject schema migration, subject-group retrieval and the frozen OVX-002 query set with fake host runners.
- [VERIFY-02] Public 0.15.3-test.1 acceptance and real host checks on the maintainer PC are recorded in the release evidence.

### Publication

- [PUB-01] Stable 0.15.3 promotes the accepted 0.15.3-test.1 product.

## 한국어

### 범위

- [SCOPE-01] `hive knowledge remember --batch <facts.json>`으로 한 턴의 사실 최대 8개를 한 번에 기록. 사실 하나라도 거부되면 묶음 전체 취소.
- [SCOPE-02] 사실마다 선택 주제 1개(예 `design/visual-style`). 기록 전 `hive knowledge subjects list`로 기존 주제 확인.
- [SCOPE-03] 적중 사실의 주제에 속한 사실을 최대 16개 더 반환. `--top-k`는 묶음 수 기준, 잘린 묶음 표시.
- [SCOPE-04] knowledge-recall Skill의 주제 묶음 우선 조회와 호스트 확장어를 쓴 후속 조회 최대 2회.
- [SCOPE-05] 기존 지식의 규칙 기반 주제 미리보기·호스트 검토·확인·복원.
- [SCOPE-06] 한국어 2자 이상 또는 ASCII 4자 이상 검색어의 더 긴 저장 단어 일치.

### 호환성

- [COMPAT-01] 공개 0.15.2·이전 지원 버전에서 사용자 답변·지식·프로젝트 파일 보존 갱신.
- [COMPAT-02] 단일 사실 `--user-statement`·`--request` 기록의 입력·출력·종료 코드 유지. 주제 없는 기존 사실 읽기 유지.
- [COMPAT-03] 주제가 있는 사실을 담은 지식 저장소는 Hive 0.15.2 이하에서 거부. 주제 기록 뒤 하위 버전 되돌림 미지원.

### 검증

- [VERIFY-01] 가짜 호스트 실행기로 묶음 기록·되돌림, 주제 스키마 이전, 주제 묶음 회수, 고정 OVX-002 질의집의 Rust·Python 시험.
- [VERIFY-02] 공개 0.15.3-test.1 수용과 유지관리자 PC 실제 호스트 확인의 출시 근거 기록.

### 게시

- [PUB-01] 공개 시험 0.15.3-test.1 수용 제품의 정식 0.15.3 승격.
