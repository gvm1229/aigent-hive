# Aigent Hive 0.17.0

## English

### Scope

- [SCOPE-01] Apollon now owns knowledge and Demeter owns writing. During 0.17.x, old calls such as `hive demeter knowledge` print a notice and still run.
- [SCOPE-02] New Aphrodite role for web design, with the `design-curate` Skill and a bundled design suite synced weekly with its sources.
- [SCOPE-03] `autonomous-workflow` replaces `verified-workflow`: work continues without mid-task questions and real questions are asked once at the end.
- [SCOPE-04] `code-polish` is `ai-slop-cleaner` again and covers code, documents and design. It shows a fix plan before editing.
- [SCOPE-05] Global setup asks for the preview browser: the default Chromium-based browser or the in-app browser. Agents reuse the active browser tab.

### Compatibility

- [COMPAT-01] Upgrade from public 0.16.1 and earlier supported versions keeps user answers, knowledge, project registrations and project files.
- [COMPAT-02] Old Skill names `verified-workflow` and `code-polish` point to their replacements.

### Verification

- [VERIFY-01] Rust and conformance tests cover the role swap, old-call notices, the renamed Skills, bundled source bytes and browser detection.
- [VERIFY-02] Public 0.17.0 test acceptance and checks on the maintainer PC are recorded in the release evidence.

### Publication

- [PUB-01] Stable 0.17.0 promotes the accepted 0.17.0 test product.

## 한국어

### 범위

- [SCOPE-01] Apollon은 지식, Demeter는 글쓰기 담당으로 교체. 0.17.x 동안 `hive demeter knowledge` 같은 옛 호출은 한 줄 안내 뒤 새 담당으로 실행.
- [SCOPE-02] 웹 디자인 담당 Aphrodite와 `design-curate` Skill 추가. 지시 충돌을 정리한 디자인 묶음 동봉, 매주 원본에 맞춰 갱신.
- [SCOPE-03] `verified-workflow`를 `autonomous-workflow`로 교체. 중간 질문 없이 진행하고 진짜 질문은 마지막에 한 번.
- [SCOPE-04] `code-polish`를 `ai-slop-cleaner`로 이름 복원, 대상을 코드·문서·디자인으로 확대. 수정 전 정리 계획을 보여 주고 확인 뒤 수정.
- [SCOPE-05] 전역 설정에서 미리 보기 브라우저 선택: Chromium 계열 기본 브라우저 또는 앱 내장 브라우저. 따로 말하지 않으면 지금 보고 있는 탭에서 작업.

### 호환성

- [COMPAT-01] 공개 0.16.1과 이전 지원 버전에서 갱신 시 사용자 답변·지식·프로젝트 등록·프로젝트 파일 보존.
- [COMPAT-02] 옛 Skill 이름 `verified-workflow`·`code-polish`는 새 이름으로 안내.

### 검증

- [VERIFY-01] Rust·적합성 시험: 역할 교체, 옛 호출 안내, 이름이 바뀐 Skill, 동봉 원본 바이트, 브라우저 판별.
- [VERIFY-02] 0.17.0 공개 시험 수용과 유지관리자 PC 확인은 출시 근거에 기록.

### 게시

- [PUB-01] 정식 0.17.0은 수용된 0.17.0 시험 제품을 승격.
