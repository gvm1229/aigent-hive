# Aigent Hive v0.10.2 업데이트 내역:

- **`hive update` 하나로 전역 Hive 설치 갱신 개선**
  - 실행 파일이 이미 최신이어도 Hive가 관리하는 사용자 설정과 선택한 호스트의 Skill 투영을 다시 확인하고 갱신
  - npm 최초 설치 뒤 `hive update`에서 사용할 호스트를 선택하면 최소 설정 안내 준비, 프로젝트 harness는 대상에서 제외

- **새로운 전역 선택을 답하기 전 일반 작업 대기**
  - 벡터 검색처럼 저장 공간이나 이후 동작에 영향을 주는 새 질문은 다음 호스트 대화에서 먼저 답변
  - “예”와 “아니요” 모두 유효, 취소하거나 답하지 않으면 선택이 필요한 변경을 임의 적용하지 않고 대기

- **설정·복구 안내를 필요한 작업별로 정리**
  - 언어 하나만 바꾸는 요청에는 전체 설정을 다시 묻지 않고 지정한 값과 관련 선택만 확인
  - 설치 소유권을 증명하지 못하면 파일을 자동 제거하지 않고 원인을 먼저 확인

- **작업 지속과 Skill 선택 개선**
  - 조사로 해결할 수 있는 시험 실패나 누락 자료는 사용자에게 같은 승인을 다시 요구하지 않고 계속 처리
  - 프롬프트 작성 요청과 실제 구현 요청을 구분하고, 모호한 구현의 승인 대기 프롬프트 자동 변환 금지
