# Aigent Hive v0.15.0 업데이트 내역:

## 새 기능

- **0.15.0 안내 정정 — 신 이름으로 고르는 작업 입구 9개 추가**
  - 기존 기능을 할 일별 이름으로 모아, 필요한 기능을 찾기 쉽게 구성. 대화창에 아래 예시처럼 이름과 할 일을 직접 입력해 호출
  - **Athena·아테나**: 계획과 별도 리뷰. `아테나, 로그인 기능 계획`
  - **Artemis·아르테미스**: 자료 조사와 문제 진단. `아르테미스, 이 오류 원인 조사`
  - **Hephaistos·헤파이스토스**: 저장한 계획의 구현과 코드 정리. `헤파이스토스, 이 계획 구현`
  - **Apollon·아폴론**: 글쓰기와 요청문 다듬기. `아폴론, 이 글 다듬기`
  - **Eileithyia·에일레이티이아**: Hive 설정과 업데이트. `에일레이티이아, 이 프로젝트 Hive 설정`
  - **Poseidon·포세이돈**: 여러 작업의 역할 배정과 인계. `포세이돈, 작업 역할 배정`
  - **Demeter·데메테르**: 지식 저장·검색·다른 컴퓨터로 이전. `데메테르, 저장한 지식 검색`
  - **Aither·아이테르**: 사용량 확인과 보호 기준 관리. `아이테르, 사용량 보호 기준 확인`
  - **Hades·하데스**: 저장 공간 확인과 정리 미리보기. `하데스, 정리할 파일 미리보기`
  - 한글 이름과 Apollo·Minerva 등의 별칭 지원, 호출한 신과 맡은 일 표시. 기존 명령·기능 호출 방법 유지, 이름 없는 요청의 신 자동 선택 없음

- **프로젝트별 역할 설정 추가, 맡은 일마다 모델과 작업 수준 선택**
  - 전역 기본값을 두고 프로젝트별로 다르게 설정, 직접 고정한 기존 모델 선택 보존. 재시작 없이 다음 요청에서 변경한 역할 설정 읽기
  - `아테나, 이 프로젝트 역할별 모델 구성 확인`으로 요청하거나 `hive roster`에 대상 폴더·홈 폴더를 지정해 구성 확인
  - `hive roster check`로 앱이 제공한 버전·모델·로그인 상태 자료 확인. 설정만으로 작업자 자동 실행 불가

- **작업 전달 전 내용을 살펴보는 `hive summon` 미리보기 추가**
  - 역할·모델·할 일·결과를 둘 위치를 한데 모아 확인하는 기능. `포세이돈, 이 작업 전달 내용 미리보기`로 요청
  - 승인된 요청만 전달 준비용 수신함에 저장. Hive의 모델 호출·작업자 직접 실행 없음
  - **작업자 자동 실행은 꺼져 있으며 이번 버전에서 켜는 경로 없음.** 미리보기와 전달 준비까지만 사용 가능
