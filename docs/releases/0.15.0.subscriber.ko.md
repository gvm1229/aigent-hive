# Aigent Hive v0.15.0 업데이트 내역:

## 새 기능

- **작업별 입구 9개 추가, 신 이름으로 필요한 기능 선택**
  - 아테나의 계획·검토, 아르테미스의 조사, 헤파이스토스의 구현처럼 이름으로 관련 기존 기능에 진입
  - 한글 이름과 Apollo·Minerva 등의 별칭 지원, 지금 사용하는 신과 맡은 일 표시
  - 기존 명령과 Skill 경로도 계속 사용 가능

- **프로젝트마다 역할의 모델·작업 수준을 정하는 역할 설정 추가**
  - 전역 기본값에 프로젝트 설정을 덮어쓰기, 기존에 직접 고정한 모델 설정 보존
  - `hive roster`로 구성 확인, `hive roster check`로 호스트가 제공한 버전·모델·로그인 상태 자료 검사
  - 설정만으로 작업자 자동 실행 불가. 이번 버전의 자동 조율은 비활성이며 켜는 경로 없음

- **실행 전 작업 내용을 확인하는 `hive summon` 미리보기 추가**
  - 역할·모델·작업 내용·결과 위치를 담은 작업 봉투 확인, 서명된 준비 요청으로 수신 상자에 저장
  - Hive의 모델 호출·작업자 실행 없음. Gemini와 실제 호스트 취소·재점유의 사용 가능 보장 제외
