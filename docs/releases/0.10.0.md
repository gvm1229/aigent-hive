# Aigent Hive 0.10.0

## English

### Scope

- [DIR10-01] Route source and consumer agent rules through one canonical owner for each rule family.
- [CON10-01] Continue agent-owned work through bounded host-native closure and optional Stop hooks.
- [VWF10-01] Replace Ralph Loop and iterative execution with the evidence-gated verified workflow.
- [SKM10-01] Remove authenticated retired Skill artifacts during every supported direct upgrade.
- [JDG10-01] Validate clean-context adversarial Judge launch and result receipts before quorum.
- [KRG10-01] Add native Markdown relations and an optional receipt-bound Graphify code adapter.
- [VEC10-01] Defer the vector adapter after the 50,000-document embedding build exceeded ten minutes.
- [KOR10-01] Apply guarded Korean revision by default and add the explicit `humanize-kor` Skill.
- [KOR10-02] Pin an inspectable Korean language pack with staged update and rollback support.
- [KOR10-03] Consume activated rules, reject invalid packs, preserve negative claims, and upgrade directly from the prior public test.

### Compatibility

- [COMPAT-01] Keep Markdown as canonical knowledge and SQLite FTS as the direct fact search engine.
- [COMPAT-02] Preserve canonical knowledge, project settings, and foreign bytes during upgrade and rollback.
- [COMPAT-03] Keep provider APIs, provider credentials, background services, and automatic package installation outside Hive.
- [COMPAT-04] Preserve quotations, code, commands, links, numbers, and provenance during Korean revision.

### Verification

- [VERIFY-01] Run Rust, Python, documentation, security, historical upgrade, rollback, and package checks.
- [VERIFY-02] Accept the exact public test artifacts on Windows x64, macOS arm64, and Linux musl x64.
- [VERIFY-03] Run thirty relationship questions with direct fact, scope isolation, and fallback checks.
- [VERIFY-04] Check Korean meaning preservation, three host projections, upgrades, and language pack rollback.

### Publication

- [PUBLISH-01] Publish `0.10.0-test.4` without changing the npm `latest` tag.
- [PUBLISH-02] Do not create a stable candidate or publish version `0.10.0` without explicit maintainer approval.
