# Aigent Hive `0.8.0` 제품 후보

> 상태: npm 시험 배포 후보
>
> 제품 버전: `0.8.0`
>
> 최초 npm 시험판: `0.8.0-test.1`

## 배포 성격

- 목적: 실제 안정 배포 전 설치·업데이트·host 연동 검증
- npm 배포: `test` 배포 표지만 사용
- GitHub Release·prerelease·release tag 생성 없음
- npm `latest` 이동 없음
- 시험 배포 성공 뒤 `develop` → `main` pull request

## 주요 변경점

- Windows x86_64, macOS arm64·x86_64, Linux musl arm64·x86_64 native package
- `npm install -g aigent-hive@0.8.0-test.1` 전역 설치
- npm registry 기반 Unix `curl`, Windows PowerShell 5.1·`cmd.exe` 직접 설치
- 첫 설정의 English·한국어 선택과 이후 질문·전역 지침의 선택 언어 유지
- 명시적 동의 기반 일 1회 업데이트 확인과 offline 뒤 다음 세션 재시도
- 설치 소유자 검증과 사용자 확인을 거치는 `hive update`
- 사용자 전역 설정, 자동 project onboarding과 user-root 공유 SQLite index
- `docs/` Wiki와 영어·한국어 원자 fact
- 5개 native archive·6개 npm tarball의 SHA-256·GitHub attestation·byte identity gate

## 시험 설치

npm:

```console
npm install -g aigent-hive@0.8.0-test.1
```

Unix:

```sh
curl --proto '=https' --tlsv1.2 -LsSf \
  https://unpkg.com/aigent-hive@0.8.0-test.1/install.sh | sh
```

Windows PowerShell 5.1 이상:

```powershell
irm https://unpkg.com/aigent-hive@0.8.0-test.1/install.ps1 | iex
```

Windows `cmd.exe`:

```bat
curl.exe -fLo install-aigent-hive.cmd https://unpkg.com/aigent-hive@0.8.0-test.1/install.cmd && install-aigent-hive.cmd
```
