# Aigent Hive v0.16.0 업데이트 내역:

## 새 기능

- **바꾸기 전에 자동 백업**
  - 설치·갱신·제거 전에 설정, 프로젝트 목록, 바뀔 파일을 `~/hive-backups`에 복사
  - `hive storage backup list`로 확인, `hive storage backup restore --id <번호>`로 복원 미리보기
  - 지식 전체와 `hive setup` 변경은 백업 범위 밖, 백업은 자동 삭제 없음

- **AI끼리 일을 주고받는 파일 수신함(실험)**
  - `hive msg`로 작성·검토·자문 역할 사이에 일과 결과 전달
  - `hive stop`으로 새 전달 중지, 다른 AI의 직접 실행은 Hive 범위 밖
  - 끝나면 Discord에 작업·결과·맡은 역할·실제로 일한 모델·걸린 시간을 알림, 알림마다 구분선
  - 이 버전의 Codex 연동은 실제 앱에서 미검증

- **Claude 사용량 읽기**
  - `hive setup --scope user --section usage --claude-statusline preview`로 확인한 뒤 상태 표시줄에 연결
  - 터미널의 Claude Code에서 사용, 데스크톱 Code 탭은 미확인

- **요청마다 내 선호를 먼저 찾아보기(Claude Code)**
  - 요청을 보내면 Hive가 저장된 지식에서 관련 선호·규칙을 찾아 함께 전달
  - 아무것도 바꾸거나 저장하지 않고, 찾지 못하면 그냥 넘어감
  - 끄기: 환경 변수 `HIVE_KNOWLEDGE_PROMPT_CONTEXT=off`

## 수정

- **갱신 중 자료 손실과 실패 수정**
  - 0.15.x의 Claude·Antigravity 설치를 `hive update`가 그대로 인식
  - 재설치가 필요해도 프로젝트 목록·실행 상태·백업 보존

- **헷갈리던 사용량 표시 수정**
  - Claude는 사용한 %, Codex·Antigravity는 남은 %로 표시와 입력
  - 사용량을 읽지 못하면 원인과 해결 방법을 알리고 작업 계속
  - 읽기 실패인데 사용량 회복을 기다리라던 Discord 안내 제거

- **Windows의 `--target .` 오류 수정**

## 개선

- **짧아진 Skill 목록**
  - 지식 관리·이어 하기·판정 Skill을 `knowledge-manage`·`run`·`judge`로 통합
  - Claude Code에서 옛 `/aigent-hive:...` 이름은 실행되지 않으므로 새 이름 사용

- **여러 AI에 설치했다면 새 Skill도 모두에게**
  - Codex·Claude를 함께 쓰면 새 프로젝트 Skill을 양쪽 폴더에 같은 내용으로 작성
  - 한 AI에만 설치했다면 지금처럼 그 AI용만 작성

- **주의: 0.15.x로 내리기 전**
  - Claude 상태 표시줄 연결을 먼저 되돌리기
  - 0.15.x 재설치 시 `~/.hive/backups`와 프로젝트 목록 삭제 위험
  - Antigravity 1.2의 사용량 연동은 실제 앱에서 미검증
