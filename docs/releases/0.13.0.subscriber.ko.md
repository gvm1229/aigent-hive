# Aigent Hive v0.13.0 업데이트 내역:

## 새 기능

- **사용량 초기화 뒤 실행 중인 Codex 작업의 중단 기능 추가**
  - 새 할당량이 계속 쓰이는 상황을 줄이도록, 실제 초기화 감지 시 진행 중인 대화 작업에 한 차례 중단 요청
  - 별도 감시기의 15초 간격 조회, 정상 조회가 60초 동안 없을 때도 보호를 위한 중단
  - Codex 앱과 저장한 파일 유지, 잠금 없이 Codex에서 직접 재개하거나 새 메시지로 작업 시작
  - Windows 11 x64·Codex 26.1013.4894.0 지원, 감시 활성화 필요. 다른 운영체제·원격·클라우드 작업 중단은 지원 범위 제외
  - 감지 전 새 사용량 소비 가능, 서버 처리·사용량 반영의 동시 종료 보장 제외

- **작업이 멈춘 이유를 알려 주는 별도 알림 창 추가**
  - Aigent Hive 공식 로고와 함께 초기화 감지·조회 실패의 원인, 중단 확인 상태와 감지 시각 표시
  - 닫기만 제공하는 안내 전용 창, 창 닫기와 작업 재개는 별개
