## English

### Scope

- [SCOPE-01] Recognize Antigravity quota callbacks in configured projects; reject missing, expired or mismatched data. Actual use requires a qualified status-line connection.
- [SCOPE-02] Keep saved knowledge intact if optional relationship analysis fails; review relationship candidates with source evidence on supported hosts.
- [SCOPE-03] Show unverified host control separately. Automatic interruption and strict delegation remain disabled without qualified connections.
- [SCOPE-04] Distinguish search helper startup, timeout, output, exit and response failures without exposing raw diagnostic text.
- [SCOPE-05] Summarize token records without double-counting cached input or included child usage. Measurements do not enforce a hard runtime cap.

- [SCOPE-06] Block new Hive work at zero quota despite ordinary guard disable. Require a separate session opt-out; exclude active calls and billing settings.

### Compatibility

- [COMPAT-01] Preserve original Markdown, existing search, vectors and user settings. Optional relationships start disabled and require scope approval.
- [COMPAT-02] Project upgrades from fixed 0.9.1 through 0.11.1 public stable samples preserve local edits and foreign files; other configurations require qualification.

### Verification

- [VERIFY-01] Windows development builds pass quota, graph, helper diagnostics and knowledge preservation checks. Actual host activation remains separately qualified.
- [VERIFY-02] Fixed source questions pass 30/30 facts and 30/30 explicit relations; cold CLI p95 is 0.47 seconds, within the two-second criterion.
- [VERIFY-03] A Windows corpus contains 50,000 distinct chunks. Measurements cover indexing and bounded analysis input preparation, excluding full model analysis.

### Publication

- [PUB-01] Unpublished draft for the planned 0.12.0-test.1. Stable publication and current user installation require separate version-specific approval.

## 한국어

### 범위

- [SCOPE-01] 설정한 프로젝트에서 Antigravity 사용량 수신값 확인, 누락·만료·다른 계정이나 대화의 자료 거부. 실제 사용은 검증된 상태 표시 연결 필요
- [SCOPE-02] 선택한 관계 분석이 실패해도 저장한 지식 보존, 지원 호스트에서 원문 근거와 함께 관계 후보 검토
- [SCOPE-03] 확인하지 못한 호스트 제어 기능을 별도 표시. 검증된 연결 없는 자동 중단·엄격한 작업 분담은 비활성 유지
- [SCOPE-04] 검색 도우미의 시작·시간 초과·출력·종료·응답 오류 구분, 진단 원문 노출 없는 원인 확인
- [SCOPE-05] 캐시 입력·부모에 포함된 자식 사용량의 중복 없는 토큰 기록 합산. 실제 실행의 엄격한 사용 상한 보장과 별도인 계측

- [SCOPE-06] 일반 보호 해제 뒤에도 구독 잔여 0%에서 새 Hive 작업 차단, 별도 대화 한정 제외 필요. 진행 중 호스트 호출·유료 설정의 제어와 구분
