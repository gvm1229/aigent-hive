# Aigent Hive 0.12.0

## English

### Scope

- [SCOPE-02] Validate knowledge relationships against source evidence and access permissions. Preserve saved documents and existing search when relationship processing fails.
- [SCOPE-04] Explain search startup, timeout, invalid-response and abnormal-exit failures more clearly. Preserve the previous healthy search index.
- [SCOPE-06] Block new Hive work when any observed quota window reaches zero, even with ordinary protection disabled. Enable by default with explicit session-only opt-out.

### Compatibility

- [COMPAT-01] Preserve original Markdown, existing search, vectors and user settings. Relationship features remain optional and require scope approval.
- [COMPAT-02] Updates from fixed public stable samples 0.9.1 through 0.11.1 preserve local edits and foreign files.
- [COMPAT-03] Distinguish test-generated project settings from stable compatibility targets. Preserve exact test-package origin; refuse unauthenticated conversions without changing settings.

### Verification

- [VERIFY-01] Accepted public test.3 passes isolated installation, updates, rollback, preservation and vectors on Windows x64, Linux musl x64 and macOS arm64.
- [VERIFY-02] Windows quota contracts verify zero-window blocking, ordinary-disable independence, explicit opt-out and reset handling before new Hive work.
- [VERIFY-03] Public test.3 validates package-origin preservation, tampering rejection, historical-test exclusion and stable predecessor preservation on three operating systems.

### Publication

- [PUB-01] Stable 0.12.0 uses accepted public test.3 as its release baseline, with completed user-facing features only.

## 한국어

### 범위

- [SCOPE-02] 지식 관계의 원문 근거·접근 권한 확인, 관계 처리 실패에도 저장한 문서·기존 검색 보존
- [SCOPE-04] 검색 시작·응답 지연·잘못된 응답·비정상 종료의 원인 안내 개선, 기존 정상 검색 색인 보존
- [SCOPE-06] 관측한 사용량 창 하나라도0%면 새 Hive 작업 차단, 일반 보호 해제와 독립인 기본 활성 보호·명시적 현재 대화 한정 제외

### 호환성

- [COMPAT-01] 원본 Markdown·기존 검색·벡터·사용자 설정 보존. 관계 기능은 사용자 선택·범위 승인 후 적용
- [COMPAT-02] 0.9.1~0.11.1 공개 안정판의 고정 프로젝트 표본에서 사용자 수정·외부 파일 보존 갱신 확인
- [COMPAT-03] 시험판이 만든 설정과 안정판 호환 대상 구분. 정확한 시험판 출처 보존, 검증할 수 없는 변환은 설정 변경 없이 거부

### 검증

- [VERIFY-01] 수용한 공개test.3의 Windows x64·Linux musl x64·macOS arm64 격리 설치·갱신·원복·보존·벡터 검사 통과
- [VERIFY-02] Windows 사용량 계약의0% 차단·일반 보호 해제와의 독립·명시적 제외·초기화 처리 검증, 새 Hive 작업의 시작 전 적용 범위
- [VERIFY-03] 공개test.3의 세 운영체제 출처 보존·변조 거부·과거 시험판 제외·이전 안정판 보존 검사 통과
