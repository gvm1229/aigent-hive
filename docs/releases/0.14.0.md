# Aigent Hive 0.14.0

## English

### Scope

- [SCOPE-01] Configure user and project settings through local CLI questions without model calls.
- [SCOPE-02] Reuse saved choices and resume interrupted setup without replacing user notes or role assignments.
- [SCOPE-03] Start new installations with automatic usage stops disabled; review existing choices before changing protection.
- [SCOPE-04] Preview program removal paths and retained knowledge, preferences and history before confirmation.

### Compatibility

- [COMPAT-01] Update targets include public 0.13.1 and the exact 0.13.2-test.2 package. Existing files still require complete ownership verification.
- [COMPAT-02] Downloads, hooks, external notifications and live monitor interruption retain separate consent requirements.
- [COMPAT-03] Existing answer files remain supported. New setup records distinguish explicit choices, defaults, inheritance and unknown historical origins.

### Verification

- [VERIFY-01] Windows disposable roots and fake applications cover setup preservation, input cancellation, interrupted application and same-operation recovery.
- [VERIFY-02] Native installation, live monitor control, three-OS acceptance and Luna cost qualification remain pending for 0.14.0.

### Publication

- [PUB-01] Unpublished development draft. Public stable distribution remains 0.13.1; the next numbered public test is 0.14.0-test.1.
- [PUB-02] Stable integration, publication, personal installation and announcements require separate approval for this version.
