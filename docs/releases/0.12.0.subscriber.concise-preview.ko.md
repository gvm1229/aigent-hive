# Aigent Hive v0.12.0 업데이트 내역:

## 새 기능

- **구독 잔여 0% 보호 기능 추가**
  - 사용량 창 하나라도 잔여 0%면 새 Hive 작업 차단, 일반 사용량 보호 해제와 별도로 유지
  - 기본 활성, 별도 확인 후 현재 대화에서만 제외 가능. 새 대화에서는 다시 기본 활성
  - Hive의 실행 전 검사를 거치는 새 작업에 적용, 사용량 확인 불가·측정값 만료 시에도 차단

---

## 수정

- **시험판 설정을 안정판으로 잘못 구분하던 갱신 오류 수정**
  - 시험판 설정의 출처 확인, 이전 안정판 설정으로 잘못 처리하는 문제 수정
  - 출처 확인 불가 시 기존 설정 보존과 이유 안내. 이전 버전 자동 갱신의 호환 대상은 공개 안정판, 시험판 제외

---

## 개선

- **지식 그래프의 관계 검증·저장 보호 개선**
  - 관계 반영 전 원문 근거·접근 권한 확인, 삭제·변경된 문서의 오래된 관계 조회 방지
  - 관계 처리 실패에도 저장 원문·기존 검색 보존, 새 결과 검증 전까지 기존 정상 그래프 유지
  - 사용자가 선택한 범위에 적용, 기존 설치의 자동 활성화 없음

- **검색 오류 안내 개선**
  - 검색 실패·응답 지연의 원인 안내 개선
  - 오류 발생 시에도 기존 검색 데이터 보존
