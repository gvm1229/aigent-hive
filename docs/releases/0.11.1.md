# Aigent Hive 0.11.1

## English

### Scope

- [SCOPE-01] Codex receives built-in Hive Skills through the active verified plugin; duplicate user and project copies are removed during their respective updates.
- [SCOPE-02] Cleanup is part of update, without a separate command or confirmation prompt.

### Compatibility

- [COMPAT-01] Preserve customized Skills, companion resources and foreign files; report remaining duplicates and reasons.
- [COMPAT-02] Keep project-only Skills local. Project update restores local delivery when plugin verification fails.
- [COMPAT-03] Keep Claude and Antigravity dedicated delivery paths. Global update does not modify consumer projects.

### Verification

- [VERIFY-01] Public 0.11.1-test.1 passes update and recovery checks on Windows x64, Linux musl x64 and macOS arm64, with simulated Codex registration.
- [VERIFY-02] Actual Codex Skill discovery and invocation remain unverified. Current user installation and a fresh session require separate approval.

### Publication

- [PUB-01] Publish and accept 0.11.1-test.1 on the test channel. The stable channel remains 0.11.0. Stable publication requires version-specific approval.
