# Aigent Hive 0.11.1

## English

### Scope

- [SCOPE-01] Codex receives built-in Hive Skills through the active verified plugin; duplicate user and project copies are removed during their respective updates.
- [SCOPE-02] Cleanup is part of update, without a separate command or confirmation prompt.
- [SCOPE-03] Fix Windows Claude user installation by passing host-compatible paths to plugin commands.
- [SCOPE-04] Improve safe installation diagnostics and setup recovery guidance; retain previous answers when question tools fail.
- [SCOPE-05] Adapt imported directives into independent rules for the target project, including paths, linked documents and authority.
- [SCOPE-06] Offer 23 default project Skills, editable selection and relevant natural-language invocation. Wiki-disabled projects start with 18.
- [SCOPE-07] Combine new Hive Skill improvements with user rules and companion settings through a reviewed preview and exact approval.

### Compatibility

- [COMPAT-01] Preserve customized Skills, companion resources and foreign files; report remaining duplicates and reasons.
- [COMPAT-02] Keep project-only Skills local. Project update restores local delivery when plugin verification fails.
- [COMPAT-03] Keep Claude and Antigravity dedicated delivery paths. Global update does not modify consumer projects.
- [COMPAT-04] Propose new defaults once for legacy projects. Preserve later choices, including an empty selection; retain changed and external Skills.

### Verification

- [VERIFY-01] Public test.7 updates, preservation and recovery pass on Windows x64, Linux musl x64 and macOS arm64; Codex registration remains simulated in these checks.
- [VERIFY-03] Public test.7 and actual Claude 2.1.163 pass Windows installation, validation, reinstall and update, including spaces and Korean paths. Interactive Skill use remains unverified.
- [VERIFY-02] Windows Codex 0.159.0 installation/discovery passed: 28 unique Skills. User confirmed restart and global user-setup calls; project-selected Skill invocation remains unverified.

### Publication

- [PUB-01] Stable 0.11.1 approved; public test.7 accepted. Complete approved user installation, project merging and actual project Skill invocation before promotion. Keep latest at 0.11.0 until publication.
