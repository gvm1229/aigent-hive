# Aigent Hive 0.11.0

## English

### Scope

- [SCOPE-01] Add optional checks before file edits to help prevent changes that break project rules.
- [SCOPE-04] Work together on the same project whether or not each collaborator installs Hive.
- [SCOPE-05] Request project guidance updates in ordinary language, or preview changes before applying them.
- [SCOPE-06] Update project guidance from older stable versions while retaining settings and personal guidance.

### Compatibility

- [COMPAT-01] Keep existing features, commands, and saved knowledge when updating.
- [COMPAT-02] Support project guidance updates from every public stable version since 0.9.1; numbered test versions are outside this guarantee.
- [COMPAT-03] Check the current conversation and running program before automatically continuing interrupted work; retain manual resume.
- [COMPAT-04] Read transferred knowledge even without its original files, with a visible warning that its current accuracy remains unverified.
- [COMPAT-05] Turn reset-triggered stops off or on for the current conversation; protection against low remaining usage stays active.
- [COMPAT-06] Automatic file-edit checks are verified for tested Windows Codex and Antigravity actions. Claude support remains unverified.
- [COMPAT-07] Automatic blocking is not guaranteed for disabled or unresponsive checkers, invalid settings or responses, or terminal commands. Periodic usage monitoring remains excluded.
- [COMPAT-08] Collaborators without Hive keep their existing tools. Hive execution errors or protection stops still block the affected Hive-enabled action.
- [COMPAT-09] Fix updates incorrectly rejected for some projects configured with 0.10.3.
- [COMPAT-11] Fix missing project guidance after Windows updates while preserving personal additions.

### Verification

- [VERIFY-01] Windows Codex verified finding the installed update Skill, ordinary-language requests, previews without edits, and updates that preserve personal changes.
- [VERIFY-02] Upgrade checks cover official Codex project samples from all nine previous stable releases, not every possible configuration.
- [VERIFY-03] Published packages passed Windows, macOS, and Linux checks. Failure recovery passed on Windows and Linux.
- [VERIFY-04] A separate macOS search check passed after a failed first attempt; the original failure cause remains unconfirmed.

### Publication

- [PUB-01] Preview for the upcoming 0.11.0 stable release. Verified test build: 0.11.0-test.7. The current public stable release remains 0.10.3.
- [PUB-02] Stable release, publication, and installation still require explicit approval for 0.11.0.

## 한국어

### 범위

- [SCOPE-01] 프로젝트 규칙을 어기는 파일 수정을 줄이도록, 편집 전 자동 검사 기능 추가
- [SCOPE-04] 협업자마다 Hive 설치 여부가 달라도 같은 프로젝트에서 함께 개발 가능
- [SCOPE-05] 말로 요청하는 프로젝트 지침 업데이트, 적용 전 변경 내용만 미리 확인 가능
- [SCOPE-06] 오래 사용한 정식 버전에서도 기존 설정과 직접 작성한 지침을 지키며 프로젝트 지침 업데이트

### 호환성

- [COMPAT-01] 업데이트 뒤에도 기존 기능·명령과 저장한 지식 유지
- [COMPAT-02] 0.9.1 이후 모든 공개 안정판의 프로젝트 지침 업데이트 지원, 번호 공개 시험판은 이 보장 범위에서 제외
- [COMPAT-03] 중단한 작업을 자동으로 이어가기 전 현재 대화·실행 프로그램 확인, 수동 재개도 유지
- [COMPAT-04] 다른 곳에서 가져온 지식은 원본 파일이 없어도 조회 가능, 최신 내용인지 확인되지 않았다는 표시 유지
- [COMPAT-05] 사용량 한도가 새로 채워질 때 멈추는 동작을 현재 대화에서 끄거나 다시 켜기, 잔여 사용량 부족에 대한 보호는 유지
- [COMPAT-06] 파일 편집 자동 검사는 Windows Codex·Antigravity에서 시험한 동작에 한정, Claude 지원은 미확정
- [COMPAT-07] 검사기 비활성·응답 없음·설정이나 응답 오류·터미널 명령에는 자동 차단 보장 제외, 일정 간격의 사용량 감시는 이번 버전에서 제외
- [COMPAT-08] Hive가 없는 협업자는 기존 도구 그대로 사용, Hive 사용 중 실행 오류나 보호 기능 중단 시 해당 작업 차단 유지
- [COMPAT-09] 0.10.3으로 설정한 일부 프로젝트에서 정상 설정을 잘못 판단해 업데이트가 막히던 문제 수정
- [COMPAT-11] Windows의 프로젝트 지침 업데이트 누락 수정, 직접 작성한 내용 보존

### 검증

- [VERIFY-01] Windows Codex에서 설치된 업데이트 스킬 발견·말로 요청하기·파일을 바꾸지 않는 미리보기·사용자 수정 보존 확인
- [VERIFY-02] 이전 안정판 9개의 공식 Codex 프로젝트 표본으로 갱신 확인, 모든 설정 조합의 전수 검증은 제외
- [VERIFY-03] Windows·macOS·Linux의 공개 배포 파일 검사 통과, 실패 복구는 Windows·Linux에서 확인
- [VERIFY-04] macOS의 별도 검색 검사는 첫 실패 뒤 재실행 통과, 최초 실패 원인은 미확정

### 게시

- [PUB-01] 0.11.0 정식 출시 예정 안내. 검증한 시험판은 0.11.0-test.7, 현재 공개 안정판은 0.10.3
- [PUB-02] 0.11.0 안정판 출시·게시·설치는 별도 명시 승인 필요
