# Aigent Hive 0.11.0

## English

### Scope

- [SCOPE-01] Add optional hooks, automatic checks before supported AI file edits; these stop direct edits to designated protected files, beyond prior instructions alone.
- [SCOPE-07] Choose key instructions to restore after a long conversation is summarized, and preview the exact text before enabling it in Codex.
- [SCOPE-04] Work together on the same project whether or not each collaborator installs Hive.
- [SCOPE-05] Request project guidance updates in ordinary language, or preview changes before applying them.
- [SCOPE-06] Update project guidance from older stable versions while retaining settings and personal guidance.

### Compatibility

- [COMPAT-01] Keep existing features, commands, and saved knowledge when updating.
- [COMPAT-02] Support project guidance updates from every public stable version since 0.9.1; numbered test versions are outside this guarantee.
- [COMPAT-03] Check the current conversation and running program before automatically continuing interrupted work; retain manual resume.
- [COMPAT-04] Read transferred knowledge even without its original files, with a visible warning that its current accuracy remains unverified.
- [COMPAT-05] A quota reset found at the next usage check blocks new automatic work until the user acknowledges it. Reset detection can be turned off or on for the current conversation; protection against low remaining usage stays active. Running work is not interrupted in real time.
- [COMPAT-06] Hooks apply to tested Windows Codex and Antigravity AI file edits when enabled.
- [COMPAT-07] Terminal commands remain outside hook checks. Periodic usage monitoring is outside this release.
- [COMPAT-08] Collaborators without Hive keep their existing tools. Hive users keep their selected protection settings.
- [COMPAT-09] Projects configured with 0.10.3 support Hive guidance updates while retaining valid settings.
- [COMPAT-11] Windows project updates include current Hive guidance and retain personal additions.
- [COMPAT-12] Turn instruction recovery off and enable it again while retaining other tool settings.

### Verification

- [VERIFY-01] Windows Codex verified finding the installed update Skill, ordinary-language requests, previews without edits, and updates that preserve personal changes.
- [VERIFY-02] Upgrade checks cover official Codex project samples from all nine previous stable releases, not every possible configuration.
- [VERIFY-03] Published packages passed Windows, macOS, and Linux checks.

### Publication

- [PUB-01] Preview for the upcoming 0.11.0 stable release, with numbered public tests before stable publication. The current public stable release remains 0.10.3.
- [PUB-02] Stable release, publication, and installation still require explicit approval for 0.11.0.

## 한국어

### 범위

- [SCOPE-01] 선택해서 켜는 Hook 추가: AI가 파일을 바꾸기 직전 실행되는 자동 검사. 이전 버전의 지침 안내에 더해 미리 보호하도록 정한 파일의 직접 편집 차단
- [SCOPE-07] 긴 대화를 요약한 뒤 다시 알려줄 핵심 지침 선택, Codex에 켜기 전 정확한 문구 미리 확인
- [SCOPE-04] 협업자마다 Hive 설치 여부가 달라도 같은 프로젝트에서 함께 개발 가능
- [SCOPE-05] 말로 요청하는 프로젝트 지침 업데이트, 적용 전 변경 내용만 미리 확인 가능
- [SCOPE-06] 오래 사용한 정식 버전에서도 기존 설정과 직접 작성한 지침을 지키며 프로젝트 지침 업데이트

### 호환성

- [COMPAT-01] 업데이트 뒤에도 기존 기능·명령과 저장한 지식 유지
- [COMPAT-02] 0.9.1 이후 모든 공개 안정판의 프로젝트 지침 업데이트 지원, 번호 공개 시험판은 이 보장 범위에서 제외
- [COMPAT-03] 중단한 작업을 자동으로 이어가기 전 현재 대화·실행 프로그램 확인, 수동 재개도 유지
- [COMPAT-04] 다른 곳에서 가져온 지식은 원본 파일이 없어도 조회 가능, 최신 내용인지 확인되지 않았다는 표시 유지
- [COMPAT-05] 다음 사용량 점검에서 리셋 감지 시 새 자동 작업 중단, 사용자 확인 후 재개. 현재 대화에서 리셋 감지만 끄거나 다시 켜기 가능, 잔여 사용량 부족에 대한 보호 유지. 진행 중인 작업의 실시간 중단은 제외
- [COMPAT-06] Hook을 켠 Windows Codex·Antigravity의 지원되는 AI 파일 편집 동작에 적용
- [COMPAT-07] 터미널 명령은 Hook 검사 대상 밖, 일정 간격의 사용량 감시는 이번 버전 범위 밖
- [COMPAT-08] Hive가 없는 협업자는 기존 도구 그대로 사용, Hive 사용자는 선택한 보호 설정 유지
- [COMPAT-09] 0.10.3으로 설정한 프로젝트도 정상 설정을 유지하며 Hive 지침 업데이트 가능
- [COMPAT-11] Windows 프로젝트 업데이트에 현재 Hive 지침 반영, 직접 작성한 내용 보존
- [COMPAT-12] 지침 복구를 껐다가 다시 켜도 다른 도구의 설정 유지

### 검증

- [VERIFY-01] Windows Codex에서 설치된 업데이트 스킬 발견·말로 요청하기·파일을 바꾸지 않는 미리보기·사용자 수정 보존 확인
- [VERIFY-02] 이전 안정판 9개의 공식 Codex 프로젝트 표본으로 갱신 확인, 모든 설정 조합의 전수 검증은 제외
- [VERIFY-03] Windows·macOS·Linux의 공개 배포 파일 검사 통과

### 게시

- [PUB-01] 번호 공개 시험을 거치는 0.11.0 정식 출시 예정 안내, 현재 공개 안정판은 0.10.3
- [PUB-02] 0.11.0 안정판 출시·게시·설치는 별도 명시 승인 필요
