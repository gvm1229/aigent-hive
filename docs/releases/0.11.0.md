## English

- [SCOPE-01] Add deterministic policy checks and explicitly configured native file-edit hooks.
- [SCOPE-02] Refactor knowledge, installation, and plan-state responsibilities while preserving existing commands.

- [COMPAT-01] Retain existing features, canonical Markdown, and historical installation data.
- [COMPAT-02] Include the unreleased 0.10.4 usage-guard changes in 0.11.0.
- [COMPAT-03] Require the current host session ID and a positive process ID for automatic run resume; preserve manual recovery.
- [COMPAT-04] Keep transferred historical knowledge readable with an explicit unverified-source marker when original files are absent; retain integrity checks.
- [COMPAT-05] Add explicit session-bound reset-only opt-out and restoration while retaining threshold protection and pending reset acknowledgement.

- [COMPAT-07] Unloaded hooks, native timeouts, malformed responses or settings, and shell tools do not provide mandatory enforcement.

- [COMPAT-08] Preserve ordinary development without Hive, existing tools and user files; keep installed errors and approved protection failures blocking the affected action.
- [COMPAT-09] Authenticate real 0.10.3 project output with native ownership, formatter markers, and disabled-guard wording; retain historical bytes and reject mismatched authority.
