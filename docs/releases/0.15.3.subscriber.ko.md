# Aigent Hive v0.15.3 업데이트 내역:

## 새 기능

- **한 번의 대화에서 여러 기억을 함께 남기는 묶음 기록 추가**
  - 대화 하나에 디자인 취향·작업 방식처럼 여러 사실이 나오면 Hive 스킬이 최대 8개를 한 번에 저장
  - 하나라도 비밀값처럼 저장하면 안 되는 내용이면 전체를 저장하지 않아 일부만 남는 일 방지
  - 직접 쓸 때는 `hive knowledge remember --batch <facts.json>`

- **기억마다 주제를 붙이고 같은 주제를 함께 찾는 주제 묶음 회수 추가**
  - "HTML 디자인"처럼 관련 기억에 `design/visual-style` 같은 주제를 붙이면, 한 기억만 맞아도 같은 주제의 기억을 최대 16개 더 함께 반환
  - 기존 주제는 `hive knowledge subjects list`로 확인, 같은 기억을 주제와 함께 다시 말하면 중복 없이 주제만 갱신
  - 이미 쌓인 기억은 `hive knowledge subjects preview`로 주제 제안 확인 뒤 승인할 때만 적용, `restore`로 원래대로 복원

- **AI 에이전트가 대화로 진행하는 프로젝트 설정**
  - project-setup 스킬을 부르면 터미널 명령을 넘기지 않고 에이전트가 대화에서 설정을 진행
  - 빈 폴더는 프로젝트 내용·목표·개발 방식을 하나씩 물어본 뒤 제안, 기존 프로젝트는 파일을 살펴본 뒤 근거와 함께 제안
  - 확인한 제안만 적용하고, 역할·hook·선택 스킬의 임의 추가 없음
  - 능력 파일 없이 미리보기·적용·검증 가능, 설정이 멈춰도 에이전트가 이어 갈 명령 안내

- **앱마다 5시간·주간 한도를 따로 정하는 사용량 보호**
  - 사용량 설정에서 고른 앱마다 구독에 5시간 한도가 있는지 질문
  - 있으면 5시간만·주간만·둘 다 중 보호할 한도를 고르고, 둘 다면 기준을 각각 입력
  - Antigravity는 한도 구분 없이 기준 하나, Codex의 30일 사용량 창도 주간 한도로 측정

- **잘못 입력한 명령의 추천과 짧아진 도움말**
  - `hive instal`처럼 틀리게 입력하면 AI 없이 `혹시 이것인가요? install`과 예시 표시
  - `hive --help`는 시작하기·설정·지식·갱신·진단·고급 묶음의 짧은 목록

## 개선

- **짧은 한국어 검색어의 기억 찾기 개선**
  - `남색`으로 `남색과`를, `글꼴`로 `글꼴은`을 찾는 것처럼 조사가 붙은 저장 문장도 검색
  - 고정 시험 질의 40개 기준 찾은 기억 22개 → 32개, 관련 없는 질문에는 결과 0개 유지
  - 스킬이 한국어·영어 바꿔 쓴 검색어를 함께 전달하고, 부족하면 다른 검색어로 최대 2번 더 찾기

- **터미널 설정 화면 가독성 개선**
  - 질문마다 `[2/4] 프로젝트 이름` 같은 번호 붙은 제목, 도움말·선택지는 들여쓴 묶음, 지금 값에 `(현재값)` 표시
  - 적용 전 미리보기는 일반·기능·지식 경로·변경 규모 구역의 표, 빈 값은 `없음`
  - 색과 굵은 글씨는 터미널에서만, `NO_COLOR`를 설정하면 일반 문자

- **새로 설정한 프로젝트가 갱신 대상으로 잘못 표시되던 문제 수정**
  - 바꿀 파일이 없는데 `hive project upgrade --validate`가 실패하던 문제 해결
  - 실제로 바뀌는 파일이 있으면 파일마다 사유 표시

- **npm으로 새 버전 설치 뒤 `hive update`가 실패하던 문제 수정**
  - 이전 버전이 설치한 앱 연결을 그대로 인증해 갱신 진행
  - 갱신 중 문제가 생기면 Hive 파일을 지우지 않고 복구 명령 안내

- **설정 화면 다듬기**
  - 마지막 확인에서 `아니요`를 고르면 실패 대신 바뀐 것이 없다는 안내와 이어서 하는 명령 표시
  - 긴 문장은 80열 창 안에서 줄바꿈, 앱 상태 확인이 오래 걸리면 확인 중 안내 표시

- **주의: 주제를 붙인 뒤에는 0.15.2 이하로 되돌리기 미지원**
  - 주제가 붙은 기억이 하나라도 생기면 이전 버전 Hive가 지식 저장소를 읽지 못하므로 0.15.3 이상 유지
