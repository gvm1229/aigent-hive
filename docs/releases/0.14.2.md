# Aigent Hive 0.14.2

## English

### Scope

- [SCOPE-01] Remove old monitor copies larger than 1 MiB and no larger than 128 MiB after an update and with `hive prune --confirm`.

### Compatibility

- [COMPAT-01] Keep current and previous copies. Preserve files locked by Windows and copies that fail exact-byte verification.
- [COMPAT-02] Keep the existing 128 MiB input limit for monitor copies.

### Verification

- [VERIFY-01] Windows source tests passed for large files, changed bytes, locked files, automatic cleanup and the actual prune command.
- [VERIFY-02] Public 0.14.2-test.2 installation acceptance passed on Linux x64, macOS arm64 and Windows x64.

### Publication

- [PUB-01] Stable 0.14.2 uses the accepted 0.14.2-test.2 product.
