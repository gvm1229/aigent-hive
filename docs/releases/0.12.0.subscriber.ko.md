# Aigent Hive v0.12.0 업데이트 내역:

- **구독 잔여 0%에서 새 Hive 작업을 차단하는 보호 기능 추가**
  - 확인한 사용량 창 중 하나라도 잔여량이 0%이면 새 작업을 시작하지 않습니다. 일반 사용량 보호를 꺼도 이 보호는 유지됩니다.
  - 기본으로 켜져 있으며, 별도로 확인한 경우에만 현재 대화에서 제외할 수 있습니다. 새 대화에서는 다시 기본 활성 상태로 시작합니다.
  - 보호 범위는 Hive의 실행 전 검사를 거치는 새 작업입니다. 사용량을 확인할 수 없거나 측정값이 오래된 경우에도 새 작업을 차단합니다.

- **지식 그래프의 관계 검증과 저장 보호 개선**
  - 문서 사이의 관계를 반영하기 전에 원문 근거와 접근 권한을 확인합니다. 삭제되거나 바뀐 문서의 오래된 관계가 조회 결과에 섞이지 않도록 검사합니다.
  - 관계 처리에 문제가 생겨도 저장한 원문과 기존 검색을 보존합니다. 새 관계 결과의 검증이 끝나기 전에는 기존 정상 그래프를 유지합니다.
  - 관계 기능은 사용자가 선택한 범위에 적용하며, 기존 설치에서 자동으로 켜지지 않습니다.

- **검색 오류 안내 개선**
  - 검색이 실패하거나 응답이 늦어질 때 원인을 더 명확하게 안내합니다.
  - 오류가 발생해도 기존 검색 데이터를 보존합니다.

- **시험판과 안정판의 프로젝트 갱신 구분 개선**
  - 시험판에서 만든 설정의 출처를 구분해 확인하고, 이전 안정판의 설정으로 잘못 취급하지 않습니다.
  - 출처를 확인할 수 없으면 설정을 임의로 바꾸지 않고 이유를 안내합니다. 이전 버전 자동 갱신의 호환 대상은 공개 안정판이며, 시험판은 포함하지 않습니다.
