# Aigent Hive v0.11.1 업데이트 내역:

- **Codex 기본 스킬의 중복 정리 추가**
  - 플러그인에서 기본 스킬을 제공하고, 사용자 설정과 프로젝트 갱신에서 같은 원본의 중복 사본을 자동 정리
  - 직접 수정한 스킬·부속 파일·프로젝트 전용 스킬은 보존, 남은 중복과 이유 표시
  - 전역 갱신의 프로젝트 일괄 변경 없이 사용자·프로젝트 각각의 갱신에서 적용

- **Windows의 Claude 전역 환경 설정 오류 수정**
  - 설치 경로를 Claude가 알아볼 수 있는 형태로 전달해 전역 설치·검증·재설치·갱신 과정 개선
  - 실패 원인 확인에 필요한 정보를 안전하게 표시하고, 기존 사용자 지침·설정·지식 보존

- **설정 질문과 실패 복구 안내 개선**
  - 같은 조건의 실패를 반복하거나 근거 없이 관리자 권한 실행을 권하는 대신, 원인과 복구 기록을 먼저 확인하는 안내로 개선
  - 질문 도구가 실패하면 기존 답변을 유지하고 일반 질문으로 이어가는 절차 추가

- **프로젝트 기본 스킬 23개와 자유로운 선택 지원**
  - 조사·코드 정리·검증·지식 관리 등 일상 작업용 스킬을 폭넓게 제공, 원하는 항목만 추가·제외하거나 빈 구성으로 설정 가능
  - 설정·에이전트 생성·기기 간 지식 이식·형식 전환 스킬은 기본에서 제외, Wiki를 끄면 지식 관련 5개도 제외
  - 요청에 맞는 스킬의 자연어 선택 지원, 저장한 맞춤 구성은 다음 갱신에서도 유지

- **다른 프로젝트 지침의 독립 이식 지원**
  - 가져온 규칙의 이름·경로·역할·연결 문서를 현재 프로젝트 기준으로 정리해 원본 프로젝트 없이 사용 가능한 지침으로 구성
  - 복사 설명과 원본의 일시적 승인 이전 방지, 원본 파일과 무관한 사용자 내용 보존
