# Aigent Hive 0.9.3

## 범위

- 사용자가 프로젝트 또는 고유 collection을 명시하면, 해당 프로젝트의 비공유 지식을 직접 조회
- 일반 자동 조회에서는 현재 프로젝트·`user-root`·검증된 shared 범위만 사용하여 다른 프로젝트 지식 혼입 차단
- 검토된 재사용 가능 decision·convention·workflow를 scan apply·rescan maintenance 중 조용히 자동 승격
- source 근거가 사라지면 해당 파생 shared 지식을 함께 무효화
- Hive 관리 Skill projection의 local-preserved validation과 formatter 보호 정합화

## 호환성

- 기존 project-private 지식은 자동 조회 범위 밖에 유지되며, 명시 collection 조회로만 접근 가능
- SQLite는 계속 Markdown 정본의 파생 색인으로만 사용
- Provider API·credential 경로 추가 없음

## 검증

- `hive-wiki` 111개, `hive-cli knowledge` 48개 단위 회귀 통과
- strict Clippy 통과
- 외부 PortareFolium에서 automatic source-private 결과 `0건`, 명시 source collection-only 결과 확인
- source Wiki lint 오류 `0건`; 기존 source digest 경고 14건은 historical fact drift로 유지
