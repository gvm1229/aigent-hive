# Aigent Hive v0.13.2 업데이트 내역:

## 수정

- **남은 할당량을 끝까지 쓰는 0% 하한 설정 지원**
  - 중단 시점을0~99%에서 선택,0%에서도 보호 활성 유지
  - 할당량 소진 뒤 새 요청도 다시 중단, 크레딧 잔액과 무관한 보호
  - 사용량 조회·중단 반영 사이의 지연 가능, 크레딧 차감0 보장 제외

- **소진 뒤 기록·정리를 계속하는 예외 제거**
  - 인계·지식 저장·검사·정리도 사용량 회복 뒤로 미루도록 지침 수정
  - 기존 중단 기록을 유지하고 짧은 중단 안내만 제공

---

## 개선

- **Codex 갱신 뒤 중간 중단 연결 개선**
  - 앱 번호가 바뀌어도 중단에 필요한 응답이 맞으면 감시 연결 허용
  - 연결·사용량 관측·실제 중단 확인을 구분하고 연결 실패 원인 표시
  - Windows의 로컬 Codex에서 명시적으로 켠 감시에 적용, Codex 앱 유지
  - 초기화·일반 하한 중단 뒤 직접 재개 허용, 이미 시작한 외부 명령의 동시 종료 보장 제외
