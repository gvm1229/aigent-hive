# Aigent Hive v0.11.0 업데이트 내역:

- **중요한 파일을 AI의 실수로부터 보호하는 ‘Hook’ 추가**
  - Hook은 AI가 파일을 바꾸기 직전에 자동으로 실행되는 검사. 이전 버전의 지침 안내에 더해, 이번에는 Hook을 켜면 보호 대상으로 정한 파일의 직접 편집을 차단.
  - 필요할 때 선택해서 사용. 확인된 사용 범위는 Windows Codex·Antigravity의 AI 파일 편집이며, 터미널 명령은 Hook 검사 대상 밖.

- **대화가 길어져도 필요한 핵심 지침을 다시 알림**
  - Codex가 긴 대화를 요약한 뒤 선택한 핵심 지침을 다시 전달. 켜기 전에 어떤 문구를 알려줄지 미리 확인 가능.
  - 지침 복구를 껐다가 다시 켜도 다른 도구의 설정 유지. 모든 지침을 반드시 따른다는 보장과는 별개인 보조 기능.

- **Hive가 없는 팀원과도 같은 프로젝트에서 개발**
  - 내 컴퓨터에 Hive가 설치돼 있어도 팀원은 따로 설치하지 않고 기존 도구로 작업 가능.
  - Hive를 사용하는 사람의 보호 설정은 그대로 유지.

- **말로 요청하는 프로젝트 지침 업데이트**
  - 프로젝트의 Hive 지침을 최신으로 바꿔 달라고 말하거나, 바뀔 내용만 먼저 확인 가능. 명령어 입력 없이 진행.
  - 지침을 갱신하는 기능이 설치된 환경에서 사용 가능. 미리보기만 요청하면 파일 변경 없이 결과 확인.

- **오래된 정식 버전에서도 내 설정을 지키며 업데이트**
  - 0.9.1 이후 정식 버전으로 설정한 프로젝트의 Hive 지침을 갱신할 때 기존 설정과 직접 작성한 내용 보존.
  - 0.10.3으로 설정한 프로젝트와 Windows 환경에도 현재 Hive 지침 반영. 번호 시험판과 모든 설정 조합은 호환성 보장 범위에서 제외.

- **중단한 작업을 더 안전하게 다시 시작**
  - 다른 대화나 이미 끝난 프로그램이 내 작업을 자동으로 이어받지 않도록 현재 대화와 실행 중인 프로그램 확인. 직접 다시 시작하는 방법도 유지.

- **사용량 리셋을 감지하면 새 자동 작업 중단**
  - 다음 사용량 점검에서 리셋을 확인하면 새 자동 작업을 멈추고, 사용자가 리셋을 확인한 뒤 재개. 진행 중인 작업을 실시간으로 멈추는 기능은 아님.
  - 필요하면 리셋 감지만 현재 대화에서 끄거나 다시 켜기 가능. 사용량 부족에 대한 보호는 계속 적용.

- **원본이 없어도 옮겨온 지식 확인**
  - 다른 컴퓨터에서 가져온 지식의 원본 파일이 없어도 이전 기록 조회 가능. 지금도 맞는 내용인지 확인되지 않았다는 표시 제공.
