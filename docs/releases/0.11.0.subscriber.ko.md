# Aigent Hive v0.11.0 업데이트 내역:

- **Hive가 없는 팀원과도 같은 프로젝트에서 개발**
  - 내 컴퓨터에 Hive가 설치돼 있어도 팀원은 따로 설치하지 않고 기존 도구로 작업 가능.
  - Hive를 사용하는 사람에게는 기존 보호 기능을 계속 적용. Hive 실행 오류나 보호 기능의 중단이 발생하면 해당 작업은 중단.

- **말로 요청하는 프로젝트 지침 업데이트**
  - 프로젝트의 Hive 지침을 최신으로 바꿔 달라고 말하거나, 바뀔 내용만 먼저 확인 가능. 명령어 입력 없이 진행.
  - 지침을 갱신하는 기능이 설치된 환경에서 사용 가능. 미리보기만 요청하면 파일 변경 없이 결과 확인.

- **오래된 정식 버전에서도 내 설정을 지키며 업데이트**
  - 0.9.1 이후 정식 버전으로 설정한 프로젝트의 Hive 지침을 갱신할 때 기존 설정과 직접 작성한 내용 보존.
  - 일부 0.10.3 프로젝트의 갱신이 막히거나 Windows에서 새 지침이 빠지던 문제 수정. 번호 시험판과 모든 설정 조합은 호환성 보장 범위에서 제외.

- **파일을 바꾸기 전 팀 규칙 확인 기능 추가**
  - 필요할 때 켜서 파일 수정 전에 프로젝트 규칙 확인. 규칙에 어긋나는 수정을 줄이는 선택 기능.
  - Windows의 Codex·Antigravity에서 시험한 파일 편집 작업에 한정. Claude·터미널 명령·검사기 오류 상황까지 모든 수정을 자동으로 막는 기능은 아님.

- **중단한 작업을 더 안전하게 다시 시작**
  - 다른 대화나 이미 끝난 프로그램이 내 작업을 자동으로 이어받지 않도록 현재 대화와 실행 중인 프로그램 확인. 직접 다시 시작하는 방법도 유지.

- **사용량 보호를 현재 대화에 맞게 조절**
  - 사용량 한도가 새로 채워졌을 때 작업을 멈추는 동작만 이번 대화에서 잠시 끄거나 다시 켜기 가능. 사용량 부족에 대한 보호는 계속 적용.

- **원본이 없어도 옮겨온 지식 확인**
  - 다른 컴퓨터에서 가져온 지식의 원본 파일이 없어도 이전 기록 조회 가능. 지금도 맞는 내용인지 확인되지 않았다는 표시 제공.

※ macOS의 선택형 검색 검사는 첫 시도에 실패했고, 같은 배포물로 다시 검사했을 때 통과. 첫 실패의 원인은 미확정.
