# Aigent Hive 0.10.3

## English

### Scope

- [USAGE103-01] Remeasure current usage before applying a stored halt from an earlier process or format.
- [USAGE103-02] Remove an obsolete halt after an allowed result or replace it in place after a blocked result.
- [USAGE103-03] Recover bounded damaged halt JSON through a fresh measurement without disabling the safeguard.

### Compatibility

- [COMPAT103-01] Preserve global and project thresholds while upgrading existing `0.10.2` installations.
- [COMPAT103-02] Authenticate frozen `0.10.2` project and user projections before replacement.
- [COMPAT103-03] Apply one recovery contract to configured projects and Hive source workspaces.

### Verification

- [VERIFY103-01] Pass complete Rust and Python conformance on Windows before public-test publication.
- [VERIFY103-02] Accept the numbered public test on Windows x64, macOS arm64, and Linux musl x64.
- [VERIFY103-03] Confirm an existing halt never requires safeguard disablement after the upgrade.

### Publication

- [PUBLISH103-01] Publish and accept `0.10.3-test.1` before stable promotion.
- [PUBLISH103-02] Keep npm `latest` on `0.10.2` during public-test qualification.

## 한국어

### 범위

- [USAGE103-01] 이전 프로세스·형식의 중단 표식 적용 전 현재 사용량 재측정.
- [USAGE103-02] 허용 결과에서 옛 중단 표식 제거, 차단 결과에서 같은 위치의 현재 형식 교체.
- [USAGE103-03] 제한 크기 안의 손상된 중단 JSON을 보호 해제 없이 새 측정으로 복구.

### 호환성

- [COMPAT103-01] 기존 `0.10.2` 설치 갱신 중 전역·프로젝트 기준 보존.
- [COMPAT103-02] 교체 전 동결 `0.10.2` 프로젝트·사용자 투영 인증.
- [COMPAT103-03] 설정된 프로젝트와 Hive 소스 작업에 하나의 복구 계약 적용.

### 검증

- [VERIFY103-01] 공개 시험 게시 전 Windows 전체 Rust·Python 적합성 검사 통과.
- [VERIFY103-02] Windows x64·macOS arm64·Linux musl x64 번호 공개 시험 수용.
- [VERIFY103-03] 갱신 후 기존 중단 표식이 보호 해제를 요구하지 않는 흐름 확인.

### 게시

- [PUBLISH103-01] 안정판 승격 전 `0.10.3-test.1` 게시·수용.
- [PUBLISH103-02] 공개 시험 검증 중 npm `latest`의 `0.10.2` 유지.
