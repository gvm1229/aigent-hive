# Aigent Hive v0.9.2 (베타) 출시

## 대표 기능

- 자체적인 메모리: Markdown + SQLite DB
- 프로젝트를 넘나드는 기억: 검토된 지식·선호·작업 방식을 Markdown 정본에 기록하고 SQLite 검색 색인으로 빠르게 회수
- 전역 설정과 프로젝트 설정의 분리: 공통 선호는 모든 프로젝트에 적용하고 프로젝트별 규칙·지식은 해당 프로젝트에만 유지
- 22가지 내장 Skill: 프로젝트 설정, 프롬프트 개선, 조사, 지식 관리, 실행 인계, 업데이트 등
- Codex·Claude Code·Gemini Antigravity 지원
- 구독 사용량 보호: 전역·프로젝트별 기준에 따라 새 자동 작업 시작을 안전하게 중단
- 선택형 Discord 알림: 사용량 보호로 중단된 작업의 프로젝트·요청 요약·진행 상태·재개 안내 전송
- 안전한 설치·업데이트: 변경 범위 검증, 백업·복구, 기존 지식·사용자 설정 보존
- 로컬 우선 구조: 현재 로그인한 구독형 에이전트 호스트 사용, 모델 제공자 API 키 요청·저장·전달 없음
