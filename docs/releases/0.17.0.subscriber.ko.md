# Aigent Hive v0.17.0 업데이트 내역:

## 바뀐 점

- **아폴론과 데메테르의 일 교체**
  - 아폴론(Apollon)은 지식 저장·찾기·관리, 데메테르(Demeter)는 글쓰기·한국어 다듬기·프롬프트 정리 담당
  - 이름이 Horizon Zero Dawn의 APOLLO(인류 지식 데이터베이스)와 맞도록 교체
  - 0.17.x 동안은 옛 습관 그대로 불러도 동작: `hive demeter knowledge …`처럼 부르면 "0.17.0부터 knowledge은 Apollon 담당" 한 줄 안내 뒤 아폴론으로 실행. 0.18.0부터는 새 담당으로만 동작
  - `Apollo`·`아폴로`는 계속 아폴론을 가리킴

- **웹 디자인 담당 아프로디테(Aphrodite) 추가**
  - "아프로디테"·"Venus"로 부르면 `design-curate`로 화면 방향 정하기·시안·점검
  - 검증된 디자인 Skill 네 개(frontend-design, web-artifacts-builder, impeccable, hallmark)의 핵심을 Hive 안에 동봉하고, 서로 부딪히는 지시는 Hive가 미리 정리
  - 내가 기록한 디자인 선호와 프로젝트 `DESIGN.md`가 언제나 먼저
  - 전역 설정에서 추천 묶음을 끄고 빈 상태로 쓸 수도 있음
  - `hive design status`로 동봉한 원본과 버전 확인

- **중간에 묻지 않고 끝까지 하는 `autonomous-workflow`**
  - 사소한 선택은 스스로 정하고, 진짜 질문만 모아 마지막에 한 번
  - 거의 쓰이지 않던 `verified-workflow`는 제거, 옛 이름으로 부르면 새 이름으로 안내

- **`ai-slop-cleaner` 이름 복원과 범위 확대**
  - `code-polish`가 `ai-slop-cleaner`로 돌아옴. 대상은 코드·문서·디자인
  - 고치기 전에 무엇을 왜 고칠지 짧은 계획을 먼저 보여 주고, 확인한 것만 수정

- **미리 보기 브라우저 선택**
  - 전역 설정에서 기본 브라우저 또는 앱 내장 브라우저 선택
  - 기본 브라우저가 Chromium 계열(Chrome·Edge·Whale·Brave 등)이 아니면 Chrome 사용
  - 따로 말하지 않으면 새 탭 대신 지금 보고 있는 탭에서 작업
  - Whale에서 Claude in Chrome 연결은 아직 확인 전

- **업데이트해도 내 자료는 그대로**
  - 0.16.1과 이전 지원 버전에서 올려도 설정 답변·기억·프로젝트 등록·프로젝트 파일 보존
  - 옛 Skill 이름(`verified-workflow`, `code-polish`)은 새 이름으로 자동 연결

- **업데이트 방법**
  - `npm install -g aigent-hive@0.17.0` 실행 뒤 `hive update`로 설치한 앱 연결까지 갱신
