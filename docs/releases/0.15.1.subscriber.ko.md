# Aigent Hive v0.15.1 업데이트 내역:

## 새 기능

- **프로젝트 자동 확인 추가, 같은 정보를 되풀이해 입력하는 부담 감소**
  - 폴더 안의 표시 파일에서 사용 언어·프레임워크·패키지 관리자·명령·구조를 찾아, 어떤 프로젝트인지 한 번 확인하는 기능
  - `에일레이티이아, 이 프로젝트 Hive 설정`으로 시작해 감지 결과를 확인하고 수락하거나 다른 종류 선택. 근거가 약하면 목록에서 직접 선택, 모델 호출이나 감지한 명령의 자동 실행 없음
  - 종류는 코드 개발·문서 작성·일반 작업·사용자 지정의 네 가지. 사용자가 고른 종류는 다음 갱신에서도 유지, 예전 기본값만 근거에 따라 새 종류 제안

## 개선

- **모든 사용자용 CLI 결과를 쉬운 문장으로 표시**
  - 명령줄 도구인 CLI에서 JSON 자료 대신 설정한 한국어·영어로 결과·바뀐 값·필요한 다음 행동 안내. 실패 시 원인과 복구 방법 표시
  - 예: `hive usage threshold --user-root <홈 폴더> --remaining-percent 10`으로 보호 기준 변경, 이전 값과 새 값 확인. 기존 JSON 기계 형식은 `--output json`으로 선택, 자동 도구·스킬·훅의 명시적 기계 호출 유지

- **프로젝트 지침을 짧게 정리하고 사용자 규칙 보존**
  - 확인한 프로젝트 사실과 짧은 Hive 안내를 나눠 표시, 긴 세부 지침은 필요할 때 읽는 방식
  - `에일레이티이아, 이 프로젝트 Hive 지침 갱신`으로 변경 미리보기 확인 후 적용. Hive 표시 블록 밖의 직접 작성한 내용 보존, 직접 교체한 지침의 갱신 누락 경로 안내

- **AI 자체 기억 대신 Hive 지식 문서에 기록**
  - AI가 자체 기억에 남기던 사실·선호·작업 방식을 Hive 지식 문서(Markdown)로 저장. 프로젝트 사실은 그 프로젝트에, 여러 프로젝트에 쓰이는 사실만 전역 지식에 저장하고 AI 기억에 중복 저장 없음
  - 전역 지침과 프로젝트 지침 모두 적용. 위키가 꺼져 있거나 Hive 없는 폴더면 이를 알리고 설정 제안

- **신 스킬 9개의 설명에 하는 일 표시**
  - 앱의 스킬 목록에서 이름만 보이던 신 스킬 설명을 하는 일 요약으로 교체. 예: 하데스는 Hive 저장 공간 측정과 정리할 파일 미리보기

- **검증된 사용자 플러그인의 중복 파일을 첫 설정에서 줄이는 기능 개선**
  - 새 프로젝트는 사용자 플러그인이 같은 기능을 제공하는지 확인해 중복 복사 축소. 이미 쓰는 프로젝트의 구성 자동 축소 없음
  - 플러그인이 없거나 확인에 실패한 컴퓨터에서는 프로젝트 파일로 제공. 사용자가 수정한 파일·프로젝트 전용 기능 보존, 역할·선택 기능 사용 시 추가 파일 가능
