# Aigent Hive v0.10.3 업데이트 내역:

- **사용량 보호 중단 뒤 자동 복구 개선**
  - 이전 Codex 프로세스나 구버전이 남긴 `halt.json` 때문에 실제 사용량이 충분한데도 작업이 계속 멈추던 문제 수정
  - 새 버전은 기존 중단 표식을 발견하면 현재 사용량을 다시 확인하고, 안전하면 같은 위치의 표식을 제거해 작업 진행
  - 사용량이 보호 기준 이하이거나 현재 상태를 확인할 수 없으면 보호 기능을 유지한 채 최신 결과로 표식 교체

- **보호 해제 없이 기준 변경·사용량 회복 반영**
  - 대화 도중 보호 기준을 바꾸거나 사용량이 초기화된 경우 다음 점검에서 현재 상태 재측정
  - 복구를 위해 보호 기능을 끄거나 `halt.json`을 직접 삭제하거나 새 대화를 만들 필요 없음

- **기존 설치와 여러 프로젝트의 같은 복구 규칙 적용**
  - `0.10.2`에서 갱신한 설치, 설정된 Hive 프로젝트, Hive 소스 작업에 같은 처리 적용
  - 전역·프로젝트별 보호 기준과 사용자가 선택한 설정은 그대로 보존
  - 손상된 제한 크기 JSON 표식도 새 측정으로 복구. 경로 이탈·심볼릭 링크·크기 초과·위조된 표식은 안전을 위해 계속 차단
