# Aigent Hive 0.15.2

## English

### Scope

- [SCOPE-01] A resumed `hive update` whose saved usage-monitor choice no longer matches this PC previews again instead of repeating the same failure.
- [SCOPE-02] A failed user install removes its Codex marketplace and plugin registration before restoring files, so Codex keeps listing its plugins.
- [SCOPE-03] A later update repairs a Codex registration left without its Hive marketplace manifest by an earlier failed install.
- [SCOPE-04] Install and update finish when an attached folder needs index consent, and show `hive index rebuild --user-root <home>` next.
- [SCOPE-05] Claude installation replaces an `aigent-hive` marketplace registration whose folder no longer exists. Registrations at existing paths remain refused.

### Compatibility

- [COMPAT-01] Upgrade from public 0.15.1 and earlier supported versions keeps user answers, knowledge and project files.
- [COMPAT-02] Supported JSON schemas, values and exit codes stay the same.

### Verification

- [VERIFY-01] Regression tests cover the stale monitor preview, rollback ordering, stuck Codex registration, deferred index rebuild and dangling Claude marketplace with fake host runners.
- [VERIFY-02] Public 0.15.2-test.1 acceptance and real host listing on this PC are recorded in the release evidence.

### Publication

- [PUB-01] Stable 0.15.2 promotes the accepted 0.15.2-test.1 product.
