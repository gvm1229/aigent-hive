# Aigent Hive 0.15.2

## English

### Scope

- [SCOPE-01] A resumed `hive update` whose saved usage-monitor choice no longer matches this PC previews again instead of repeating the same failure.
- [SCOPE-02] A failed user install removes its Codex marketplace and plugin registration before restoring files, so Codex keeps listing its plugins.
- [SCOPE-03] A later update repairs a Codex registration left without its Hive marketplace manifest by an earlier failed install.
- [SCOPE-04] Install and update finish when an attached folder needs index consent, and show `hive index rebuild --user-root <home>` next.
- [SCOPE-05] Claude installation replaces an `aigent-hive` marketplace registration whose folder no longer exists. Registrations at existing paths remain refused.
- [SCOPE-06] Antigravity CLI 1.2.x installs Hive; the supported range becomes `>=1.1.7 <2.0.0`.
- [SCOPE-07] Interactive setup says several apps can be chosen and accepts commas or spaces, such as `1,2`.

### Compatibility

- [COMPAT-01] Upgrade from public 0.15.1 and earlier supported versions keeps user answers, knowledge and project files.
- [COMPAT-02] Supported JSON schemas, values and exit codes stay the same.
- [COMPAT-03] A PC already looping on 0.15.1 needs `npm install -g aigent-hive@0.15.2`, then `hive update`.

### Verification

- [VERIFY-01] Regression tests cover the stale monitor preview, rollback ordering, stuck Codex registration, deferred index rebuild and dangling Claude marketplace with fake host runners.
- [VERIFY-02] Public 0.15.2-test.4 acceptance passed on Windows x64, macOS arm64 and Linux musl x64.
- [VERIFY-03] On a Windows PC, Codex, Claude Code and Antigravity CLIs list Hive 0.15.2 with 37 Skills; their apps show the Skills.

### Publication

- [PUB-01] Stable 0.15.2 promotes the accepted 0.15.2-test.4 product.

## 한국어

### 범위

- [SCOPE-01] 저장된 감시 선택이 이 PC와 달라진 `hive update` 재개의 같은 실패 반복 대신 다시 미리보기.
- [SCOPE-02] 사용자 설치 실패 시 파일 복원 전 Codex 마켓·플러그인 등록 제거, Codex 플러그인 목록 유지.
- [SCOPE-03] 이전 설치 실패로 Hive 마켓 manifest 없이 남은 Codex 등록의 다음 갱신 복구.
- [SCOPE-04] 연결 폴더 색인에 명시 동의가 필요할 때 설치·갱신 완료, 다음 행동으로 `hive index rebuild --user-root <홈>` 안내.
- [SCOPE-05] 폴더가 사라진 `aigent-hive` Claude 마켓 등록의 교체 설치. 존재하는 경로의 등록은 계속 거부.
- [SCOPE-06] Antigravity CLI 1.2.x에 Hive 설치, 지원 범위 `>=1.1.7 <2.0.0`.
- [SCOPE-07] 대화형 설정의 여러 앱 선택 안내, `1,2`처럼 쉼표나 공백 구분 입력.

### 호환성

- [COMPAT-01] 공개 0.15.1·이전 지원 버전에서 사용자 답변·지식·프로젝트 파일 보존 갱신.

- [COMPAT-03] 0.15.1에서 이미 반복 실패 중인 PC의 `npm install -g aigent-hive@0.15.2` 뒤 `hive update` 필요.

### 게시
