# Aigent Hive v0.10.0 업데이트 내역:

- **벡터 데이터베이스 도입, 의미 기반 검색 기능 추가**
  - 이제 정확한 단어를 몰라도 찾고 싶은 내용을 설명해 보세요. “지운 자료를 되찾는 방법”으로 “백업 복원 절차”처럼 뜻이 비슷한 자료를 찾거나, 한국어 질문으로 관련 영어 문서를 찾을 수 있습니다.
  - 벡터 검색은 내 컴퓨터에서 작동합니다. 오류 코드·날짜·정확한 문구를 찾는 기존 SQLite 키워드 검색도 그대로 유지됩니다.
  - 새 기능의 사용 여부는 직접 선택합니다. “예”를 선택하면 새 대화용 설정 안내문을 제공하고, “아니요”를 선택하면 다시 권하지 않습니다. 기존 설정에 다시 답할 필요도 없습니다.
  - 실행 환경과 모델 설치에는 Windows 실측 약 376MB가 필요하고, 지식량에 따라 저장 공간이 추가됩니다. 처음 준비할 때는 수 분 이상, 의미 검색에는 수 초가 걸릴 수 있습니다.

- **지식 그래프 기능 추가, 연결된 자료까지 이어서 탐색**
  - 문서에 기록된 연결 관계를 따라 관련 지식과 영향을 받을 항목을 살펴볼 수 있습니다. 설정 하나를 바꾸기 전에 연결된 사용 안내를 함께 확인하는 식으로 활용해 보세요.

- **지식 이전 전용 `knowledge-transfer` Skill 추가, 컴퓨터 간 복원 개선**
  - Windows에서 내보낸 지식 파일을 Mac에서 복원하는 등, 운영체제가 달라도 경로와 충돌을 확인하며 이전을 진행합니다. 기존 지식을 다시 요약하지 않고 옮긴 뒤 기본 검색을 자동으로 준비합니다.
  - 벡터 검색을 사용 중이라면 복원 뒤 벡터 색인을 지금 다시 만들지 선택할 수 있습니다. “아니요”는 이번 재생성만 미루는 선택이며, 벡터 검색 사용 설정은 유지됩니다. 기밀 자료는 이전 대상에서 제외합니다.

- **여러 지식 파일의 일괄 통합 기능 추가**
  - 컴퓨터 A와 B에서 내보낸 지식을 컴퓨터 C의 기존 지식과 함께 모을 수 있습니다. 확실한 중복은 정리하고, 서로 다른 지식과 출처는 보존합니다.
  - 표현이 비슷해도 조건·수치·예외가 다르면 별개로 남깁니다. 근거로 해결하지 못한 모순은 한꺼번에 질문하고, 해결한 뒤 전체 결과를 적용합니다.

- **작업 지속·검증 흐름 개선, `verified-workflow`로 통합**
  - 구현·시험·수정이 이어지는 복잡한 작업에서 남은 일과 검증 결과를 기록하며 진행합니다. 시험에 실패하면 원인을 확인하고 허용된 범위에서 수정·재검증을 이어갑니다.
  - 대화가 길어지거나 나중에 작업을 재개할 때 기록된 진행 상황을 확인해 이어갑니다. 사용자의 취소 요청은 우선합니다.

- **에이전트 리뷰 전용 `adversarial-judge` Skill 추가**
  - 다른 에이전트에게 구현이나 계획의 별도 리뷰를 맡길 수 있습니다. “정상 동작 말고, 실패할 수 있는 조건을 찾아줘”처럼 요청해 놓친 전제와 예외 상황을 살펴보세요.

- **한국어 언어 코어 도입, `humanize-kor` Skill 추가**
  - im-not-ai 기반 한국어 규칙을 새 답변과 문서 작성에 기본 적용해 번역투와 불필요한 반복을 줄입니다. 기존 글을 다듬을 때는 `humanize-kor`로 요청할 수 있습니다.
  - 문장을 다듬어도 원래 의미·수치·명령어·인용·출처를 보존하도록 검사합니다.

- **이전 버전 갱신과 Skill 이름 변경 처리 개선**
  - 중간 버전을 차례로 설치할 필요 없이 갱신하면서, Hive가 설치한 것으로 확인된 폐기·이름 변경 Skill 파일을 정리합니다. 사용자가 수정한 파일은 함부로 삭제하지 않습니다.
  - 외부 폴더에서 새 지식을 추출하는 `knowledge-import`는 `knowledge-scan`으로 이름을 바꿨습니다. 기존 지식을 다른 컴퓨터로 옮기는 작업은 새 `knowledge-transfer`가 담당합니다.
