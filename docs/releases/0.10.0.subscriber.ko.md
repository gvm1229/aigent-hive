# Aigent Hive v0.10.0 업데이트 내역:

> 안정판 게시 전 읽기 쉬움을 검토하기 위한 초안. 공개 완료 안내나 Discord 발송에 사용하지 않음.

- **표현이 달라도 관련 지식을 찾는 의미 검색을 선택할 수 있습니다.**
  - “지운 자료를 되찾는 방법”으로 “백업 복원 절차”를 찾거나, 한국어 질문으로 관련 영어 문서를 찾을 수 있습니다.
  - 오류 코드·날짜·정확한 문구를 찾는 기존 검색도 그대로 사용할 수 있습니다.

- **의미 검색은 사용 여부를 직접 선택합니다.**
  - 갱신 뒤 기존 설정을 다시 묻지 않고 의미 검색 사용 여부만 안내합니다.
  - “예”를 선택하면 새 대화에 붙여넣을 설정 안내문을 제공합니다. “아니요”를 선택하면 다시 권하지 않습니다.
  - 처음에는 모델 설치와 지식 준비에 시간이 걸릴 수 있습니다.

- **진행 중인 작업을 이어가고 결과를 확인하는 흐름을 보강합니다.**
  - 구현·시험·수정이 필요한 작업은 진행 상태와 검증 근거를 남기며 이어갈 수 있습니다.
  - 사용자가 중단을 요청하면 멈추고, 재개할 때 남은 작업을 확인합니다.

- **다른 관점의 검토를 요청할 수 있습니다.**
  - “이 구현에서 놓친 결함을 찾아줘”처럼 요청하면 별도의 검토가 문제와 근거를 확인합니다.

- **한국어 답변과 문서를 더 자연스럽게 다듬습니다.**
  - 새로 작성하는 한국어에 기본 적용하며, 기존 글은 `humanize-kor`로 다듬도록 요청할 수 있습니다.
  - 코드·명령어·수치·인용·출처와 원래 의미는 보존합니다.

- **지식의 연결을 살펴보고 오래된 설치를 안전하게 갱신합니다.**
  - 문서에 기록된 연결을 따라 관련 자료와 영향 범위를 확인할 수 있습니다.
  - 이전 버전에서 바로 갱신할 때 Hive 소유로 확인된 폐기·이름 변경 Skill을 정리하고 사용자 수정 자료는 보존합니다.
