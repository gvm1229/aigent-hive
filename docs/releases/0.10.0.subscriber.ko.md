# Aigent Hive v0.10.0 업데이트 내역:

> 안정판 게시 전 읽기 쉬움 검토용 초안. 공개 완료 안내·Discord 발송 제외.

- **컴퓨터를 바꿀 때 기존 지식을 그대로 이전하는 전용 기능**
  - 이전 컴퓨터에서 내보낸 지식 파일을 새 컴퓨터에 가져와 원문과 기본 검색 복원
  - 서로 다른 내용이 같은 위치에 있으면 충돌 목록 확인 후 현재 자료 유지와 해당 항목 제외, 또는 취소 선택

- **지식 이전 뒤 벡터 재생성 시점 선택**
  - 이미 의미 검색을 사용 중이면 기본 검색 복원 뒤 지금 재생성할지 질문
  - “아니요”는 이번 재생성만 연기. 의미 검색 사용 설정 유지와 같은 이전 작업의 재질문 방지
  - 이미 승인된 모음·모델만 재사용. 새 설치나 비공개 프로젝트 연결은 별도 확인

- **표현이 달라도 관련 지식을 찾는 의미 검색 선택 기능**
  - “지운 자료를 되찾는 방법”과 “백업 복원 절차”, 한국어 질문과 관련 영어 문서의 검색 예시
  - 오류 코드·날짜·정확한 문구 대상 기존 검색 유지

- **의미 검색 사용 여부 직접 선택**
  - 갱신 뒤 기존 설정 재질문 없이 의미 검색 사용 여부만 안내
  - “예” 선택 뒤 새 대화용 설정 안내문 제공, “아니요” 선택 뒤 재권유 제외
  - 모델 설치와 최초 지식 준비의 시간 소요 가능성

- **진행 상태·검증 근거 기반 작업 지속**
  - 구현·시험·수정 작업의 진행 상태와 검증 근거 기록
  - 사용자 중단 요청과 재개 시 남은 작업 확인

- **다른 관점의 검토 요청 기능**
  - “이 구현에서 놓친 결함을 찾아줘” 요청의 별도 검토와 문제·근거 확인

- **한국어 답변·문서의 자연스러운 다듬기**
  - 새 한국어 작성물의 기본 적용과 기존 글 대상 `humanize-kor` 요청
  - 코드·명령어·수치·인용·출처·원래 의미 보존

- **지식 연결 확인과 오래된 설치의 안전한 갱신**
  - 문서에 기록된 연결을 따른 관련 자료·영향 범위 확인
  - 이전 버전 직접 갱신 시 Hive 소유 폐기·이름 변경 Skill 정리와 사용자 수정 자료 보존
