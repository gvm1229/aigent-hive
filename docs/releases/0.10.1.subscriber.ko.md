# Aigent Hive v0.10.1 업데이트 내역:

- **이전 버전의 project harness 갱신 복구**
  - 이제 Hive가 설치된 이전 상태를 먼저 확인한 뒤 새 구조로 변경. `0.9.5`처럼 여러 옛 Skill 이름이 하나로 합쳐지는 설치도 선언된 규칙에 따라 정상 갱신.
  - 실제 중복·알 수 없는 Skill·수정된 관리 파일·외부 파일 충돌이 있으면 아무것도 바꾸지 않고 중단. Project 설정, 사용자 문서, 로컬 표식과 외부 파일은 그대로 보존.
  - `scan`과 `dry-run`에서 source version, snapshot digest, migration ID, 정규화된 항목과 Skill 병합 결과 확인 가능. Apply 전에 실패했다면 복구 자료가 없는 것이 정상이라는 안내도 제공.

- **같은 대화에서 사용량 보호 기준을 즉시 변경**
  - 사용량 기준 변경 뒤 보호 기능 해제나 새 대화 없이 같은 session에서 즉시 재측정. 예: 60% 기준 중단 뒤 10%로 변경하고 남은 사용량 10% 초과 시 바로 작업 재개.
  - 전역 기준과 project 기준 중 더 큰 값을 계속 적용. 새 측정이 기준 이하이거나 측정할 수 없으면 안전을 위해 계속 멈추고, 다른 session의 중단 표식은 그대로 보존.
