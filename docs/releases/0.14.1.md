# Aigent Hive 0.14.1

## English

### Scope

- [SCOPE-01] Changing the global usage floor now keeps its saved choice record valid, so the change succeeds.
- [SCOPE-02] Keep an explicitly detached knowledge collection detached. Sync and rebuild do not attach it again.
- [SCOPE-03] Keep the current and previous usage monitor programs. Remove older copies after an update.
- [SCOPE-04] Report Hive storage use with `hive storage`. Preview unused monitor programs with `hive prune --dry-run`.

### Compatibility

- [COMPAT-01] Update targets include public 0.14.0. Existing files still require complete ownership verification.
- [COMPAT-02] An explicitly detached collection needs an explicit attach command before use.
- [COMPAT-03] Version 0.14.0 cannot read a collection list that has an explicit detach. Attach the collection before a downgrade.

### Verification

- [VERIFY-01] Unit and integration tests pass on Linux. Public test results for Windows, Linux and macOS are pending.

### Publication

- [PUB-01] Publish 0.14.1 only after an accepted numbered public test and version approval.

## 한국어

### 범위

- [SCOPE-01] 전역 사용량 하한 변경 때 저장된 선택 기록의 유효성 유지와 변경 성공
- [SCOPE-02] 직접 해제한 지식 연결의 해제 유지, 동기화·재구성의 재연결 없음
- [SCOPE-03] 갱신 뒤 현재와 직전 감시 프로그램만 보관, 오래된 사본 정리
- [SCOPE-04] `hive storage`의 저장 공간 보고, `hive prune --dry-run`의 미사용 감시 프로그램 미리보기

### 호환성

- [COMPAT-01] 공개 0.14.0을 포함한 갱신 대상, 기존 파일의 전체 소유 검증 유지
- [COMPAT-02] 직접 해제한 연결의 사용에는 명시적 재연결 필요
- [COMPAT-03] 연결 해제 뒤 0.14.0의 연결 목록 읽기 불가, 이전 버전 복귀 전 재연결 필요

### 검증

- [VERIFY-01] Linux 단위·통합 시험 통과. Windows·Linux·macOS 공개 시험 결과 대기

### 게시

- [PUB-01] 수용된 번호 공개 시험과 버전 승인 뒤에만 0.14.1 게시
