# Aigent Hive v0.9.4 업데이트 내역:

- 모든 Hive Skill 설명의 시작에 정식 영문 식별자를 표시하고, 모든 호스트 투영·목록·설치·갱신·정리 동작을 일관되게 개선
- 전역 설정과 설치 검증에서 공식 갱신 절차가 허용하는 로컬 보존 투영을 정상 처리하고, 변조·위조·잘못된 형식·외부 소유 파일은 계속 안전하게 차단
- 안전한 사용자 전역 지식 기록의 오탐 자격 증명 감지를 제거하고, 실제 비밀·자격 증명·기밀 정보 차단은 유지
- 지식 기능 안내를 표로 새로 정리하고, 한국어 PDF에서 고립된 제목이 페이지 하단에 남도록 품질 개선
- 한국어 응답 환경에서도 프롬프트는 기본적으로 영어로 만들고, 명시적으로 한국어 프롬프트를 요청한 경우에만 한국어로 생성하도록 개선
