# Aigent Hive v0.14.0 업데이트 내역:

## 새 기능

- **AI 없이 답만 골라 끝내는 대화형 CLI 설정 추가**
  - 터미널에서 한국어·영어로 전역 환경과 프로젝트 설정, 생성형 모델 호출 없이 질문·미리보기·확인·적용
  - 저장한 선택 재사용, 한 항목만 변경하거나 중단한 질문부터 재개 지원

- **설정과 지식을 남기는 프로그램 제거 기능 추가**
  - `hive uninstall --dry-run`으로 제거·보존 대상 확인 후 명시한 범위 제거
  - 사용자 설정·지식·기록·프로젝트 자료 보존, 재설치 뒤 재사용 지원

---

## 수정

- **보호를 켠 상태에서 남은 사용량0~99% 하한 선택 지원**
  - 0%에서도 할당량 소진 보호 유지, 소진 확인 뒤 기록·정리 작업도 중단
  - 관측과 중단 반영의 지연 가능, 크레딧 차감0 보장 제외

---

## 개선

- **처음 갱신할 때 새 설정까지 이어서 선택**
  - 기존0.13.1의 `hive update`에서 새 질문과 적용까지 연결
  - 질문할 수 없는 환경에서는 기존 선택 보존·새 선택형 기능 비활성·남은 질문 안내

- **사용량 보호를 원하는 방식으로 선택**
  - 새 설치의 자동 중단 기본 비활성, 기존 설정의 변경 전 선택 확인
  - 시작 전 확인과 실행 중 감시 분리, Windows 로컬 Codex의 실행 중 감시는 별도 동의
  - Codex 앱 번호 대신 필요한 통신 기능 확인, 초기화 중단 뒤 직접 재개 지원

- **AI에 설정을 맡길 때 중복 안내 조회 축소**
  - 필요한 질문과 짧은 결과부터 전달, 기존 파일 입력과 상세 확인 유지
  - 직접 선택·기본값·상속을 구분하고 사용자 글·역할의 현재 작업 보존
