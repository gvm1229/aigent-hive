# Aigent Hive 0.12.1

## English

### Scope

- [SCOPE-01] Interrupt running local Codex tasks once after an observed quota reset, or after 60 seconds without a valid usage reading.
- [SCOPE-02] Show a separate notice with the official logo, stop reason, confirmation status and detection time. Keep Codex open.

### Compatibility

- [COMPAT-01] Session interruption supports Windows 11 x64 with Codex 26.1013.4894.0. Enable the independent usage monitor for protection.
- [COMPAT-02] Preserve saved files and existing quota-floor protection. Allow direct Codex resume or new messages without a resume lock.
- [COMPAT-03] Other operating systems, remote tasks and cloud tasks lack session-interruption support. Detection does not guarantee simultaneous server processing or billing termination.

### Verification

- [VERIFY-01] Windows qualification combines four real native task interruptions with subsequent read-only confirmation, one-shot control regressions and actual close-only notice display.

### Publication

- [PUB-01] Release scope contains session interruption and its notice only. Other planned features remain deferred.

## 한국어

### 범위

- [SCOPE-01] 실제 사용량 초기화 감지 또는 60초 동안 정상 사용량 조회 부재 시, 실행 중인 로컬 Codex 작업에 한 차례 중단 요청
- [SCOPE-02] 공식 로고·중단 이유·확인 상태·감지 시각을 담은 별도 알림 창, Codex 앱 유지

### 호환성

- [COMPAT-01] Windows 11 x64·Codex 26.1013.4894.0의 세션 중단 지원, 보호를 위한 독립 사용량 감시 활성화 필요
- [COMPAT-02] 저장한 파일·기존 사용량 하한 보호 보존. 재개 잠금 없이 Codex의 직접 재개·새 메시지 허용
- [COMPAT-03] 다른 운영체제·원격·클라우드 작업의 세션 중단 미지원. 감지와 서버 처리·과금의 동시 종료 보장 제외

### 검증

- [VERIFY-01] Windows 실제 native 작업 네 개 중단·후속 읽기 전용 확인·한 차례 제어 회귀·닫기만 제공하는 실제 알림 창 표시의 결합 검증

### 게시

- [PUB-01] 세션 중단·알림만의 출시 범위, 다른 예정 기능은 후속 유지
