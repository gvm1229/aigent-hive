# Aigent Hive 0.13.1

## English

### Scope

- [SCOPE-01] Apply the existing remaining-usage floor to active Codex work when midway monitoring is enabled.
- [SCOPE-02] Retry failed readings through a fresh connection and retain the 60-second protection deadline.
- [SCOPE-03] Show the applied floor, remaining usage and stop confirmation in the existing notice.
- [SCOPE-04] Preserve knowledge, settings, stop history and the monitoring choice during updates.
- [SCOPE-05] Correct observation timing after explicit reactivation and identify the actual monitoring build.
- [SCOPE-06] Preserve selected user Skills during authenticated updates from 0.13.0.

### Compatibility

- [COMPAT-01] Session interruption requires opt-in on Windows 11 x64 with Codex 26.1013.4894.0.
- [COMPAT-02] Keep Codex open. Allow direct resume without a lock. The notice only closes its own window.
- [COMPAT-03] Other operating systems, remote tasks and cloud tasks lack direct interruption support. Server processing and billing termination are not simultaneous guarantees.
- [COMPAT-04] Chat stops do not guarantee exit of ordinary external commands already running. Separate local AI sessions and subagents stay interruption targets.

### Verification

- [VERIFY-01] Windows regressions cover usage policy, owner inheritance, manual resume, reading validation and update preservation.
- [VERIFY-02] Live sensing passed 1,810 seconds with 115 valid readings, connection replacement and backup recovery without false 60-second outages.
- [VERIFY-03] Windows PowerShell 5 notice display covers extended paths, numeric reasons, confirmation changes and close-only controls.

### Publication

- [PUB-01] Numbered public test for 0.13.1. Stable publication and user installation require separate version-specific approval.
- [PUB-02] Release scope contains existing usage protection corrections only. Other planned features remain deferred.

## 한국어

### 범위

- [SCOPE-01] 중간 중단 감시를 켠 경우 기존 잔여 사용량 하한을 실행 중인 Codex 작업에도 적용
- [SCOPE-02] 조회 실패 시 새 연결로 재확인, 정상 조회60초 부재의 보호 기준 유지
- [SCOPE-03] 기존 안내 창에 적용 하한·남은 사용량·실제 중단 확인 표시
- [SCOPE-04] 갱신 시 지식·설정·중단 기록·감시 활성 선택 보존
- [SCOPE-05] 명시적 다시 켜기의 관측 시간 보정과 실제 감시 실행 버전 표시
- [SCOPE-06] 일부 기능만 고른 설치에서도 설정을 지키며0.13.0에서 갱신

### 호환성

- [COMPAT-01] Windows 11 x64·Codex 26.1013.4894.0의 직접 중단 지원, 중간 중단 감시의 명시적 활성화 필요
- [COMPAT-02] Codex 앱 유지, 재개 잠금 없는 직접 재개 허용. 안내 창의 닫기는 해당 창에만 적용
- [COMPAT-03] 다른 운영체제·원격·클라우드의 직접 중단 미지원. 서버 처리·과금의 동시 종료 보장 제외
- [COMPAT-04] 대화 중단 뒤 이미 시작한 일반 외부 명령의 계속 실행 가능. 별도 로컬 AI 세션·하위 에이전트는 중단 대상 유지

### 검증

- [VERIFY-01] 현재 Windows 회귀의 사용량 정책·소유 대화 계승·수동 재개·조회 검증·갱신 보존 확인
- [VERIFY-02] 실제 조회1,810초·정상 관측115개, 연결 교체·보조 조회 복구와 허위60초 공백0건 확인
- [VERIFY-03] Windows PowerShell 5의 실제 안내 창에서 확장 경로·숫자 이유·확인 상태 갱신·닫기 전용 동작 확인

### 게시

- [PUB-01] 0.13.1 번호 시험판 검토안. 정식 게시·사용자 설치의 해당 버전 승인 별도
