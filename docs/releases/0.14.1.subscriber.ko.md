# Aigent Hive v0.14.1 업데이트 내역:

## 새 기능

- **저장 공간 확인과 정리 미리보기 추가**
  - `hive storage`로 지식·색인·백업·감시 프로그램별 사용량 확인, 변경 없음
  - `hive prune --dry-run`으로 쓰지 않는 감시 프로그램 목록 확인, 삭제는 `--confirm`에서만

## 수정

- **전역 사용량 하한 변경 실패 수정**
  - 하한을 바꿔도 저장된 선택 기록이 유효하게 남아 변경 성공

- **직접 해제한 지식 연결의 해제 유지**
  - 동기화·재구성 뒤에도 다시 연결되지 않음, 사용하려면 직접 재연결
