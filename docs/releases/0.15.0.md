# Aigent Hive 0.15.0

## English

### Scope

- [SCOPE-01] Add reloadable role configuration and declarative worker profiles without model calls.
- [SCOPE-02] Prepare digest-bound inbox requests through signed orchestration events. Hive does not launch workers.
- [SCOPE-03] Add nine functional Skill entries, canonical names, aliases, and Korean and English notices.

### Compatibility

- [COMPAT-01] Preserve existing commands, Skill paths, and fixed-model user profiles.
- [COMPAT-02] Freeze public 0.14.2 project and user sources for authenticated historical upgrades.
- [COMPAT-03] Keep orchestration default-off until real host consumption, receipts, cancellation, and safe reclaim are qualified.

### Verification

- [VERIFY-01] Codex on Windows verified configuration, schema rejection, inbox preparation, aliases, and both display languages.
- [VERIFY-02] Public 0.15.0-test.1 acceptance passed on Windows x64, macOS arm64 and Linux musl x64.
- [VERIFY-03] Windows 11 verified the real round trip with Claude Code 2.1.322 and Codex. Gemini and other OS round trips remain unverified.

### Publication

- [PUB-01] Stable 0.15.0 promotes the accepted 0.15.0-test.1 product.
- [PUB-02] Three OSes accepted roster merge and rejection, and `roster check` on host-supplied output in 0.15.0-test.1.
- [PUB-03] Those OSes also accepted inert summon preview, signed Prepare, nine god entries and aliases, and project upgrade from 0.14.2.
- [PUB-04] Orchestration is disabled with no enablement path in this build.
- [PUB-05] Windows verified the real Claude lab Stop-to-Codex-to-return round trip. Gemini and other OS round trips are outside this test.
- [PUB-06] Cancellation and reclaim on a real host remain unverified and are not accepted by this test.
