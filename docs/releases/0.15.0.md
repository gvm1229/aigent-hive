- [COMPAT-02] Freeze public 0.14.2 project and user sources for authenticated historical upgrades.

- [VERIFY-01] Codex on Windows verified configuration, schema rejection, inbox preparation, aliases, and both display languages.
- [VERIFY-02] Windows verified preservation, upgrades, rollback, and interrupted recovery from 17 public stable project fixtures.
- [VERIFY-03] Real Claude Stop-to-Codex feedback and Gemini execution remain unverified. Other operating systems and public acceptance remain unverified.

### Publication

- [PUB-01] Draft only. No 0.15.0 public test, tag, publication, merge, or user installation has run.
- [PUB-02] Public stable stays at 0.14.2. 0.15.0-test.1 accepts, on three OSes: roster merge and rejection, `roster check` on host-supplied output, inert summon preview and signed Prepare, nine god entries and aliases, and upgrade from 0.14.2. Orchestration is disabled with no enablement path in this build. Real Claude Stop→Codex→return, Gemini execution, cancellation and reclaim on a real host are unverified and are not accepted by this test.
