# Aigent Hive 0.16.1

## English

### Scope

- [SCOPE-01] A registered project folder that was deleted, moved or made unusable is skipped. Knowledge commands keep working for every other project.
- [SCOPE-02] A skipped project stays registered and reconnects automatically when its folder becomes usable again.
- [SCOPE-03] A changed or missing source drops only its own search result. Other results still return; outdated text never returns.
- [SCOPE-04] A knowledge write stopped before writing anything no longer blocks later commands. `hive index rebuild` repairs it from disk.
- [SCOPE-05] Stray files such as `Thumbs.db` or `desktop.ini`, and links inside knowledge folders, are ignored instead of failing every command.
- [SCOPE-06] A session coordination lock left by a crash is cleared after five minutes.

### Compatibility

- [COMPAT-01] Upgrade from public 0.16.0 and earlier supported versions keeps user answers, knowledge, project registrations and project files.
- [COMPAT-02] A partly written knowledge write, a corrupt recovery record and importing into a missing folder still stop with an error.

### Verification

- [VERIFY-01] Rust tests cover deleted and replaced project folders, dropped stale results, never-written recovery records, stray files and abandoned locks.
- [VERIFY-02] Public 0.16.1 test acceptance and checks on the maintainer PC are recorded in the release evidence.

### Publication

- [PUB-01] Stable 0.16.1 promotes the accepted 0.16.1 test product.

## 한국어

### 범위

- [SCOPE-01] 삭제·이동되었거나 쓸 수 없게 된 등록 프로젝트 폴더는 건너뜀. 다른 프로젝트의 지식 명령은 계속 동작.
- [SCOPE-02] 건너뛴 프로젝트의 등록 유지. 폴더를 다시 쓸 수 있게 되면 자동 재연결.
- [SCOPE-03] 원본이 바뀌었거나 사라진 검색 결과만 제외. 나머지 결과는 반환, 오래된 본문은 미반환.
- [SCOPE-04] 아무것도 쓰기 전에 멈춘 지식 기록으로 인한 이후 명령 차단 없음. `hive index rebuild`가 디스크 내용으로 복구.
- [SCOPE-05] 지식 폴더의 `Thumbs.db`·`desktop.ini` 같은 잡파일과 링크는 무시. 모든 명령의 실패 원인에서 제외.
- [SCOPE-06] 충돌로 남은 세션 조정 잠금은 5분 뒤 자동 정리.

### 호환성

- [COMPAT-01] 공개 0.16.0과 이전 지원 버전에서 갱신 시 사용자 답변·지식·프로젝트 등록·프로젝트 파일 보존.
- [COMPAT-02] 일부만 쓰인 지식 기록, 손상된 복구 기록, 없는 폴더로의 가져오기는 계속 오류로 중단.

### 검증

- [VERIFY-01] Rust 시험: 삭제·교체된 프로젝트 폴더, 오래된 결과 제외, 쓰이지 않은 복구 기록, 잡파일, 버려진 잠금.
- [VERIFY-02] 0.16.1 공개 시험 수용과 유지관리자 PC 확인은 출시 근거에 기록.

### 게시

- [PUB-01] 정식 0.16.1은 수용된 0.16.1 시험 제품을 승격.
