# Aigent Hive v0.15.2 업데이트 내역:

## 수정

- **갱신이 같은 오류를 끝없이 반복하던 문제 수정**
  - 사용량 보호 설정이 바뀐 PC에서 `hive update`를 다시 실행해도 "monitor choice changed" 오류만 반복되던 문제. 이제 현재 상태로 다시 확인하고, 터미널에서는 보호 선택 질문 표시
  - 이미 답한 선택과 적용된 설정은 그대로 유지
  - 0.15.1에서 이미 이 오류가 반복되는 PC는 `hive update`가 0.15.1에서 멈추므로 `npm install -g aigent-hive@0.15.2` 실행 뒤 `hive update` 다시 실행

- **설치 실패 뒤 Codex 플러그인 목록이 깨지던 문제 수정**
  - 첫 설치가 중간에 실패하면 Codex에 Hive 마켓 등록만 남아 `codex plugin list` 등이 실패하던 문제. 이제 실패 시 Codex 등록을 먼저 정리한 뒤 파일 복원
  - 이미 이 상태가 된 PC도 0.15.2로 갱신하면 자동 복구

- **Claude Code에 Hive가 설치되지 않던 문제 수정**
  - 예전 시험 설치가 지워진 폴더를 가리키는 `aigent-hive` 등록을 남긴 경우, 이를 정리하고 Hive 플러그인과 Skill 설치. 실제로 존재하는 다른 등록은 보존

- **최신 Antigravity CLI에 Hive가 설치되지 않던 문제 수정**
  - Antigravity CLI(`agy`) 1.2.x가 지원 범위 밖으로 거부되던 문제. 1.2.x에서도 Hive 플러그인과 Skill 설치

---

## 개선

- **Hive를 여러 앱에 한 번에 설치하는 선택 안내 개선**
  - 설정의 "Hive를 사용할 앱" 질문에 여러 개 선택 가능 안내 표시. `1,2`나 `1 2`처럼 번호나 이름을 쉼표나 공백으로 구분해 Codex·Claude Code·Antigravity를 함께 선택
  - 선택한 앱은 한 번의 적용으로 함께 설치, 앱마다 별도 등록으로 서로 충돌 없음

- **지식 검색 색인 문제로 설치 전체가 멈추지 않도록 개선**
  - 연결한 외부 폴더 때문에 색인 재생성에 동의가 필요하면 설치·갱신은 끝내고, 다음 단계로 `hive index rebuild --user-root <홈 폴더>` 안내. 외부 폴더는 동의 전까지 미접근
