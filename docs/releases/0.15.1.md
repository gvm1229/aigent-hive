# Aigent Hive 0.15.1

## English

### Scope

- [SCOPE-01] Detect local project languages, frameworks, package managers, commands, and structure without model calls.
- [SCOPE-02] Separate project facts from a short Hive entry and preserve user rules outside Hive markers.
- [SCOPE-03] Reuse verified user plugins and preview detected project changes before explicit application.
- [SCOPE-04] Default to readable Korean or English CLI results. Keep explicit JSON output and native hook protocols.
- [SCOPE-05] Global and project directives record facts an agent would keep in its own memory as Hive Markdown knowledge, project first and global only when general.
- [SCOPE-06] Every Skill description states what the Skill does, including the nine god Skills.

### Compatibility

- [COMPAT-01] Read existing general and custom answers and retain approved project-only Skills.
- [COMPAT-02] Freeze exact public 0.15.0 project and user sources for authenticated historical upgrades.
- [COMPAT-03] Keep local delivery when plugin verification fails. Approved roles or optional features require extra project files.
- [COMPAT-04] Allow usage show and setup summaries without JSON options. Preserve supported JSON schemas, values, and exit codes.

### Verification

- [VERIFY-01] Windows local detection matches 29 of 30 original labels and all 30 reviewed labels. General defaults fall from 30 to two.
- [VERIFY-02] Fixed retrieval remains 22 of 40, including three of ten held-out queries. Retrieval changes belong to stage five.
- [VERIFY-03] Public 0.15.1-test.1 acceptance passed on Windows x64, macOS arm64 and Linux musl x64, including plugin-backed and local Skill delivery.
- [VERIFY-04] Real host Skill discovery and a second PC without the plugin remain unverified.

### Publication

- [PUB-01] Stable 0.15.1 promotes the accepted 0.15.1-test.1 product.
