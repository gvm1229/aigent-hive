# Aigent Hive v0.16.1 업데이트 내역:

## 수정

- **지운 프로젝트 폴더 때문에 기억 기록이 멈추던 문제 수정**
  - 등록한 프로젝트 폴더를 지우거나 옮겨도, 그 폴더만 건너뛰고 다른 프로젝트의 기억 기록·찾기는 그대로 동작
  - 건너뛴 프로젝트는 등록 목록에 남고, 폴더가 다시 생기면 자동으로 다시 연결

- **바뀐 기억 하나 때문에 찾기 전체가 실패하던 문제 수정**
  - 원본이 바뀌었거나 사라진 결과 하나만 빼고 나머지 결과는 그대로 전달
  - 오래된 내용은 지금처럼 결과에서 제외

- **도중에 멈춘 기억 기록이 다음 명령을 막던 문제 수정**
  - 아무것도 쓰기 전에 멈춘 기록은 바로 정리되어 다음 명령 정상 동작
  - 남은 흔적은 `hive index rebuild`로 디스크 내용에 맞춰 복구

- **`Thumbs.db`·`desktop.ini` 같은 잡파일로 모든 명령이 실패하던 문제 수정**
  - 지식 폴더 안의 이런 파일이나 링크는 읽지 않고 건너뜀

- **비정상 종료 뒤 남은 세션 잠금이 계속 일을 막던 문제 수정**
  - 프로그램이 갑자기 꺼져 남은 잠금은 5분 뒤 자동 정리

- **업데이트해도 내 자료는 그대로**
  - 0.16.0과 이전 지원 버전에서 올려도 설정 답변·기억·프로젝트 등록·프로젝트 파일 보존
  - 절반만 쓰인 기록, 망가진 복구 기록, 없는 폴더로 가져오기는 안전을 위해 지금처럼 오류로 멈춤

- **업데이트 방법**
  - `npm install -g aigent-hive@0.16.1` 실행 뒤 `hive update`로 설치한 앱 연결까지 갱신
