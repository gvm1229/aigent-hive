# Archive 안내

완료·대체된 계획과 과거 상태의 보존 위치.

## 사용 경계

- 현재 작업의 자동 선행 확인 대상 제외
- 활성 계획·현재 상태·제품 계약의 정본 사용 금지
- 과거 결정·출시 증거 확인 때만 제한적 확인
- 일반 문체·현재 링크 검사 대상 제외
- [`MANIFEST.md`](MANIFEST.md)의 이전 경로·digest·대체 정본 확인 필수

## 구조

| 경로 | 내용 |
| --- | --- |
| `state/` | 과거 시점의 상태 snapshot |
| `plans/foundations/` | 완료된 기반·phase·stage·계약 계획 |
| `plans/releases/` | version별 완료 계획·출시 실행 기록 |

현재 작업: [`../plans/PLAN.md`](../plans/PLAN.md)

버전 미지정 후보: [`../plans/backlog/README.md`](../plans/backlog/README.md)
