> 공개 Stable: `0.14.0`
> 현재 단계: 원래 조건 15/15 완료. 정식 0.14.0 게시·공지 완료, PC 본체 0.14.0·감시 복구의 Windows 승인 대기

## 목표와 결정

- [상세 구현 계획](../../plans/0.14.0-implementation.md): AI 없는 전역·프로젝트 설정과 첫 갱신의 질문·적용, 설정 출처·기록, 사용량 보호 기본 비활성, 보존형 제거
- [남은 구현의 작은 완료 단위](../../plans/details/0.14.0-delivery-milestones.md): M00–M24, 단위별 검증·ship·실제 설치 격리. 기존 15개 완료 조건과 집계 유지
- 사용자 선택: 프로젝트까지 CLI 확장에 따라 0.14.0으로 변경. 제거는 미리보기·확인·자료 보존만, 비대화형 갱신은 기존 선택 보존·질문 보류
- 필수 수용: 수정하지 않은 공개 0.13.1에서 시작한 갱신 중 새 질문·답변·적용. 다음 버전·AI 수동 재설정으로 대체 금지
- 기존 0.13.2 통신 호환·0~99% 구현과 test.2 증거 보존. 정식 0.13.2 공개는 보류 유지, 해당 수정은 0.14.0 통합
- 최종 계획의 구현 승인 수신. 제품 소스 메타데이터 0.14.0 동기화, 실제 설치의 회귀 시험 제외·정식 PC 갱신 별도 실행
- 2026-10-26 사용자 정정: 작업 브랜치 `feature/interactive-cli-0.14.0`, 검증 단위별 로컬 커밋. 타 작업의 미추적 학습·평가·별도 계획 문서 보존
- 정식 0.14.0의 main 통합·태그·게시·실제 설치와 새 공지 전송은 해당 범위 승인 전 제외. 0.13.2 승인 자동 이전 없음

- 2026-10-30 [정식 실행](../../plans/0.14.0-stable-release.md): 현재 버전의 main 통합·게시·이 PC 갱신·공지 승인, 40%·초기화 중단 유지
