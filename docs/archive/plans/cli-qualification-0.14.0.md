## Q140-001 — 설정 비용

- 신고: 초기 설정만으로 Plus의5시간 한도 소진. 실제 모델·속도·기존 사용량·오류 이력 부재, 원인 미확인. 비싼 모델이나 Fast만의 문제로 확정 금지
- 고정 합성 입력: 전역 빠른 설정, 전역 맞춤 설정, 프로젝트 빠른 설정, 사용자 역할 포함 맞춤, 한 항목 재설정, 취소 후 재개, 인증된 불완전 설치 복구
- 각 입력에서 직접 CLI와 AI 연결을 분리. 측정 항목: 질문/모델 대화/도구 호출 수, 모델에 전달한 UTF-8 byte, 가능한 입력·출력·추론 token, 경과 시간, 재시도, 실제 최종 설정·보존 지문
- 모델명·추론 강도·속도·호스트·OS·새 대화 여부·캐시 조건 기록. 알려지지 않은 값은unknown. 지원되는 호스트 제공 계측만 사용, 제공자 API 호출·원문 대화 수집 없음
- 사용자 확인의 기본 non-Fast 유지, 도구 priority와 UI Fast 구분. 미제공 속도·토큰은 unknown. [확인 근거](../../research/cli-model-validation-0.14.0.md)
- 직접 CLI 합격: 생성형 모델 호출0회, 같은 정상 입력에 사용자 질문 외의 AI 필요0건
- 정상 AI 연결 목표: 시작 안내와 결과 설명의 두 대화 단계, 모델 왕복이 사용자 답변 수에 비례하지 않는 구조. 전체 schema 재조회0회, 같은 실패 무조건 재시도0회
- 구조화 정상 응답은 상태4KiB·다음 질문8KiB·완료 요약8KiB 이내. 초과 상세는 명시적section/페이지 조회로 분리, 필요한 값의 조용한 잘라내기 금지
- 공개0.13.1 배포본/설정Skill을기준으로 전역빠른설정·프로젝트빠른설정을각각2회비교. 같은호스트/모델/추론강도/일반속도/답안/기능의도사용. Hive소유입력byte 중앙값이각각50% 이상감소. 구독 한도 절감률의 직접 증명과 구분, 합격을 위한 검사·보존 절차 제거 금지
- 같은 매개변수 최대5회, 변경 시 별도 시험. 누적 합계는 한도에서 제외.5회 초과 필요 시 기존 근거 활용 우선, 불가능할 때만 승인 요청. 고정 입력·검사의 develop 회귀 유지, 세부는 수용 근거 참조
- Codex 후보: Luna low/medium·일반 속도. 같은 기준에서 low 우선, 실패 시 medium 평가; 통과한 최소 강도 권고. 모두 실패하면 설정 경로 보정·재시험, 상위 모델 기본 권고 금지. 호스트 설정 자동 변경 없이 지원 경로로 선택
- 비교용 상위 모델/Fast 실사용은 기본 요구 제외. 사용자 계정 고의 소진 금지. Plus 한도 증감은 다른 작업과 공유되므로 token·byte·호출 수와 별도로 보고
- 완료: 각빠른설정의2회독립실행의 정상 결과와 입력 감소, 실패 경로의 재시도 제한. 실제 소형 모델 평가 미실행을모의 결과로 대체하지 않는 경계
