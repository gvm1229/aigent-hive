# 0.13.1 재시작 뒤 초기화 비교 기준

> Plan version: 0.13.1
> Scope: product

## 원인과 경계

- 사용자 신고: 잔량60%·초기화 없는 상황의 초기화 안내. 설치0.13.0 검사에 재시작 전 기록과의 비교 결과, 새 조회는 정상 허용. 덮어쓴 이전 잔량 부재로 해당 사건의 실제 초기화·정확한 오탐 원인 미확정
- 확인한 결함: `usage_control.rs::enforce_captured`에서 다른 프로세스의 기록도 초기화 비교에 사용, 만료된 이전 관측의 비교 제한 부재. 중단 기록·설정 보존, 최신 정상 관측으로 기준 수립
- 직접 중단 감시의 현재 기준과60초 보호·하한·독립0% 보호 유지. 과거 기록의 삭제·보호 해제·앱 종료 금지

## 실행 항목

- [x] [UG131-010] 재시작·만료 기준의 초기화 오판 방지

1. `usage_control.rs::enforce_captured`의 초기화 기준은 현재 프로세스에 결합한 기록만 사용. `hive_core::usage_guard::detect_usage_reset`에서 새 측정 시각에 유효한 이전 관측만 비교, 시작 검사와 감시의 같은 판정 사용. 기존 하한·0%와 신선한 증가·확인된 구간 교체 유지
2. `tests/conformance/contracts/test_usage_control.py`의 합성 설치에서 다른 프로세스·만료된 이전 값의 잔량 증가를 재현. 최초 기준 수립 허용, 현재 프로세스의 유효한 증가에는1회 중단·정상 재개, 낮은 잔량·0%는 계속 거부
3. 수정 전 실패·수정 뒤 같은 검사 통과·엄격 검사·최신 공개test.4에 근거 결합. 실제 사용자 이전 값 부재를 재현 성공으로 대체 금지, 설치된0.13.0의 제품 바이트 변경 없음

## 현재 앱 변경

- 재개 시 현재 앱26.1016.6573.0 확인, 기존 실제 중단 수용26.1013.4894.0과 구분. 기존 제어부는 새 버전 연결 거부, 이름만 허용하는 변경 금지
- 새 버전의 로컬 제어 계약과 읽기 전용 연결 확인을 먼저 수행. 같은 계약의 근거·현재 앱 수용이 없는 경우 직접 중단 지원으로 표시 금지, 해당 수용의 계획을 확정한 뒤 구현

- [x] [UG131-011] 현재26.1016 앱의 동일 제어 계약과 한정 수용
  - state: complete; depends: UG131-005; evidence: repo:docs/research/usage-current-app-0.13.1.md#sha256:cff2b85e6b5facf17347214215bf88853a4ffb70d8bb6e3852e81dc15b486509

1. 현재 설치의 읽기 전용 계약 확인: `thread-follower-interrupt-turn`의 버전3·`mode=user-stop`·응답 `interruptedTurnId`, `turn/interrupt` 연결과 하위 AI 정리. 새 계약이나 임의 버전 허용 제외
2. `usage_monitor.rs::require_desktop_version`와 `desktop.ps1::Assert-DesktopVersion`에 확인한 두 정확한 버전만 허용. 상태·미리보기의 허용 목록과 실제 버전 구분, 알려지지 않은 버전 거부 회귀
3. 기존 승인 시험 대화2개 재사용, 현재 앱의 읽기 전용 확인 뒤 긴 추론·도구 호출·하위 AI 취소와 원인 안내·정상 재개를 독립 관측. 앱·비대상 대화 보존, 일반 외부 명령 계속 실행의 승인한 한계 유지
4. 새 제어부30분의 읽기 전용 관측·보조 회복·허위 중단0건, 공개test.4 갱신에 현재 앱 지문 결합. 이전 버전 수용과 별도 결과, 실패 시 해당 새 버전의 지원 주장 보류

- 공개 갱신의 현재 앱 경계: 구버전0.13.0 감시기는26.1016 미지원이므로 실행 금지. 격리 환경에서 정확한 공개0.13.0의 `preview`·`status` 출력으로 이전 설정·초기 기록을 생성하고, 그 공개 실행 파일의 지문과 일치한 과거 예약 어댑터로 실제 예약만 등록. 이전 제어부는 시작하지 않은 상태의 새 공개판 전환·정상 조회를 검증. 실제 이전 제어부가 실행 중인 인계는26.1013의 기존 수용과 별도 증명, 현재 앱에서 재실행한 결과로 표시 금지
