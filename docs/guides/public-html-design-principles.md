# 공개 HTML 디자인 원칙

## 목적

- Hive 안내 문서의 일관된 브랜드·정보 구조·읽기 흐름 유지
- 기술 내용을 처음 접하는 사용자도 핵심 답과 다음 행동을 빠르게 확인할 수 있는 구성
- 현재 기준 구현: [`hive-core-features.ko.html`](../hive-core-features.ko.html),
  [`hive-install-guide.ko.html`](../hive-install-guide.ko.html)

## 브랜드 체계

| 역할 | 토큰 | 값 | 사용 범위 |
| --- | --- | --- | --- |
| 보조 강조색 | `--gold` | `#F5A623` | 구분선·단계 번호·상태 표식·강조 테두리 |
| 짙은 강조색 | `--gold-dark` | `#D98A00` | 작은 제목·표 머리·상호작용 상태 |
| 옅은 강조면 | `--gold-tint` | `#FFF6DF` | 안내 상자·열린 상세 영역 |
| 구조색 | `--navy` | `#0B1B31` | 브랜드 바·주요 글자·코드 영역 대비 |
| 본문색 | `--ink` | `#15171B` | 제목·핵심 본문 |
| 최대 본문 폭 | `--wrap` | `960px` | Hero·요약·탐색·본문 정렬 |

- 보조색은 벌집 금색 계열만 사용, 참조 문서의 빨간색 계열 사용 금지
- 구조색 navy와 넓은 흰색 여백으로 금색의 시각적 과밀 방지
- 로고 정본: [`hive-logo-mark.png`](../assets/branding/hive-logo-mark.png)
- 로고 비율 유지, 임의 재채색·왜곡·대체 이미지 생성 금지
- 장식용 브랜드 바: 높이 `6px`, 앞쪽 금색 `160px`, 나머지 navy

## 정보 구조

1. 브랜드와 문서 목적을 제시하는 Hero
2. 대상·소요 시간·지원 범위를 모은 한눈 요약
3. 긴 문서의 위치 이동을 돕는 sticky 탐색
4. 번호·제목·금색 구분선으로 시작하는 본문 구역
5. 관련 문서와 최신성 경계를 알리는 바닥글

- 결론과 사용자의 다음 행동 우선
- 한 구역에 하나의 질문 또는 작업 흐름 배치
- 표·카드·단계·코드 블록의 역할 분리
- 기능 설명은 카드와 경계 비교, 설치 설명은 번호 단계와 명령 예시 중심

## 타이포그래피와 간격

- 기본 글꼴: `Pretendard`, 실패 시 `Malgun Gothic`, 마지막 대체 `sans-serif`
- 명령 글꼴: `Cascadia Code`, `SFMono-Regular`, `Consolas`, `monospace`
- 본문 행간 `1.72`, 긴 한국어 낱말의 안전한 줄바꿈과 문장 단위 유지
- Hero 제목 약 `39px`, 본문 구역 제목 약 `23px`, 본문 약 `15.5px`
- Hero·본문 좌우 여백 `28px`, 본문 구역 위 여백 `46px`
- 장식보다 계층·정렬·반복 간격을 통한 구분 우선

## 구성 요소

- Hero 로고 패널: `154px` 정사각형, 옅은 금색 방사형 배경, 낮은 navy 그림자
- Callout: 금색 왼쪽 테두리와 옅은 금색 배경, 핵심 전제·주의 사항 전용
- Card: 금색 위쪽 테두리와 옅은 회색 바탕, 동급 기능 그룹 전용
- Step: 원형 금색 번호와 실행 순서, 한 단계당 하나의 주 행동
- Code: 짙은 navy 배경과 밝은 본문, 실행 위치를 알리는 작은 label 포함
- Details: 대체 설치·문제 해결처럼 기본 흐름 밖의 보조 정보

## 반응형·인쇄

- `760px` 이하: Hero 단일 열, 로고 `112px`, 긴 흐름·호스트 목록 단일 열 전환
- `520px` 이하: 카드·통계·경계 비교·단계 단일 열, 로고 `96px`
- 좁은 화면 탐색: 가로 스크롤 허용, scrollbar 장식만 숨김
- 코드 블록: 가로 넘침 처리와 긴 명령 줄바꿈 지원
- 인쇄: sticky 탐색과 장식 요소 축소, 내용 손실 없는 흰색 바탕 우선

## 접근성과 정확성

- 문서 언어 `lang="ko"`, UTF-8, viewport, 문서별 description 필수
- 의미 있는 로고 `alt` 제공, 장식 전용 요소 `aria-hidden="true"` 적용
- 탐색 링크의 `hover`와 `focus-visible` 상태 동등 제공
- 색상만으로 순서·상태를 전달하지 않고 번호·제목·문구 병행
- 링크·이미지·anchor의 repository 상대 경로 사용과 정적 검증
- 설치 명령은 실제 CLI parser와 현재 release 계약 확인 뒤 표기
- `hive install`의 `--host`는 명령당 하나만 허용, 복수 호스트는 host별 명령 반복과
  전역 설정의 `selected_hosts` 복수 선택으로 구성
- `--hosts` 또는 반복 `--host`를 한 명령에 넣는 미지원 예시 금지
