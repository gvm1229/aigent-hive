# 0.11.0 공개 HTML 안내 갱신

- 대상: `docs/hive-core-features.ko.html`, `docs/hive-install-guide.ko.html`
- 목적: 게시된 0.11.0 안정판의 기능·첫 설치 절차를 공개 HTML 두 페이지에 반영
- 경계: 문서·문서 계약 검사·연결된 지식만 변경. 제품·설치 실행 파일·과거 기준본·브랜드 이미지 바이트 유지

## 순서와 판정

1. 현재 안정판 안내·실제 Skill·설치 명령과 두 HTML 문구 비교. 오래된 단계·기능 이름·누락한 사용자 이점 목록화
2. 설치 안내의 5단계 유지: 실행 파일 설치 → 버전 확인 → 대화형 `hive update`에서 호스트 선택·전역 준비 → 호스트 대화에서 전역 선호와 새 질문 처리 → 별도 프로젝트 설정. 기존 설치자의 저장된 호스트 보존과 설치되지 않은 협업자의 선택권 명시
3. 핵심 기능 페이지에 선택형 Hook 파일 보호·긴 대화 뒤 선택 지침 복구·말로 요청하는 프로젝트 지침 갱신·Hive 없는 협업자 경계 반영. 사용량 리셋은 다음 점검 차단으로 설명하고, 현재 Skill ID는 `knowledge-scan` 사용
4. HTML 정적 계약의 카드 수·Skill 명칭·0.11.0 기능과 설치 단계 검사 갱신. 기존 로고 PNG·레이아웃·지식 표·외부 바이트 보존
5. 연관 지식 출처 지문과 현재 설명 보정. 문체·링크·문서·정적 계약 검사, 필요 시 좁은 화면 시각 확인. `develop` 커밋·원격 검사 뒤 문서 전용 PR로 `main` 반영

## 완료 증거

- 두 HTML의 0.11.0 현재 설명과 실제 명령 일치, 구버전 Skill ID·첫 설치 수동 연결 단계 0건
- 정적 계약·문서 검사 통과, Source Wiki 오류·경고 0건
- 제품 파일 변경 0건, 브랜치는 `main`·`develop`만 유지
