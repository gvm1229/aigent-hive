# 사용량 보호 중단 안내 창 0.12.1

> 적용 완료: [최종 알림 전용 동작](../../research/usage-stop-notice-0.12.1.md)·[설치와 증명 범위](../../research/session-stop-installation-0.12.1.md). 아래 명령 복사·잠금 문구는 정정 전 계획의 보존, 현재 구현과 재실행 지시에서 제외

## 이전 구현·보정 계획

- 범위: RST121-002·003의 사용자 안내 개선. Windows 실제 중단 두 번과 사용자 관측 보존, 추가 실제 중단 시험 중지
- 목적: 갑자기 멈춘 이유와 Hive의 보호 동작 구분, 앱 유지·자동 재개 부재·다음 행동의 명확한 표시
- 현재 전체 자동 확인은 4개 중 3개·미확인 1개. 실제 세 시험 실행의 중단 사건은 별도 통과, 자동 확인·설치 통과로 확대 금지
- 기본 동작: 안내 닫기·재개 방법의 명령 복사, 잠금·감시·작업 상태 변경 없음. 재개 동작의 사용자 선호 질문은 선택 사항, 답변 전 직접 확인·실행 동작 제외
- 재개 안내 보정: 잠금 중 새 대화도 중단되는 경계에 맞춰 외부 PowerShell의 정확한 확인 명령 복사 제공. 복사만 수행, 창 안의 명령 실행·사건 확인·잠금 해제·작업 재개 없음

## 구현과 경계

- 소유: Codex. 기존 Windows 창의 운영 화면, 별도 제품 정체성·다른 기능 확대 제외
- `usage_monitor/notice.ps1`: WPF 안내 창과 순수 표시 상태 계산. 중단 이유·확인 상태·감지 시각·재개 방법, 기술 수치는 접힌 상세 영역
- `usage_monitor/windows.ps1`: 기존 예약 작업·앱 신원 조회 유지, 이전 안내 구현을 새 파일로 이동. 앱 제어 코드와 창 표시 분리
- `usage_monitor/platform.rs::notify`: 새 고정 안내 스크립트·원인 전달, 감시 제어부와 별도 실행. 5초 표시 확인·표시 실패 시 간단한 Windows 안내 대체
- 새 할당량 보호와 60초 조회 공백의 서로 다른 문구. 확인 실패·현재 실행 없음·상태 읽기 실패·새 사건·확인 완료를 성공으로 바꾸는 표시 금지
- 실제 사용자 창에 시험 문구 제외. 별도 표시 미리보기와 실제 합성 사건을 명확히 구분, 미리보기에서 감시·중단·설치·설정 변경 없음

## 화면 기준

- Windows 기본 창 조작·한국어 시스템 글꼴, 밝은 바탕·진한 글자·의미에 따른 초록/갈색 상태. 색만으로 의미 전달 금지
- 첫 화면: 원인과 Hive의 행동 → 확인 상태 → 앱 유지·자동 재개 부재 → 재개 방법 → 안내 닫기
- 긴 원문·식별자·명령줄의 기본 노출 제외. 상세 영역에 중단 요청·확인·미확인·연결·감시 상태
- 장치 독립 크기·자동 줄바꿈·스크롤, 좁은 창·높은 배율·키보드 초점·Esc 닫기·접근성 이름 확인

## 검증과 완료

- 현재 표시 수용: [Windows 안내 근거](../../research/usage-stop-notice-0.12.1.md), 실제 144 DPI·표시844ms·닫기와 Esc 경로의 사건 보존. 원래 Codex 앱 유지, 추가 실제 중단 없음
- 순수 상태 회귀: 실제/시험·초기화/조회 실패·성공/부분 확인·읽기 오류·확인 완료의 이유 보존
- 실제 Windows에서 새 표시 코드만 실행, 원래 Codex 앱 신원·저장 상태 지문 보존. 표시·상세 펼치기·닫기와 원인 지속 확인
- 대표 화면을 직접 확인하고 저장, 기본·좁은 창·긴 문구의 잘림 검사. 실제 실행 배율과 별도 그림 배율의 증명 범위 구분
- Rust 포함 스크립트의 Windows 명령줄 크기·관련 회귀·엄격 Clippy·빌드. 기존 실제 중단 근거 재사용, 추가 중단 없음
- 남은 자동 확인 1건은 읽기 전용 근거와 모의 회귀로 별도 해결. 설치는 전체 수용 조건 충족 후 기존 승인 경로, 정식 게시 별도 단계

## 추가 중단 없는 확인 보정

- `desktop.ps1::Interrupt-Response`: 새 실행 식별자나 오류 때만 재확인 표시, 실행 식별자 없는 반복 응답·같은 식별자의 중복 응답으로 확인 상태 무효화 금지
- `Advance-Stop`: 아직 받지 못한 대화 상태 우선, 모든 대화의 첫 상태 수신 전 이미 받은 대화의 재조회 금지. 중단 요청·앱 제어 규약·2초/5초 기준 변경 없음
- 회귀: 새 대화 확인을 가로막는 반복 조회와 불필요한 재확인 표시의 실패 재현 → 수정 → 현재 앱의 읽기 전용 상태 수신·기존 정확한 중단 사건 비교
- 기존 두 실제 중단의 범위·시간 근거 유지, 새 전체 실제 중단 시험으로 확대 금지. 설치 선행 조건은 미충족 항목별로 계속 보존
- 조회 공백의 읽기 시험: 정상 제품 native probe 1회 → 자식 조회에만 실패 프록시 적용해 연속 60초 실패 관측 → 정상 환경의 새 조회 회복. 감시 제어·앱 중단 호출 없음, 실제 센서 실패와 Rust의 60초 상태 전이 시험을 분리
- 이전 긴 셸의 종료 시각은 정확한 PID·생성 시각과 Windows 실행 종료 기록만 대조. 기록 부재를 5초 종료 통과로 계산하지 않는 경계

## 기존 실제 중단과 수정 부문의 결합 수용

- 사용자 관측 두 번과 정확한 native 중단 사건 재사용. 두 번째 시험의 네 실행 모두 감지 초 기준 283~306ms, 새 읽기에서 네 실행의 interrupted 확인 4/4·전체 상태 10/10·1180ms
- 실제 시험 바이너리와 후보의 중단 요청 본문·앱 신원·예약 작업·Rust 제어부·센서 코드 동일성 필수. 이전 실제 바이너리와 후보에 해당 스크립트가 실제 포함된 지문 확인
- 수정 부문은 확인 순서·표시뿐인 경계. 모의32개·Rust25개·표시11개·실제 UI 진입·60초 넘는 조회 실패·회복·정확한 시험 사건 확인·자동 재개 부재를 함께 검증
- 설치 영수증의 결합 수용 단계와 원래 실패한 전체 자동 영수증 분리. 원래 실패·현재 새 대화 실행을 전체 중단 성공으로 바꾸는 처리 금지
- 설치기는 후보 지문·필수 근거 파일 지문·현재 제품 소스 지문·각 검증 결과를 모두 확인. 어느 하나 누락·불일치 때 기존 설치 거부 유지
- 이번 완료 범위는 Windows 모델 실행 중단과 안내. 긴 셸의 native 작업 중단은 확인, 개별 OS 프로세스의 5초 종료 시각은 기록 부재로 미검증 유지. 다른 OS·원격·실제 제공자 초기화·서버 처리와 과금 종료 제외

## 공식 로고와 재개 동선 정정

- 사용자 추가 요청: 임의 방패 그림 대신 공식 로고, PowerShell 재개 절차의 필요성과 Codex 직접 재개의 관계 확인
- 로고 정본: `harness/plugins/aigent-hive/assets/hive-logo-plugin.png`. Rust의 원본 바이트 포함·표시 요청의 입력 전달, 창 제목 아이콘과 본문 이미지에 같은 원본 사용. 명령줄에 이미지 삽입 없음
- 변경 경로: `platform.rs::notify`, `notice.ps1::New-NoticeWindow`, 표시 미리보기·검사 도구와 관련 회귀. 실제 중단·관측·잠금 해제 조건 변경 없음
- 사용자 확정: 알림 전용 창, 닫기 외 버튼과 잠금·해제 절차 모두 제외. 감지 뒤 Codex의 직접 재개·새 메시지 허용
- `state.rs`: 사건 기록과 실행 허가 분리, 사건별 전송 상태 저장과 재시작 중복 억제. 초기화 관측 뒤 기준값 전진, 조회 공백은 연속 실패당 한 번·정상 관측으로 다음 실패 감지 준비
- `usage_monitor.rs`·`usage_control.rs`: 공유 사건의 새 실행 차단·확인 명령 제거. 기존 세션별 초기화 표식도 새 정상 관측으로 처리, 하한·0% 판정 유지
- 감시기가 이미 요청한 초기화는 세션별 이전 기준값 때문에 첫 재개 입력을 다시 멈추지 않는 공유 관측 비교. 같은 계정·묶음·집계 구간과 처리 시각·현재 잔량의 대조, 새 초기화·낮은 잔량의 보호 유지
- `desktop.rs`·`desktop.ps1`: native user-stop 요청 유지, 사건 시작 시 알려진 대상마다 한 번만 요청. 5초 확인 뒤 제어 자동 종료, 같은 사건·앱 재시작으로 새 작업 재중단 금지
- 검증: 중복 사건·지속 실패·회복·다음 초기화·재시작·직접 재개 허용의 Rust 회귀, 모의 Windows 요청 횟수·대상 고정·시한 뒤 미요청, 현재 앱 읽기 전용 확인과 표시 전용 검증. 추가 실제 중단 시험 제외, 기존 중단 근거와 바뀐 제어 수명 근거 구분
- 확인: 현재 Windows의 표시 전용 화면·원본 이미지 일치·닫기와 사건 보존·관련 회귀·시작 크기 제한. 추가 실제 작업 중단 없이 수정 후보 재검증·승인한 설치 갱신

## 설치 갱신의 지문 형식 복구

- 실제 설치 거부 원인: Windows 경로의 역슬래시로 GNU 지문 출력 앞에 붙은 단일 이스케이프 표식. 실행 파일의 실제 지문은 기존 승인 후보와 일치, 변경 전 안전 검사에서 중지
- `scripts/dev-install.sh`: 파일명을 해시 출력에 넣지 않는 표준 입력 방식, 이전 형식은 단일 표식과 64자리 소문자 지문을 검증한 뒤 정규화. 기존 기록 직접 수정 없음
- `complete-usage-monitor-install.ps1`: 같은 형식 검사와 현재 실행 파일 지문의 정확한 비교 유지. Windows 경로·공백·이전 표식·손상 거부 회귀 뒤 관리된 원복·설치 재시도
