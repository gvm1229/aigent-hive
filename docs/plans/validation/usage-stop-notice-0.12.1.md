# 사용량 보호 중단 안내 창 0.12.1

- 범위: RST121-002·003의 사용자 안내 개선. Windows 실제 중단 두 번과 사용자 관측 보존, 추가 실제 중단 시험 중지
- 목적: 갑자기 멈춘 이유와 Hive의 보호 동작 구분, 앱 유지·자동 재개 부재·다음 행동의 명확한 표시
- 현재 전체 자동 확인은 4개 중 3개·미확인 1개. 실제 세 시험 실행의 중단 사건은 별도 통과, 자동 확인·설치 통과로 확대 금지
- 기본 동작: 안내 닫기만 제공, 닫아도 잠금·감시·작업 상태 변경 없음. 재개 동작의 사용자 선호 질문은 선택 사항, 답변 전 기존 닫기 동작 유지

## 구현과 경계

- 소유: Codex. 기존 Windows 창의 운영 화면, 별도 제품 정체성·다른 기능 확대 제외
- `usage_monitor/notice.ps1`: WPF 안내 창과 순수 표시 상태 계산. 중단 이유·확인 상태·감지 시각·재개 방법, 기술 수치는 접힌 상세 영역
- `usage_monitor/windows.ps1`: 기존 예약 작업·앱 신원 조회 유지, 이전 안내 구현을 새 파일로 이동. 앱 제어 코드와 창 표시 분리
- `usage_monitor/platform.rs::notify`: 새 고정 안내 스크립트·원인 전달, 감시 제어부와 별도 실행. 5초 표시 확인·표시 실패 시 간단한 Windows 안내 대체
- 새 할당량 보호와 60초 조회 공백의 서로 다른 문구. 확인 실패·현재 실행 없음·상태 읽기 실패·새 사건·확인 완료를 성공으로 바꾸는 표시 금지
- 실제 사용자 창에 시험 문구 제외. 별도 표시 미리보기와 실제 합성 사건을 명확히 구분, 미리보기에서 감시·중단·설치·설정 변경 없음

## 화면 기준

- Windows 기본 창 조작·한국어 시스템 글꼴, 밝은 바탕·진한 글자·의미에 따른 초록/갈색 상태. 색만으로 의미 전달 금지
- 첫 화면: 원인과 Hive의 행동 → 확인 상태 → 앱 유지·자동 재개 부재 → 재개 방법 → 안내 닫기
- 긴 원문·식별자·명령줄의 기본 노출 제외. 상세 영역에 중단 요청·확인·미확인·연결·감시 상태
- 장치 독립 크기·자동 줄바꿈·스크롤, 좁은 창·높은 배율·키보드 초점·Esc 닫기·접근성 이름 확인

## 검증과 완료

- 현재 표시 수용: [Windows 안내 근거](../../research/usage-stop-notice-0.12.1.md), 실제 144 DPI·표시875ms·닫기와 Esc 경로의 사건 보존. 원래 Codex 앱 유지, 추가 실제 중단 없음
- 순수 상태 회귀: 실제/시험·초기화/조회 실패·성공/부분 확인·읽기 오류·확인 완료의 이유 보존
- 실제 Windows에서 새 표시 코드만 실행, 원래 Codex 앱 신원·저장 상태 지문 보존. 표시·상세 펼치기·닫기와 원인 지속 확인
- 대표 화면을 직접 확인하고 저장, 기본·좁은 창·긴 문구의 잘림 검사. 실제 실행 배율과 별도 그림 배율의 증명 범위 구분
- Rust 포함 스크립트의 Windows 명령줄 크기·관련 회귀·엄격 Clippy·빌드. 기존 실제 중단 근거 재사용, 추가 중단 없음
- 남은 자동 확인 1건은 읽기 전용 근거와 모의 회귀로 별도 해결. 설치는 전체 수용 조건 충족 후 기존 승인 경로, 정식 게시 별도 단계
