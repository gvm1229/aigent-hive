- 선택형 감시·연속 60초 관측 공백·앱 유지·닫기 전용 공식 로고 안내·같은 사건의 직접 재개 허용
- 지정 시험 대화의 긴 추론·셸 취소와 30분 조회 새 수용 승인. 앱 종료·잠금·시험 밖 불필요한 중단 금지
- 사용자 선택2: 이미 시작한 일반 외부 명령의 계속 실행 가능성 명시. 별도 로컬 AI 대화·하위 에이전트 중단은 필수, 앱 유지·원인 안내·직접 재개 검증
- 예기치 않은 앱 종료의 읽기 전용 조사 계속. 기존 감시 예약 비활성·기록 보존, 지정 시험 대화만 재시험
- 시험 대화2개 생성·시험 뒤 보관 승인 수신. 정식 게시·사용자 설치의 해당 버전 승인 별도
- 작업 브랜치 develop, Windows Codex. 이전 작업의 변경 보존
- [결정](../decisions/steering-preservation.md)·[0.12.0 완료 계획](../archive/plans/0.12.0-complete.md)
- [이전 미완료 9개](backlog/0.12.0-deferred-host-acceptance.md): 기존 후속 이관 유지, 이번 범위 편입 없음

- 아래 완료율은 구현·시험 수용 범위. REL121-004·005의 정식 게시는 [실행 기록](0.13.0-stable-release.md)에서 완료 확인
