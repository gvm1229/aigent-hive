## HCT112-001

- 읽기·변경: `crates/hive-cli/src/usage_control.rs`의 `parse_capture`, `capture_claude`, `read_claude_capture_snapshot`, Antigravity 관측 분기. `usage.rs`의 정규화 구조 재사용
- 절차: Claude 수신 형식을 유지하면서 호스트별 파서 분리 → `quota` 모음별 비율·초기화 시각 검증 → 계정·대화 지문·수신 시각 결합 → 기존 보호 정책에 전달
- 범위: 0~1 비율, 필수 모음 누락·빈 값·오래된 값·다른 계정·세션·손상 값은 사용 허가 불가. 토큰 수를 구독 사용량으로 변환하는 처리 제외
- 사용자 설정: 정확한 상태 표시 명령·변경점 검토 뒤 승인된 결합만 적용. 기존 표시 보존, 실패 시 원복. 원문·이메일·경로·식별자 원본 저장 금지
- 검증: 호스트별 파서 회귀, 두 모음 중 하나 제한·초기화·중복·순서 변경 반례, 실제 CLI 버전과 `/usage` 표시의 동시 대조. IDE 지원과 15초 보장으로 확대 금지
- 완료: 실제 정제 수신·보호 판정·설정 복원 증거. 1.1.18에서 필드 부재 시 지원 버전 확인 후 계획 수정, 현재 버전 지원 주장 제외

- 읽기: `crates/hive-core/src/native_workflow.rs`, `crates/hive-cli/src/custom_agent_cli.rs`, `run.rs`, 공식 호스트 제어 계약
- 결정 기준: 현재 실행의 호스트 소유 전송·권한·대상·제어 세대·중단 응답·최종 상태 확인 가능 여부
- 통과 뒤 변경: 기존 선언형 실행·영수증 계약에 지원 연결 정보를 결합. 경로는 조사 결과에 따라 정확히 확정한 뒤 수정

## HCT112-003

- 입력: 검증된 연결, 현재 실행 결합, HCT112-001 또는 기존 Codex의 신선한 사용량 관측
- 방식: 현재 호스트 소유 실행 범위 안의 제한된 15초 관측. 스킬의 상시 서버·별도 모델 서버·프로세스 강제 종료 제외
- 상태: 관측 → 제한 또는 관측 불확정 → 후속 실행 금지 → 인증된 중단 요청 → 호스트 `interrupted` 확인. 불확정 중단의 성공 처리 금지
- 재개: 같은 기준의 새 측정과 명시적 재개, 새 세션 기본 활성, 기존 예산·초기화 감지·제외 상태 경계 보존
- 검증: 관측 간격·누락·지연·비용 실측, 중단 직전 완료 경쟁·중복 요청·사용자 취소·복원 시험. 상태 변경 콜백만으로 15초 관측 통과 불가
- 완료: Windows 실제 동작과 오작동 반례 증거. 미지원 호스트는 명시 제외, 전체 기준의 임의 통과 금지
