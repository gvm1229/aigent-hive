# 0.13.1 공개 갱신의 부분 선택 인증

> Plan version: 0.13.1
> Scope: product

## 결정과 경계

- 실제 공개0.13.0에서 Skill3개를 고른 합성 설치의13.1-test.1 갱신 실패 재현. 실행 파일 갱신은 완료, 기존 사용자 연동은 인증 거부로 보존. 실사용자 설치 변경 없음
- 원인: `historical_09x_user_inventory`의 전체 Skill 파일 필수 조건. 포함된 파일의 알려진 원본·현지화·Windows 줄바꿈 인증은 통과하나 선택하지 않은 Skill까지 요구하는 불일치
- 수정: 설치 기록에 있는 Skill 묶음별 전체 파일과 기존 필수 메타데이터만 요구. 포함된 모든 파일은 내장 공개 원본의 지문과 대조, 모르는 경로·변조·선택 묶음의 일부 누락 거부 유지. 과거 기록을 자체 서명 권위로 사용하는 우회 금지
- Codex 앱·사용자 자료 보존, 재설치·원본 기록 수정으로 인증 오류를 숨기는 처리 금지. 공개test.1 바이트 보존, 다음 공개 시험test.2. 기존 중단 경로 변경 없음

## Windows 경로 보정 계약

- 기존 벡터 작업의 방식 재사용: 일반 Windows 경로로 다시 연 폴더와 고정한 폴더의 장치·파일 식별자 대조. 동일할 때만 프로세스용 경로 정규화, 파일 쓰기는 기존 고정 핸들과 상대 경로 사용
- `usage_monitor.rs`의 `configuration`에서 확인한 일반 경로로 실행 파일·인자·예약 이름 산출. `upgrade.rs`는 같은 고정 루트의 두 알려진 이름만 허용하고 기존 작업의 정확한 실행 정의로 제거, 새 정의로 등록
- 이전 실행 파일은 해당 루트의 bin 바로 아래 한 파일만 허용. 다른 폴더·부모 경로·임의 예약 이름 거부. 활성 선택·중단 기록 보존, 앱 종료·재개 잠금 없음
- Windows 일반/확장 경로·이전 이름 전환·활성/비활성·위조 경로 회귀. 실제 공개0.13.0 합성 설정과 예약을 새 소스로 전환해4회 정상 조회·앱 보존 확인, 중단 신호 주입 금지. test.1·2 실패 보존 후test.3 공개 수용
- 추가 재현: 이전 감시기가 종료되기 전 새 상태 형식의 읽기 실패와 보호 중단 요청 가능. `upgrade.rs`에서 이전 설정을 잠시 비활성으로 저장하고, 기존 상태를 바꾸지 않은 채 controller.lock 해제를 확인한 뒤 정확한 이전 예약 제거·새 상태 전환. 종료 확인 실패 시 상태 형식은 보존하고 전환 미완료 기록, 앱이나 감시 프로세스 강제 종료 경로 추가 금지
- `usage_monitor.rs` 오류 복구에서도 비활성 설정을 먼저 확인해 종료. `platform.rs`·`notice.ps1`은 기록 읽기 실패 때도 전달한 사건 이유·발생 시각 유지, 확인 실패의 성공·과거 사건 표시 금지. 회귀 및 표시 전용 Windows 시험으로 확인, 추가 대화 중단 시험 없음
- 감시기 시작 실패는 `startup.json`에 해당 실행 번호·버전·원인을 고정 루트 안에 보존하고 `status`에서 표시. 예약 시작 요청 성공을 감시기 정상 실행으로 계산하지 않는 기존 조건 유지
- 실제 긴 대화의19,943,687바이트 상태 자료가 기존16MiB 한도를 초과해 제어 연결 종료. `desktop.ps1`의 C# 수신부에서 제한된64MiB 입력을 표준 JSON 해석기로 읽고, 대화 식별·작업 상태·순서·확인 정보만256KiB 이하로 줄여 PowerShell에 전달. 본문·도구 결과·변경 값은 대기열 제외. 기존 중단·소유권·확인 시한 유지, 합성 큰 자료·잘못된 구조 회귀와 현재 앱의 중단 없는 전체 상태 연결 확인 후 실제 갱신 재검증

## 구현·검증 순서

1. `crates/hive-cli/src/user_install.rs`의 `historical_09x_user_inventory`에서 인증한 설치 항목의 Skill 이름 집합 산출. 알려진 과거 파일 목록의 Skill 항목은 해당 이름이 선택된 경우만 완전성 검사, 비Skill 필수 조건 유지
2. 공개0.13.0 실행 파일로 만든 합성3개 선택 기록을 개인정보·절대 경로 없이 `tests/fixtures/user-predecessors/0.13.0/`에 보존. 전체·부분 선택, 묶음의 일부 누락·변조·모르는 파일의 거부 시험. 사용자 실제 설정의 복제 제외
3. 새 소스 실행 파일로 별도의 공개0.13.0 합성 설치에 정상 미리보기·적용·검증, 지식·설정·기존 기록 보존 확인. 원래 실패 시험은 실패로 보존
4. 기존 인증·보안·사용자 갱신 회귀와 정확 소스 CI. 새 제품 지문으로test.2 후보·게시·세 운영체제 공개 수용·Windows 활성/비활성 실제 갱신. test.1의macOS 벡터 보조 프로그램 종료 실패는 별도 원인 확인, 중단 기능 통과로 대체 금지
5. UG131-007의 로컬 구현 검증 뒤 공개 수용은 UG131-006에서 합산. 실패 시 자료 보존·원인 기록, 정식 게시·실사용자 설치는 별도 승인
