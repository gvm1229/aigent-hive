# 0.13.1 공개 갱신의 부분 선택 인증

> Plan version: 0.13.1
> Scope: product

## 결정과 경계

- 실제 공개0.13.0에서 Skill3개를 고른 합성 설치의13.1-test.1 갱신 실패 재현. 실행 파일 갱신은 완료, 기존 사용자 연동은 인증 거부로 보존. 실사용자 설치 변경 없음
- 원인: `historical_09x_user_inventory`의 전체 Skill 파일 필수 조건. 포함된 파일의 알려진 원본·현지화·Windows 줄바꿈 인증은 통과하나 선택하지 않은 Skill까지 요구하는 불일치
- 수정: 설치 기록에 있는 Skill 묶음별 전체 파일과 기존 필수 메타데이터만 요구. 포함된 모든 파일은 내장 공개 원본의 지문과 대조, 모르는 경로·변조·선택 묶음의 일부 누락 거부 유지. 과거 기록을 자체 서명 권위로 사용하는 우회 금지
- Codex 앱·사용자 자료 보존, 재설치·원본 기록 수정으로 인증 오류를 숨기는 처리 금지. 공개test.1 바이트 보존, 다음 공개 시험test.2. 기존 중단 경로 변경 없음

## 구현·검증 순서

1. `crates/hive-cli/src/user_install.rs`의 `historical_09x_user_inventory`에서 인증한 설치 항목의 Skill 이름 집합 산출. 알려진 과거 파일 목록의 Skill 항목은 해당 이름이 선택된 경우만 완전성 검사, 비Skill 필수 조건 유지
2. 공개0.13.0 실행 파일로 만든 합성3개 선택 기록을 개인정보·절대 경로 없이 `tests/fixtures/user-predecessors/0.13.0/`에 보존. 전체·부분 선택, 묶음의 일부 누락·변조·모르는 파일의 거부 시험. 사용자 실제 설정의 복제 제외
3. 새 소스 실행 파일로 별도의 공개0.13.0 합성 설치에 정상 미리보기·적용·검증, 지식·설정·기존 기록 보존 확인. 원래 실패 시험은 실패로 보존
4. 기존 인증·보안·사용자 갱신 회귀와 정확 소스 CI. 새 제품 지문으로test.2 후보·게시·세 운영체제 공개 수용·Windows 활성/비활성 실제 갱신. test.1의macOS 벡터 보조 프로그램 종료 실패는 별도 원인 확인, 중단 기능 통과로 대체 금지
5. UG131-007의 로컬 구현 검증 뒤 공개 수용은 UG131-006에서 합산. 실패 시 자료 보존·원인 기록, 정식 게시·실사용자 설치는 별도 승인
