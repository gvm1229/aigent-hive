# 호스트 정책 훅 독립 평가

> Plan version: 0.11.0
> Scope: product

> 소유 항목: `HK-004`

- [ ] [HK-004] 수정에 사용하지 않은 보류 평가 자료로 기준선과 비교, 위반·오탐·시간·문맥 비용 측정
  - state: agent-owned; depends: HK-003

## 수용 조건

- 수정용 사례와 보류 평가 사례를 분리하고 식별자·기대 결과·판정 기준을 구현 조정 전에 고정
- 보류 자료를 보고 수정한 경우 해당 자료를 회귀 자료로 이동, 새 보류 자료로 다시 평가
- 새 정상 요청·유사하지만 허용할 작업·미로드·손상 입력·시간 초과·중단 재개를 포함
- 같은 작업 자료·호스트·정책 버전에서 지침만 제공한 기준선과 비교. 입력량·호출 수·추가 지연·위반·오탐 각각 보고
- 로드 성공률로 준수율 대체 금지, 미지원·미실행을 통과 분모에 포함 금지. 외부 홍보 수치를 합격 기준으로 사용 금지
