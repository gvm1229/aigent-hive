## 실행 계약

- Claude Code는 사람이 쓰는 대화형 호스트, Codex·Gemini는 구독 로그인 비대화형 작업자. Claude+Codex 먼저, Gemini도 동등한 작업자. `claude -p`·외부 키 입력·제공자 화면 캡처·cmux 없음
- Hive는 파일 봉투 작성·검증·상태 조율, 호스트 소유 처리기는 공식 확장점으로 봉투 소비·작업자 호출. Hive 자체 프로세스 실행·모델 호출·API·인증 파일 접근 없음
- 재사용: `crates/hive-core/src/orchestration.rs`의 `DispatchState`·`HostReceipt`, `schemas/host-orchestration-receipt.schema.json`·`hook-consent.schema.json`. Gemini 식별자 추가는 역할 지원과 함께 명시 검증, 기존 antigravity와 혼동 금지
- 봉투 필수값: 버전, 작업·실행 ID, 역할, 제공자, 정확한 모델·수준, 작업 파일·지문, 대상 프로젝트, 사건 머리·제어 세대, 일회 권한, 중복 방지 키, 결과 위치. 같은 파일시스템의 임시 파일 작성 후 원자적 이동, 단일 소비권 획득
- 확인증 유실·불명확 실행은 `dispatch-uncertain`, 자동 재호출 금지. 취소·재점유는 기존 정확한 대상·확인증 계약 유지. 단계 6 OV160-002에서 양방향 메시지 계약 확장
