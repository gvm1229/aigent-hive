## 결정

- **행동 기준:** 0.17.0의 모든 작업은 [`autonomous-workflow`](../../../.agents/skills/autonomous-workflow/SKILL.md) 기준. 중간에 멈춰 묻지 않고, 진짜 질문은 모아서 마지막에 한 번. 이 Skill은 지금 소스 프로젝트 전용 Skill로 먼저 추가된 상태이며, OV170-020에서 제품 Skill로 옮김
- **`verified-workflow` 제거:** 유지관리자가 최근 두 달간 사용 기록 없음. 제품 Skill에서 빼고 옛 이름은 `autonomous-workflow`로 안내. `hive loop`·`hive orchestration` CLI와 상태 기계는 단계 7 야간 반복이 재사용하므로 유지
- **정리 Skill:** `code-polish`를 `ai-slop-cleaner`로 이름 복원, 대상은 코드·문서·디자인. 이미 만든 결과물에서 AI 티를 걷어내는 Skill. 방향 확정: 유지관리자 2026-11-28 논의
- **브라우저:** 전역 설정에서 "기본 브라우저" 또는 "앱 내장 브라우저" 선택 단계 추가. 기본 브라우저는 Chromium 기반일 때만 사용하고, 아니면 Chrome으로 대체
- **기존 탭 사용:** 사용자가 따로 말하지 않으면 새 탭 대신 사용자가 보고 있는 탭에서 작업

  - 강제 겹(Claude): 사용자 확인과 `~/hive-backups` 백업 뒤 `~/.claude/settings.json`의 `permissions.deny`에 추가. `default-browser` 선택 시 `mcp__Claude_Browser__*`, `in-app` 선택 시 `mcp__claude-in-chrome__*`, `reuse_active_tab: true`면 새 탭 도구(`mcp__claude-in-chrome__tabs_create_mcp`, `mcp__Claude_Browser__tabs_create`)
  - 강제 겹(Codex): Codex의 MCP 도구별 끄기 설정·훅 지원 여부를 먼저 조사하고 지원되는 방식만 사용. 미지원이면 지침 겹만 적용하고 한계 표시
  - 미검증 위험: Claude in Chrome 확장이 Whale에서 연결되는지(Chrome Web Store 확장 설치와 native messaging 등록). 이 PC에서 실제 확인 전까지 Whale 사용은 "지원 미검증"으로 표시하고, 연결 실패 시 Chrome으로 안내
  - 미리 보기·되돌리기: 바꿀 파일과 줄을 보여 준 뒤 적용, 되돌리기 명령 제공. 다른 도구 설정은 이 단계에서만, 사용자 확인 뒤에만 변경
