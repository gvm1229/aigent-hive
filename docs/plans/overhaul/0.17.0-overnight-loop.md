# 단계 7 — 0.17.0 야간 루프

> Plan version: 0.17.0
> Scope: product

브랜치: `feature/overhaul-7-0.17.0-overnight-loop`([브랜치 규칙](README.md)). 진입: 0.16.0 정식. 설계: 개편 계획의 작업 흐름 F. 기존 `hive-core/loop_graph`·`loop_engineering` 재사용, 평가표는 `docs/decisions/score-driven-improvement.md`에서 흡수

## 반복 소유권

- 기준: [ADR-0026](../../decisions/ADR-0026-official-cli-extension-points.md)과 단계 6의 수신 상자·훅·확인증. Hive는 목표·예산·결정적 상태만 관리, 모델 호출과 작업자 프로세스는 호스트 소유
- Claude Code: 사람이 연 대화형 호스트 안의 공식 `/loop`·예약 작업·훅·하위 에이전트로 이어가기. Claude 비대화형·`claude -p`·외부 키 입력·제공자 CLI 화면 캡처 금지
- Codex·Gemini: 호스트 소유 처리기가 공식 비대화형 작업자 호출. 구독 로그인 사용, 역할·모델·수준·일회 권한·예산 결합. CLI 내장 반복·예약 기능의 존재 추정 금지
- Claude+Codex 우선 수용, Gemini 동등한 작업자 경로도 별도 수용. 공식 기능·설치 버전·실제 증명 없는 조합 비활성, API·인증 파일·사용자 전역 호스트 설정 변경 없음
