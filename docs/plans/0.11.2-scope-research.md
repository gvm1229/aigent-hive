# 0.11.2 후속 범위 조사

- 날짜: 2026-10-05
- 요청: 후속 8개·추가 7개 항목의 사용자 결정 반영, 구현 가능성 조사와 0.11.2 범위 편입
- 현재 실행 환경: Windows·Codex. Windows 우선, macOS 전용 검증은 마지막 순서
- 이번 완료 조건: 각 항목의 채택·대기·폐기·완료 판정, 근거·한계·실행 순서·정확한 후속 기준 기록과 문서 검사
- 승인 범위: 읽기 전용 조사, 계획·결정·지식 문서 수정. 발표 자료의 폐기 결정 기록
- 보존: 0.11.1 출시·수용 근거, 완료된 벡터 구현과 엔진 비교 자료, Git 복구 이력
- 제품 번호·설치본·호스트 설정·외부 발표 저장소 변경 제외. 현재 공개 제품 0.11.1 유지

## 순서

1. 공식 자료와 설치 CLI 도움말·관련 소스만 조사. Antigravity 사용량 출력, Codex 중단·분담 연결, 파일 검사 범위, Graphify·Obsidian, 토큰 집계·샌드박스·macOS 오류의 질문별 판정
2. 지원 계약·현재 버전·실제 실행 증명을 분리. 비밀·로그인 자료·대화 원문 접근과 모델 호출 없는 조사
3. `docs/research/followup-feasibility-0.11.2.md`에 출처·조회일·적용 버전·미검증 범위 기록. 불확실한 구현은 검증할 질문과 합격 조건을 먼저 고정
4. `docs/decisions/ADR-0025-0.11.2-scope.md`, `docs/plans/active/`의 관심사별 기준, `PLAN.md`·`CURRENT.md`와 후속 목록 정합화. 0.11.1 현재 문서의 과거 사본 보존
5. 기존 Notion·발표 자료 지식의 폐기 상태 정합화, 현재 결정의 영한 지식 기록. 엔진 비교의 참고 경로 유지
6. `python scripts/check-plan-state.py`, `python scripts/check-human-documentation-style.py`, `python scripts/check-markdown-links.py`, Source Wiki 색인·검사 실행. 제품 구현·macOS 실제 수용 성공 주장 제외

## 종료와 복구

- 조사·문서 반영을 이번 작업의 종료 범위로 한정. 새 제품 구현 완료와 구분
- 실행 계약 부재는 해당 구현의 검증 선행 조건으로 표시, 다른 조사 지속
- macOS 재현이 필요한 경우 Windows에서 준비 가능한 진단과 실제 macOS 검증을 분리, 마지막 기준에 배치
- 삭제 대신 폐기 사유·대체 문서 연결 우선. 외부 발표 파일의 위치 추측과 일괄 삭제 제외
