## 실패와 복구

- 후보 실패·부분 게시를 완료로 표시하지 않는 경계. 제품·설치·메타데이터·수용 수정이면 다음 허용 시험 번호로 재검증
- 이미 게시한 파일의 지문 대조와 같은 후보 복구만 사용, 공개 내용 교체·태그 삭제·강제 갱신 없음
- 필수 외부 권한·증거 결손은 해당 단계만 소유자·원인·해결 행동 기록. 독립 Agent 소유 작업은 계속 수행
- 추가 실제 중단·Codex 앱 종료 시험 없음. 현재 Windows 읽기 확인과 기존 실제 중단/표시 증거의 경계 유지
