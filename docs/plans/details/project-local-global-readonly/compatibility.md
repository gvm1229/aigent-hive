# 기존 읽기·쓰기 기능 보존 회귀

[설계](design.md) · [수용](acceptance.md) · [별도 공통 연결 작업](../../backlog/knowledge-attachment-consistency.md)

## 필수 계약

읽기 전용은 직접 고른 프로젝트에만 적용하는 추가 기능. 미선택 프로젝트의 기존 동작·권한·기본값 유지. 공통 연결 결함 수정과 새 기능을 같은 변경 단위에 포함 금지. 기존 프로젝트의 강제 전환·이전·재연결 절차 변경 금지.

아래 시험은 미래 제품 구현의 수용 조건. 이번 문서 수정에서 실행한 기존 제품 시험을 새 기능의 보존 통과로 집계 금지. `KB-A8`은 아래 C1–C5의 연결 항목이며 별도 중복 집계 제외.

## 비교 방법

- 공개0.14.0과 제품 경로가 같은 기준 실행 파일, 새 옵션을 추가한 실행 파일에 같은 가짜 입력·순서 적용
- 서로 다른 가짜 사용자 루트·프로젝트 사용. 실제 사용자 자료·진행 기록·설정·식별자 복사 금지
- 결과 항목·공개 범위·권한·승격·오류·복구·실제 저장 위치·부수 효과 비교. 시간·난수 ID·세대 번호는 명시한 대응표로 비교, 의미 차이를 무조건 지워 정규화 금지
- 미선택·명시 `shared-user-root`·명시 local 모드의 경로 분기 증거 확인. 새 읽기 전용 검사나 전역 쓰기 거부가 기존 경로에 적용되면 실패
- 정상 동작뿐 아니라 기존에 허용한 전역 초기화·색인 수리·변경도 성공해야 통과. 전역 쓰기를 막아 모든 시험을 통과시키는 대체 금지

## 실행과 판정

관련 기존 명령: `cargo +1.99.0 test --locked -p hive-wiki --lib`, `cargo +1.99.0 test --locked -p hive-cli knowledge::tests`, 공유 색인·승격·세션 CLI 시험. 새 모드 비교 회귀는 제안한 `test_project_knowledge_boundary.py`와 Rust CLI 통합 시험에 추가.

Windows·Linux·macOS에서 지원한 기능별 실제 실행·미실행·제외 이유 기록. 알려진 기존 Windows 잠금 경합 실패를 숨기거나 다른 운영체제 통과로 대체 금지. 현재 D1·D2의 기존 공유 동작 수정은 별도 승인이 있기 전 이번 기능의 수용 조건에서 제외.

릴리스 판정: 새 모드 KB-A1–A9와 C1–C5 모두 충족. 공통 코드 재사용 시에도 기존 동작 보존 비교 필수. 단위 시험만으로 전체 기능 보존·모든 운영체제 수용 주장 금지.
