### 범위 고정과 사례

- 상위 배점을 작업별 독립 조건으로 분해, 각 잎 조건은 양의 정수 배점
- 비해당 조건은 시작 전 같은 그룹에서 대체. 사후 만점·분모 제외·배점 재분배 금지
- 모호한 조건은 compile 실패와 구체적인 부족 항목 반환. 단순한 과제에는 필요한 조건만 작성
- 여러 작업 종류는 각 산출물의 결과를 분리. 전체 완료는 모든 필수 산출물의 통과, 평균 상쇄 금지
- 예시: 코드 획득30+25+14+6+8=83 → 0.83, 그룹1.00/1.00/0.70/0.40/0.80 → 미완료
- 과제 유형이 분류되지 않으면 명시한 평가표 선택 또는 사용자 정의 평가표 사용; 임의 평균 평가표 생성 금지

## QSI-004 — 교정과 채점표 자체 시험

- 선행: QSI-002·003
- 신규: tests/fixtures/quality/calibration/<profile>/, tests/conformance/contracts/test_quality_calibration.py
- 신규 자료: 평가표별24개 검토 사례, 개발12개·별도 보류12개. 보류 자료의3회 평가
- 각 분할: 정상 정답3, 표현·구조가 다른 정답3, 매끄러운 오답3, 필수 위반·근거 부족3
- 정답 항목·필수 조건은 결정적 근거 또는 사람 검토로 확정. 평가 모델이 자신의 기준 정답을 단독 확정하는 처리 금지
- 먼저 사례·정답·평가표·평가자 계약을 고정, 이후 보류 자료 공개 없이 평가
- 합격 기준: 필수 위반의 거짓 통과0건, 항목 판단 일치율과 완료 판단 일치율 각각0.90 이상
- 점수의 평균 절대 오차0.05 이하, 같은 사례3회 점수 범위0.03 이하
- 유효성: 위 표본·해당 평가표/모델/설정/자료/범위에 한정. 전체 작업의 정확도 확률 보장 제외
- 실패 시 원인 분석→개발 자료 수정→새 버전·새 보류 자료로 재시험. 같은 보류 자료를 반복 최적화하는 처리 금지
- 교정 자료에 노출된 사례는 실제 하네스 채택의 독립 보류 사례로 재사용 금지
- 분포 정보 부재 자체는 실패 아님. 미교정 분포·평가자 불일치만으로 자동 합격·탈락 금지
