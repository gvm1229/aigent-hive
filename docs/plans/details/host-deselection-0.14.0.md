# M05 선택에서 뺀 앱의 Hive 연결 해제

- 목표: 전역 설정에서 선택을 해제한 앱의 Hive 플러그인·마켓플레이스·정확한 Hive 안내 블록만 비활성화. 다른 플러그인·사용자 글·지식·기존 투영 원문 보존
- 소유: `user_install/deactivation.rs`, `user_install.rs`, `user_setup.rs`, `setup_engine/{interactive,file_apply,host_scope}.rs`, `progress_store.rs`, 인접 단위 시험·격리 Linux 수용 자료
- 제외: 본체 제거·프로젝트 조사·타사 설정 전체 교체·자동 재활성화. 설치 원문과 소유 목록은 남겨 재선택 때 기존 보존형 설치 경로 재사용

## 순서와 자료 계약

1. 기존 `reject_host_deselection`의 위키 backend 변경 거부 유지. 제거된 앱 목록을 계산하고 전용 읽기 전용 미리보기로 연결
2. 설치 소유 목록과 실행 중인 제품의 보존형 설치 계획으로 파일 소유권 검증. 검증된 앱 실행 파일·지원 버전·실제 구조화된 Hive 등록 상태 확인. 앱 존재만으로 기능 지원 판정 금지
3. `user_install::deactivation::Plan`에 앱·소유 목록 지문·원래 구조화된 Hive 상태·안내 파일 경로와 전후 지문 저장. 정확한 Hive 표식 제거 뒤 사용자 글의 전후 바이트 보존. 소유 증거가 없는 등록·다른 경로·손상 표식은 변경 전 거부
4. 미리보기에 앱별 해제·보존 대상 표시. 터미널과 파일의 공통 `SetupProgress.host_deactivations`에 같은 계획 저장. 최종 확인·처리 기록 선행 후만 적용
5. 각 앱은 원래 상태→Hive 플러그인 없음→Hive 마켓플레이스 없음의 고정 단계. 현재 상태가 기록한 단계 중 하나일 때만 남은 명령 실행, 명령 뒤 실제 상태 재검사. 중단 뒤 이미 없는 항목은 재삭제하지 않는 처리. 전혀 다른 등록은 보존 후 충돌
6. 안내 파일은 미리 본 전후 지문만 허용하고 비교 교체. 파일이 새로 편집되면 변경 전 거부. 활성 연결 해제 후 새 선택 앱 적용과 전역 설정 저장. 후속 실패가 해제한 앱을 임의로 다시 활성화하는 처리 금지
7. 새 설정 저장 전에 해제 계획 완료 확인. 재개는 저장한 계획과 기존 설정 복구 원본 사용, 이미 확인한 해제의 중복 명령 없음. 공통 처리 기록 없는 옛 내부 직접 적용의 해제 요청은 거부
8. Codex 상시 감시 유지와 Codex 선택 해제의 동시 요청은 감시 해제 선택부터 요구. 앱 선택 변경으로 감시 선호 자동 해제 없음. 완료 기록의 답안 삭제 뒤에도 중복 앱·범위 검사는 유지, 삭제한 선택 목록 검사는 완료 전 단계에만 적용
