- 상태: `ready`, 실제 실행 환경 확보 대기
- 목표 버전: 미정, `0.11.0` 범위 밖
- 사용자 결정: 2026-09-20, 당장 사용할 Claude Code 환경 부재로 후속 목표 이전
- 원래 소유 범위: `RFH-003`·`HK-003`·`HK-004`의 Claude 실제 실행 부분, 이를 참조한 `RFR-001`
- 기존 변환기·명시적 설정·철회·직접 명령 회귀·과거 증거 보존. 검증되지 않은 실제 호스트 지원의 통과 주장 금지

## 후속 수용

- 사용할 Claude Code 버전·운영체제·구독 호스트 실행 환경 확인
- 정확한 정의 검토·승인과 격리 설치, 시작·편집·종료 이벤트의 실제 동작 확인
- 허용·거부·검사기 부재·손상 입력·시간 초과·미로드·자식 작업의 범위 확인
- 지침 단독 기준선과 독립 자료 비교, 위반·오탐·전달량·지연 기록
- 지식 저장·새 대화 조회·후속 작업, 지원되는 취소·재개의 실제 근거 확인
- 미래 활성 계획에 명시적으로 편입한 뒤 새 완료 기준 부여. 현재 35개 항목의 완료율에 별도 가산 없음
