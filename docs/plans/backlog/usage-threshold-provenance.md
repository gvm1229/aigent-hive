# 사용량 임계값 변경 오류 조사·수정 후보

## 범위와 승인

- 기준: 공개0.14.0과 같은 제품 소스. 현재 승인: 원인 조사·가짜 자료 재현·계획. 제품 수정·버전 변경·출시 미승인
- 별도 개인 설정 조치: 승인한 이전 진행 기록 백업·공식 CLI 정리와 임계값 변경 완료. 개인 설정·백업·원문 진행 기록의 소스 반입 금지
- 수정 버전:0.14.1의 패치 후보 검토. 버전 확정·구현·번호 시험·정식 공개의 승인과 구분
- 결과 위치: [근거](../../research/usage-threshold-provenance-0.14.0/README.md)

## 조사 절차

1. `UT-I1`: 같은 가짜 설정에서 확인 기록 없음·유효 기록 존재를 비교. 미완료 설정 기록 없는 경우부터 전용 threshold 명령 재현
2. `UT-I2`: 일반 설정의 부분 답안 적용과 미완료 기록의 다른 의도 거부를 분리. 실제 개인 자료 사용 금지
3. `UT-I3`: 값 변경·직렬화·재읽기·확인 기록 정규화·전체 비교·되돌림의 함수·줄 번호 연결
4. `UT-I4`: 제품 결함과 로컬 미완료 기록의 관계, 확인하지 못한 과거 중단 원인, 수정 범위·회귀·버전 후보 정리

## 수정 후보

- `set_operational_usage_threshold`: 숫자 변경 직후 후보를 JSON 선언으로 변환하고, 기존 `reconcile_decisions(..., PreferenceScope::User)`를 후보의 기록에 적용한 뒤 직렬화·투영·게시
- 기존 유효 기록의 새 값은 공통 규칙의 `ExternalChange`·새 지문으로 정규화. 과거 답변 시각·질문 증거 제거, 대화형 입력·새 인간 답변 시각 허위 생성 금지. 확인 기록이 없는 입력은 기존 호환 유지
- `canonical_config` 뒤 `load_operational_config`의 일치 검사 유지. 검사를 제거하거나 확인 기록 전체를 지워 통과시키는 방법 금지
- `PreferenceDecision`과 부분 답안의 기존 의미 유지. 새 입력 출처 열거형·CLI 인자·필수 질문 추가 없이 최소 수정. 무관한 설정 값·정상 확인 기록 보존
- 실패 전후 정본·투영·지문 복구, 같은 값의 무변경, 임계값 상승·하락·0·99, 기존 프로젝트별 상한 관계 회귀
- `file_apply::require_same_intent`의 확인된 다른 의도 거부는 유지. 기존 진행 기록을 threshold 명령이 지우거나 우회하는 수정 금지
- 미완료 진행의 원인 조사와 복구는 별도 항목. 현재 설정과 값이 같다는 이유만으로 자동 삭제·자동 완료 처리 금지

검증 추가 위치: `user_setup.rs`·`usage_control.rs`의 기존 단위 시험. 새 시험 이름 제안: `global_threshold_with_valid_provenance_updates_atomically`. explicit·legacy-unknown 기록, 기록 부재, 같은 값, 일반 설정 완료 뒤 전용 변경, 미완료 의도 거부의 가짜 CLI 비교 포함. 지문 보정 후 재읽기 일치, 원래 실패 재현과 무관한 값·기록 보존 확인.

schema1·2, 부모 `/usage_guard`와 하위 임계값 기록의 동시 존재도 비교. 관련 지문은 함께 일치, 다른 정상 선호 기록은 그대로 유지. 전용 임계값 제어와 일반 설정의 미완료 의도 보호를 합쳐 새 제한을 만드는 변경 제외.

## 완료 조건

- 유효한 확인 기록이 있는 가짜 사용자도 전용 임계값 변경 성공, 다시 읽은 값·확인 지문 일치
- 무관한 설정·확인 기록·설치·지식 불변, 거부·실패의 복구 검증
- 명시적인 설정 변경 후 같은 세션의 재확인 필요 표시, 초기화·0% 보호 유지
- 기존 실패 재현 보존과 Windows·지원 운영체제별 수용. 이번 문서·재현만으로 제품 수정 완료 주장 금지

## 진행

- `UT-I1–I4`: 완료. 가짜 9개 관측과 소스 호출 흐름으로 전용 명령 결함·일반 설정의 의도 보호를 분리. 과거 설정 이전의 최초 실패 상세 원인은 미확인으로 보존
- 구현·버전 확정·출시: `awaiting-user-authority`
