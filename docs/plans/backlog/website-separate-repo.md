# 소개 사이트 독립 배포

> 작성일: 2026-11-28 · 상태: 승인·진행 중

사이트 이전 대상: 별도 저장소 `aigent-hive-website`. 전체 계획·디자인 규칙 정본: 그 저장소 `docs/PLAN.md`·`AGENTS.md`. 이 저장소에 디자인·사이트 코드 보관 금지.

## 이 저장소에서 할 일

| 항목 | 내용 |
| --- | --- |
| 출시 완료 기준 | 안정판마다 사이트 저장소에 `content/releases/<version>.json`(What's new, 이전·최신 대화 비교, 영향 구역 문구)과 영향 구역 수정을 합치고 운영 사이트에 그 버전이 보여야 출시 완료. 버전 번호만 바꾸기 금지 |
| 게시 뒤 확인 | `release-publish.yml` 끝에 운영 사이트의 새 버전 표시 확인 단계 추가. 실패해도 npm 게시는 막지 않고 그 단계만 실패 표시 |
| `website/` 삭제 | 사이트 저장소 운영 배포 확인 뒤 삭제, README·문서 링크를 새 저장소와 운영 주소로 교체 |
