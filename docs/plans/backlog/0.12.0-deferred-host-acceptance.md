# 0.12.0에서 이관한 실제 호스트 수용

- 사용자 결정: 2026-10-06 미완료9개는 나중 작업으로 이관, 완료 기능만으로0.12.0 안정판 출시
- 목표 버전: 미지정. 사용자가 후속 버전을 지정하기 전 임의 배정 제외
- 이번0.12.0 안정판 범위 밖, 완료 처리 없음. 기존 담당자·실패·미검증·의존 관계 보존
- 현재 Windows·Codex에서 실제 연결·모델·사건 증명 결손, 같은 컴퓨터의 합성 검사로 대체 제외
- macOS 원래 오류의 실제 arm64 재현·복구는 후속 수용의 마지막 단계
