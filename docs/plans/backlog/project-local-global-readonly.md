- 제외: 제품 수정, 실제 소비자·전역 지식 접근과 이전, 커밋·게시·설치
- 미래 제품 버전: 미정. 정식 `0.14.0` 수정이나 새 시험판 번호 임의 배정 금지

## 2026-11-04 수정 범위

- 읽기 전용은 명시적으로 선택하는 추가 옵션. 기존 읽기·쓰기의 기능·기본값·저장 방식·자동 승격·권한·재연결 의미 유지
- 기존 프로젝트의 자동 전환·강제 이전·새 필수 질문 금지. 새 모드의 제한과 무쓰기 조회 경로만 선택한 프로젝트에 적용
- 공통 연결 상태 수정은 별도 미승인 작업으로 분리. 읽기 전용 기능의 선행 조건·수용 집계에서 제외
- 기존 동작 보존의 전후 비교·미선택·명시 기존 방식·두 방식 동시 사용 회귀 추가
- 별도 승인한 개인 설정 진행 기록의 복구·사용량 기준 변경은 제품 구현과 구분. 임계값 확인 정보 오류의 가짜 자료 재현·수정 후보 검토,0.14.1은 버전 후보만 검토

수정 절차: `KB-R1` 계획 분리 → `KB-R2` 보존 회귀 보강 → `UT-I1` 임계값·미완료 기록 원인 분리 → `KB-R3` 문서·소스 사실 검사. 제품 구현은 계속 미승인.

- `KB-R1–R2`: 완료. 공통 연결 작업 분리, 추가 옵션만 적용하는 설계·단계·C1–C5 회귀 반영
- `UT-I1`: 완료. [별도 임계값 조사](../../research/usage-threshold-provenance-0.14.0/README.md),0.14.1 호환 오류 수정 후보
- `KB-R3`: 완료. 작성 문서 문체·링크·기존15개 계획 집계·262쪽 소스 사실과 파생 색인 확인. 제품 코드·버전·실제 지식 변경 없이 계획과 진단만 수정

## 조사 순서

1. `KB-I1`: 공개 태그·현재 제품 경로 비교, 설정·등록·저장소·권한의 호출 경로 확인
2. `KB-I2`: 별도 사용자 루트와 가짜 프로젝트로 새 설정·조회·정본 저장의 변경 파일 확인
3. `KB-I3`: 매 시험 전 해제 상태 복원, 명령별 직렬 시험, 통제된 동시 실행과 재시작 비교
4. `KB-I4`: 기능 표·원인·미해결 가설·최소 수정과 후속 단계 작성
5. `KB-I5`: 문서 연결·문체·관련 기존 시험·정본 사실과 파생 색인 확인

## 종료 조건

- 공개 동작과 소스 추론의 분리, 파일·함수·줄 번호 근거
- 실제 전역 저장소를 사용하지 않는 재현 명령과 작은 관측 기록
- 확인된 결함·새 기능 필요·문서 오류·동시성 미확인 항목의 구분
- 중앙 강제 정책, 읽기 전용 조회, 해제 보존, 선택적 이전, 회귀 시험의 구현 가능 계획
- 조사 완료 뒤 제품 구현 승인 대기. 제품 수용 시험의 미실행 상태 보존
