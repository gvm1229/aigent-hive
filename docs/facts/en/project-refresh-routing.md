# Project Refresh Skill Routing

Selected global project-refresh Skills permit implicit invocation for existing project guidance updates. Project copies retain explicit invocation. Preview-only requests do not apply changes. The Skill runs authenticated upgrade, exact path coordination, preservation checks, and validation; users need not type CLI commands.
