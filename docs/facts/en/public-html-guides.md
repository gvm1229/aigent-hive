# Public Korean HTML Guides

Two standalone Korean guides retain the logo, 960 px layout, gold `#F5A623` and one embedded PNG per page, without external resources. The feature HTML retains the 0.11.0 snapshot: optional Hooks, selected instruction recovery, project refresh, collaboration without Hive and reset stops at the next usage check. Its knowledge table names knowledge-capture, knowledge-recall, knowledge-scan, knowledge-promote and knowledge-maintain.

Install HTML follows the current stable manifest: npm/direct install, interactive hive update for host selection, global setup, optional project setup and knowledge transfer. PDFs retain the 0.11.0 Chrome snapshots, checked at 144 dpi (9/7 pages); a new HTML release does not prove a new PDF render.
