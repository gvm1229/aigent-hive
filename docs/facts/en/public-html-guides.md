# Public Korean HTML Guides

The repository includes standalone Korean pages for Hive's core features and streamlined stable
installation. Both pages reuse `docs/assets/branding/hive-logo-mark.png`, inherit the reference
document's compact 960 px information structure, and replace its accent with beehive gold
`#F5A623`. The feature page covers provider-neutral setup, durable Markdown knowledge, Skill and
run continuity, usage safeguards, and ownership boundaries. The install page covers stable
`0.8.0`, host activation, global preferences, project setup, direct installers, and updates.
The originating request required two individual Korean HTML files, the existing Hive logo, and
gold branding; README branding was already completed by commit `245ae80`.
