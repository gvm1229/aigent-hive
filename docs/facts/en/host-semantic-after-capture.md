# Host-owned relationships after capture

Canonical storage completes first. Enabled partitions queue changes; identical saves add no analysis. The current host receives at most ten changed documents and authorized context within 16KiB.

Hive checks scope, source digests, UTF-8 evidence spans and bound result receipts before atomic publication. Invalid results allow one correction. Relations never become canonical facts; no provider API, watcher or recursive save is used.

Source, shared, project-private and confidential data stay separate. Deleted relations are hidden; an empty result clears obsolete state without analysis.
