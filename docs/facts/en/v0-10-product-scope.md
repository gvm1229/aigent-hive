# Aigent Hive 0.10.0 Product Scope

The scope includes native Markdown relations, optional Graphify code extraction, FTS and a
conditional vector gate, safe nested scans, host-neutral continuation, `verified-workflow`, and
`adversarial-judge`. Direct upgrades remove authenticated retired Skill projections. Foreign or
modified bytes block activation. A failed vector gate adds no dependency. Stable publication
requires three-OS acceptance and explicit maintainer approval.
