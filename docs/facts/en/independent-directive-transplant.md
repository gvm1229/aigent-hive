# Independent Directive Transplantation

A requested directive transfer adapts names, paths, roles, links and authority into independent target-owned rules. Operational copied-from commentary is removed, while required notices and source files remain intact. Source-session approvals never transfer. Imported user directives do not become Hive-generated files. Unresolved mappings block only their dependent edits. Exact archival copies keep explicitly requested bytes.
