# Source Project-Only Update Summary Skill

`update-summary` is maintainer-authorized and source-only; product bundles, catalogs, and consumer
projections exclude it. It writes Korean subscriber advertising from verified baseline/target
evidence. Distinguish new, improved, fixed, and renamed features. Lead with core technical names
and user benefits; follow with examples, choices, and costs. Korean agent review uses `리뷰`.
Developer-only publication formatting, CI, records, and plans stay out. Unreleased targets need a
review-draft label. Preserve factual limits; no publication authority.
Stable payload: `docs/releases/<version>.subscriber.ko.md`.
