# Source-Project Update Summary Skill

Nonshipping `update-summary` compares requested releases for Hive newcomers: verified complete benefits, core technical names, examples, choices, costs and limits; keep failed checks internal. Use noun phrases; reject polite endings and mechanical ham/eum suffixes. Reference 0.11.1 for tone and approved 0.10.0 for positioning. New copy uses ordered new/fix/improvement sections with separators, omits empty categories and assigns each change once. Count the whole 2,000-character message; shorten only if over. Drafts are unissued; wording approval is not release authority. Existing gh registers approved digests, without manual setup or sending. Compare file/sidecar/external digest without refresh; changed copy needs new approval, retries reuse it.
