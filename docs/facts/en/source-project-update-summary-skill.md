# Source Project-Only Update Summary Skill

`update-summary` is a source-only maintainer Skill; product bundles, catalogs, and consumer
projections exclude it. It writes verified Korean subscriber advertising, separating new,
improved, fixed, and renamed changes. Lead with core technical value; follow with examples, choices,
and costs. Unreleased text stays a draft; no publication authority. Stable delivery needs matching
`.sha256` and protected `AIGENT_HIVE_SUBSCRIBER_SUMMARY_DIGEST` values. Required reference: the
maintainer-approved 0.10.0 note, dated 2026-09-01.
