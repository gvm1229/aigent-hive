# 0.11.2 Scope and Windows First

The maintainer's 2026-10-05 decision assigns usage monitoring, interruption, host-owned
delegation, remaining Graphify work, and feasible diagnostics to 0.11.2. Windows comes first;
macOS-specific acceptance is last. Claude live validation and publisher signing stay pending.

Notion and the old presentation are retired. The logo and vector feature are complete;
engine comparisons remain references. Basic Obsidian use needs only Markdown.

Official documents, local CLI help, and source inspection support the saved scope and
verification order. Research completion does not prove implementation or live acceptance.
