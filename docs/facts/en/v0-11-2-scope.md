# 0.11.2 Scope and Windows First

The maintainer's 2026-10-05 decision puts usage monitoring, interruption, host-owned delegation, remaining Graphify work and diagnostics in 0.11.2. Only verified host features activate. Other features remain disabled or pending. Enabled relations run after capture; analysis failure preserves the successful save.

Windows comes first and macOS-specific acceptance last. Claude live validation and publisher signing remain pending. Notion and the old presentation are retired. The logo and vector feature are complete; engine comparisons remain references. Obsidian needs Markdown, with no extra plugin.

Official documents, CLI and source research support the plan. Research and implementation do not prove live acceptance.
