# 공개 한국어 HTML 안내

Repository의 독립 한국어 페이지 2개: Hive 핵심 기능과 간단한 stable 설치 경로.
공통 visual contract: `docs/assets/branding/hive-logo-mark.png`, 참조 문서의 compact
960 px 정보 구조, 벌집 금색 `#F5A623` accent.
핵심 기능 범위: provider-neutral setup, 지속 가능한 Markdown 지식, Skill·run 연속성,
사용량 보호, 소유권 경계.
설치 안내 범위: stable `0.8.0`, host 활성화, 전역 선호, project 설정, 직접 installer,
update.
Originating request: 개별 한국어 HTML 2개, 기존 Hive logo, 금색 branding.
README branding: 기존 commit `245ae80`에서 완료.
