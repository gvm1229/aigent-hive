# Antigravity 파일 훅 확인 범위

사용자 보고 환경: Windows의 Antigravity IDE 2.5.5, Gemini Flash 3.8 Medium. replace_file_content의 일반 편집 성공·보호 편집 거부 보고. 제어 작업에서 일반 표식 추가와 보호 바이트 불변을 독립 확인하고 원본 복원. 버전·도구 실행은 사용자 보고 근거. 합성 파일 한 쌍에 한정한 검증이며 다른 도구·시간 초과·시작 및 종료 훅·지식 연결·취소는 미검증.
