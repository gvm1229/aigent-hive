# 프로젝트 갱신 스킬 연결

선택한 전역 project-refresh 스킬은 기존 프로젝트 지침의 자연어 갱신 요청에 연결. 프로젝트 사본은 명시 호출 유지. 미리보기 요청에서는 적용 금지. 스킬이 인증된 갱신·정확한 경로 예약·원본 보존·최종 검사를 수행하므로 사용자의 명령 입력 불필요.
