01 · WHAT'S NEW

0.16.0에서 달라진 대화

같은 요청, 다른 결과. 업데이트 전과 후의 AI 에이전트 대화를 나란히 비교.

대화는 기능 설명을 위한 연출 예시. 터미널 출력은 요약 표시이며 실제 문구·모델·시간은 환경에 따라 다름.

02 · WHY HIVE

바꾸지 않는 것까지 약속

AI 앱의 실행은 그 앱에 맡기고, Hive는 기억·설정·안전 경계만 담당.

API 키 요청 없음

모델 회사 API를 부르지 않고 지금 쓰는 구독 로그인 그대로 사용.

내 컴퓨터의 텍스트

지식과 설정은 읽을 수 있는 Markdown·YAML 파일. 검색 색인은 언제든 다시 생성.

바꾸기 전 백업

설치·갱신·제거 전에 설정과 바뀔 파일을 복사. 복원은 미리보기부터.

동의 뒤 적용

추가 Skill, 훅, 상태 표시줄 연결은 미리 보여 준 뒤 승인할 때만 적용.

03 · INSTALL

설치와 첫 설정

설치 프로그램만 Node.js·npm이 필요하고, 설치된 hive는 독립 실행 파일.

  1. 설치
    오른쪽 명령 중 하나를 터미널에서 실행
  2. 버전 확인
    hive --version → AIgent Hive v0.16.0 (released 2026-11-25)
  3. 앱 연결
    hive update 실행 뒤 쓰는 AI 앱 선택
  4. 프로젝트 설정
    AI 에이전트에게 프로젝트 설정 Skill 요청. 빈 폴더는 질문부터, 기존 프로젝트는 파일 확인 뒤 제안 하나
