# Aigent Hive Marketing Deck

An eight-slide marketing overview for Aigent Hive was created in the LumaDeck repository as
`projects/aigent-hive-overview/`. The editable core is `slides.md` with project-local CSS and deck
metadata. The last validated PDF lives under the matching `artifacts/aigent-hive-overview/` tree.

The deck was created to explain:

1. What our Hive harness is about
2. Who Hive is for
3. What features Hive provides
4. How Hive is structured and functions
5. What optimization strategy Hive uses

The narrative positions Hive as a local, provider-neutral, user-owned harness. It covers automatic
onboarding, project Markdown Wiki, the user-root disposable SQLite search index, safe upgrade,
usage guard, prompt refinement, narrow loading, native-first capability reuse, and tiered
verification.
